## 序章　二段構成CMOSオペアンプとは

# 小さな信号を、次の回路へ増幅

## オペアンプ

センサやマイクから出てくる信号は、とても小さい。
その小さな変化を受け取り、扱いやすい電圧に変える。
オペアンプは、電子機器の中でそんな仕事をしている。
オペアンプには、非反転入力と反転入力という2つの入力がある。オペアンプは、この2つの入力電圧の差を受け取り、その差を大きくして出力する。

```text
差動入力電圧 = 非反転入力電圧 − 反転入力電圧
```

例えば、2つの入力電圧の差がわずか1 mVであっても、オペアンプの電圧利得が大きければ、より大きな出力電圧の変化として

## 0.1　二段構成オペアンプの概要

### わずかな電圧の違いを大きくする
<img width="1111" height="747" alt="image" src="https://github.com/user-attachments/assets/bf00479c-59f1-4c89-96fb-ea42275197c9" />



### NMOSとPMOSを組み合わせる

二段構成CMOSオペアンプは、NMOSとPMOSという2種類のMOSFETを組み合わせて作られる。

MOSFETは、ゲートに加えられた電圧によって、ドレイン電流の流れ方を調整する部品である。

* NMOS：ゲート電圧が高くなると電流を流しやすくなる
* PMOS：ゲート電圧が低くなると電流を流しやすくなる

NMOSとPMOSは反対の電圧変化に対して電流を流しやすくなる。この2種類を組み合わせることで、差動入力回路、電流源、増幅回路などを1つのIC内に作ることができる。



### 二段構成オペアンプが使われる場所

二段構成オペアンプは、アナログ信号を増幅する回路や、出力電圧を一定に保つ制御回路などに使用される。

| 使用例        | オペアンプの役割                    |
| ---------- | --------------------------- |
| センサー信号処理回路 | 温度、圧力、光などの小さな信号を増幅する        |
| A/D変換回路    | 入力信号を増幅または保持し、ADCへ渡す        |
| D/A変換回路    | DACの出力電流や出力電圧を扱いやすい電圧へ変換する  |
| アクティブフィルタ  | 必要な周波数成分を通し、不要な成分を減らす       |
| LDOレギュレータ  | 出力電圧と基準電圧を比較し、出力電圧を一定に保つ    |
| DC/DCコンバータ | 出力電圧の誤差を増幅し、PWMのデューティ比を調整する |
| 基準電圧回路     | 基準となる電圧を安定させる               |
| オーディオ回路    | 音声信号を増幅したり、周波数特性を調整したりする    |
| 医療・計測用IC   | 生体信号や測定信号などの小さな電圧を増幅する      |



**結論**

二段構成CMOSオペアンプは、2つの入力電圧の小さな差を、センサー信号処理、ADC、DAC、アクティブフィルタ、LDO、DC/DCコンバータなど、さまざまなアナログ・ミックスドシグナル回路で使用される。


## 0.2　第1段と第2段の役割

### 前半で入力を受け取り、後半で大きくする

第1段は、2つの入力電圧の違いを受け取る部分である。

第2段は、第1段から渡された信号をさらに大きくして、出力へ送る部分である。

```text
入力 → 第1段 → 第2段 → 出力
```

**結論**

第1段が入力を受け取り、第2段が出力に必要な大きさまで増幅する。

---

## 0.3　入力から出力までの信号経路

### 信号は二つの増幅段を順番に通る

入力された信号は、まず第1段に入る。

第1段で変化した信号は第2段へ渡され、さらに増幅される。最後に、オペアンプの出力端子から外へ出ていく。

```text
2つの入力
    ↓
第1段
    ↓
第2段
    ↓
出力
```

**結論**

入力信号は、第1段から第2段へ順番に伝わり、最後に出力信号になる。

---

## 0.4　二段構成にする理由

### 二つの回路で仕事を分ける

一つの増幅回路だけで、小さな入力を受け取り、大きな出力を作るのは難しい。

そこで、入力を受け取る部分と、出力を大きくする部分に仕事を分ける。二段に分けることで、それぞれの役割に合った回路を作りやすくなる。

**結論**

二段構成にする理由は、入力と出力の仕事を分け、十分な増幅を得やすくするためである。

---

## 0.5　主な要求仕様

### 大きく、速く、安定して動くことが求められる

オペアンプは、ただ信号を大きくできればよいわけではない。

* 信号を十分に増幅できること
* 入力の変化にすばやく反応できること
* 出力が不安定にならないこと
* 必要な範囲の電圧を扱えること
* 消費する電力が大きすぎないこと

これらの性能を、使う目的に合わせて決めていく。

**結論**

オペアンプの設計では、増幅の大きさだけでなく、速度、安定性、電圧範囲、消費電力も重要になる。

---

## 序章の結論

二段構成CMOSオペアンプは、小さな入力電圧の差を受け取り、二つの増幅段を通して大きな出力信号に変える回路である。

第1段と第2段がどのような回路で作られ、どのように信号を増幅するのかを、次の章から順番に見ていく。


# 第1章　オペアンプとMOSFETの基礎

## Fundamentals of Operational Amplifiers and MOSFETs

二段構成CMOSオペアンプは、NMOSとPMOSを組み合わせて作られている。

この章では、オペアンプの基本的な使い方と、MOSFETで信号を増幅するために必要な内容を学ぶ。式は、回路でよく使う形に絞って説明する。

---

## 1.1　差動入力と出力電圧

### 2つの入力電圧の差を増幅する

オペアンプには、非反転入力と反転入力がある。オペアンプが増幅するのは、2つの入力電圧の差である。
<img width="690" height="490" alt="image" src="https://github.com/user-attachments/assets/9798ab15-135f-4234-b449-98cccac06f21" />

~~~text
v_id = v_in+ - v_in-
~~~

| 記号 | 意味 |
|---|---|
| v_in+ | 非反転入力の電圧 |
| v_in- | 反転入力の電圧 |
| v_id | 2つの入力電圧の差 |

開ループ利得をA_0とすると、出力電圧は次のようになる。

~~~text
v_out = A_0 × v_id
~~~

| 記号 | 意味 |
|---|---|
| A_0 | 負帰還をかけていないときの電圧利得 |
| v_out | オペアンプの出力電圧 |

- v_in+ が高いと、出力は高くなる
- v_in- が高いと、出力は低くなる
- 出力できる電圧は、電源電圧によって制限される

**結論**

オペアンプは、非反転入力と反転入力の電圧差を増幅する。

---

## 1.2　開ループ動作と負帰還

### 開ループ動作

出力を入力側へ戻さない状態を、開ループ動作という。

オペアンプの開ループ利得は非常に大きい。そのため、わずかな入力差でも出力が電源電圧付近まで動き、それ以上変化できなくなる。この状態を出力の飽和という。

### 負帰還

出力の一部を反転入力へ戻す接続を、負帰還という。

負帰還が正常に働き、出力が飽和していないときは、2つの入力電圧をほぼ同じと考えられる。

~~~text
v_in+ ≈ v_in-
~~~
<img width="827" height="602" alt="image" src="https://github.com/user-attachments/assets/a49f5e13-17be-4722-8393-b48621c4c9bf" />

この関係を使うと、反転増幅回路と非反転増幅回路の利得を簡単に求められる。

### 反転増幅回路
<img width="555" height="325" alt="image" src="https://github.com/user-attachments/assets/72bd0e6d-73f4-44f3-b911-d18d3cf6d30e" />

反転増幅回路では、入力信号を抵抗R_1を通して反転入力へ加える。非反転入力はGNDへ接続する。抵抗R_2は、出力と反転入力の間に接続する。

負帰還によって反転入力もほぼ0 Vになる。この状態を仮想接地という。ただし、反転入力が実際にGNDへ接続されているわけではない。

電圧利得は次のようになる。

~~~text
A_v = -R_2 / R_1
~~~
<img width="555" height="552" alt="image" src="https://github.com/user-attachments/assets/10bdc5fd-f505-49c6-8491-39768105d9b3" />

| 記号 | 意味 |
|---|---|
| A_v | 入力電圧に対する出力電圧の倍率 |
| R_1 | 入力と反転入力の間の抵抗 |
| R_2 | 出力と反転入力の間の帰還抵抗 |
| - | 入力と出力の向きが反対になることを表す |

出力電圧は次の式で求められる。

~~~text
v_out = A_v × v_in
~~~

たとえば、R_1 = 10 kΩ、R_2 = 40 kΩの場合は次のようになる。

~~~text
A_v = -40 kΩ / 10 kΩ = -4
~~~

入力が0.2 Vなら、出力は次の値になる。

~~~text
v_out = -4 × 0.2 V = -0.8 V
~~~

反転増幅回路では、入力が正方向に変化すると、出力は負方向に変化する。

### 非反転増幅回路
<img width="1024" height="559" alt="image" src="https://github.com/user-attachments/assets/b7fc330e-b970-4037-bde7-417d13ebfd22" />

非反転増幅回路では、入力信号を非反転入力へ加える。

R_1は反転入力とGNDの間、R_2は出力と反転入力の間に接続する。

電圧利得は次のようになる。

~~~text
A_v = 1 + R_2 / R_1
~~~

| 記号 | 意味 |
|---|---|
| A_v | 入力電圧に対する出力電圧の倍率 |
| R_1 | 反転入力とGNDの間の抵抗 |
| R_2 | 出力と反転入力の間の帰還抵抗 |
| 1 | 非反転増幅回路の利得が1倍より小さくならないことを表す |

たとえば、R_1 = 10 kΩ、R_2 = 40 kΩの場合は次のようになる。

~~~text
A_v = 1 + 40 kΩ / 10 kΩ = 5
~~~

入力が0.2 Vなら、出力は次の値になる。

~~~text
v_out = 5 × 0.2 V = 1.0 V
~~~

非反転増幅回路では、入力と出力が同じ方向に変化する。

### 反転増幅と非反転増幅の違い

| 項目 | 反転増幅 | 非反転増幅 |
|---|---|---|
| 入力を加える端子 | 反転入力 | 非反転入力 |
| 出力の向き | 入力と反対 | 入力と同じ |
| 利得 | -R_2 / R_1 | 1 + R_2 / R_1 |
| 入力抵抗 | 主にR_1で決まる | オペアンプの入力抵抗が高いため大きい |

**結論**

負帰還を使うと、抵抗の比によって回路の利得を決められる。反転増幅では出力の向きが反対になり、非反転増幅では同じ向きになる。

## 1.3　理想オペアンプと実際のオペアンプ

### 理想オペアンプの基本ルール

理想オペアンプは、回路を簡単に計算するためのモデルである。

負帰還が働いているときは、次の2つのルールを使う。

~~~text
入力電流：i_+ = i_- = 0
~~~

~~~text
入力電圧：v_in+ ≈ v_in-
~~~

| 記号 | 意味 |
|---|---|
| i_+ | 非反転入力へ流れ込む電流 |
| i_- | 反転入力へ流れ込む電流 |
| v_in+ | 非反転入力の電圧 |
| v_in- | 反転入力の電圧 |

### 実際のオペアンプの限界

| 項目 | 理想 | 実際 |
|---|---|---|
| 開ループ利得 | 無限大 | 大きいが有限 |
| 入力電流 | 0 | わずかに流れる |
| 出力電圧 | 制限なし | 電源電圧で制限される |
| 周波数範囲 | 制限なし | 上限がある |
| 入力オフセット電圧 | 0 | わずかに存在する |

v_in+ ≈ v_in- と考えられるのは、負帰還が働き、出力が飽和していない場合だけである。

**結論**

基本計算では理想オペアンプを使い、実際の設計では電圧、電流、周波数の限界を確認する。

## 1.4　NMOSとPMOS

### MOSFETの役割

MOSFETは、ゲート電圧によってドレイン電流を調整する部品である。

主な端子は次の4つである。

| 端子 | 記号 | 役割 |
|---|---|---|
| ゲート | G | 電流を調整する入力 |
| ドレイン | D | 電流経路の一方 |
| ソース | S | 電流経路のもう一方 |
| バルク | B | MOSFETが作られている基板側 |
<img width="860" height="636" alt="image" src="https://github.com/user-attachments/assets/8c25a674-c68e-4985-ad50-8e934ddb0855" />
---

* Behzad Razavi, *[Design of Analog CMOS Integrated Circuits, 2nd Edition](https://www.mheducation.com/highered/product/design-of-analog-cmos-integrated-circuits-razavi.html)*, McGraw Hill

### NMOS

NMOSは、ゲート電圧がソース電圧より十分に高くなると電流を流しやすくなる。

~~~text
V_GS = V_G - V_S
~~~

~~~text
V_GS > V_THn
~~~

| 記号 | 意味 |
|---|---|
| V_G | ゲート電圧 |
| V_S | ソース電圧 |
| V_GS | ゲートとソースの電圧差 |
| V_THn | NMOSのしきい値電圧 |

### PMOS

PMOSは、ゲート電圧がソース電圧より十分に低くなると電流を流しやすくなる。

~~~text
V_SG = V_S - V_G
~~~

~~~text
V_SG > abs(V_THp)
~~~

| 記号 | 意味 |
|---|---|
| V_SG | ソースとゲートの電圧差 |
| V_THp | PMOSのしきい値電圧 |
| abs(V_THp) | V_THpの大きさ |

### NMOSとPMOSの違い

| 項目 | NMOS | PMOS |
|---|---|---|
| オンになりやすい条件 | ゲートが高い | ゲートが低い |
| 主なキャリア | 電子 | 正孔 |
| 電流の向き | ドレインからソース | ソースからドレイン |

**結論**

NMOSとPMOSは反対のゲート電圧で動作し、CMOS回路では両方を組み合わせて使う。

### MOSFETは小さな入力電力で大きな出力電流を制御する

MOSFETは、入力側のゲート・ソース間電圧`V_GS`によって、出力側のドレイン電流`I_D`を制御する部品である。
<img width="1448" height="1086" alt="image" src="https://github.com/user-attachments/assets/c1049a97-c8ce-4e0b-9a14-c446d9136ecd" />

```text
入力側                       出力側

ゲート電圧 V_GS              ドレイン電流 I_D
ゲート電流 I_G ≈ 0     →     ドレイン電圧 V_DS
        制御                    電力を扱う
```

| 側   | 電圧     | 電流        | 役割          |
| --- | ------ | --------- | ----------- |
| 入力側 | `V_GS` | `I_G ≈ 0` | MOSFETを制御する |
| 出力側 | `V_DS` | `I_D`     | 負荷へ電力を供給する  |




### なぜ省エネルギーなのか

MOSFETのゲートは酸化膜によって絶縁されているため、理想的にはゲートへ直流電流が流れない。

```text
I_G ≈ 0
```

したがって、入力側で消費される直流電力は非常に小さい。

```text
P_IN = V_GS × I_G ≈ 0
```

小さな入力電力で、出力側の大きなドレイン電流を制御できることがMOSFETの特徴である。


### 結論

```text
MOSFETは、ほとんど電流を必要としないゲート電圧V_GSによって、
出力側のドレイン電流I_Dを制御できる。
```

```text
V_GS：MOSFETを制御する入力電圧
V_DS：出力側に加わる電圧
I_D ：MOSFETによって制御される出力電流
```

MOSFETは、小さな入力電力で大きな出力電流を制御できる。MOSFETは省エネ。

## 1.5　しきい値電圧とオーバードライブ電圧

### しきい値電圧

しきい値電圧は、MOSFETのゲートにどの程度の電圧を加えると、チャネルが形成されて電流が流れやすくなるかを示す目安である。

* `V_THn`：NMOSのしきい値電圧
* `V_THp`：PMOSのしきい値電圧

一般に、NMOSのしきい値電圧は正、PMOSのしきい値電圧は負の値で表される。

```text
V_THn > 0

V_THp < 0
```

例えば、次のような値を考える。

```text
V_THn = 0.5 V

V_THp = -0.5 V
```

NMOSでは、ゲート電圧がソース電圧より高くなり、次の条件を満たすと電流が流れやすくなる。

```text
V_GS > V_THn
```

PMOSでは、ソース電圧がゲート電圧より高くなり、次の条件を満たすと電流が流れやすくなる。

```text
V_SG > abs(V_THp)
```

ここで、`abs(V_THp)`はPMOSのしきい値電圧の絶対値を表す。

しきい値電圧より低い場合でも、実際には微小な電流が流れる。この電流をサブスレッショルド電流という。そのため、しきい値電圧は「完全に電流が0から流れ始める境界」ではなく、「MOSFETにチャネルが形成され、電流が大きくなり始める目安」と考える。

また、しきい値電圧は、製造ばらつき、温度、ソースと基板の電位差などによって変化する。本章では、まず一定値として扱う。

### オーバードライブ電圧

オーバードライブ電圧は、ゲートに加えた電圧がしきい値電圧をどれだけ超えているかを表す。

しきい値を超えた部分が、MOSFETに電流を流すために実際に使われる電圧と考えられる。

### NMOSのオーバードライブ電圧

NMOSでは、オーバードライブ電圧を次のように定義する。

```text
V_OV = V_GS - V_THn
```

例えば、次の条件を考える。

```text
V_GS  = 0.8 V
V_THn = 0.5 V
```

このとき、オーバードライブ電圧は次のようになる。

```text
V_OV
= V_GS - V_THn
= 0.8 - 0.5
= 0.3 V
```

これは、ゲート・ソース間電圧が、しきい値電圧を`0.3 V`だけ超えていることを表す。

### PMOSのオーバードライブ電圧

PMOSでは、ソース・ゲート間電圧`V_SG`を使う。

```text
V_OVp = V_SG - abs(V_THp)
```

例えば、次の条件を考える。

```text
V_SG  = 0.9 V
V_THp = -0.5 V
```

しきい値電圧の絶対値は次のようになる。

```text
abs(V_THp) = 0.5 V
```

したがって、PMOSのオーバードライブ電圧は次のようになる。

```text
V_OVp
= V_SG - abs(V_THp)
= 0.9 - 0.5
= 0.4 V
```

### 各電圧の意味

| 記号           | 意味                 |
| ------------ | ------------------ |
| `V_THn`      | NMOSのしきい値電圧        |
| `V_THp`      | PMOSのしきい値電圧。通常は負の値 |
| `abs(V_THp)` | PMOSのしきい値電圧の絶対値    |
| `V_OV`       | NMOSのオーバードライブ電圧    |
| `V_OVp`      | PMOSのオーバードライブ電圧    |
| `V_GS`       | NMOSのゲート・ソース間電圧    |
| `V_SG`       | PMOSのソース・ゲート間電圧    |

### オーバードライブ電圧とドレイン電流

長チャネルMOSFETの飽和領域を簡単な式で表すと、NMOSのドレイン電流は次のようになる。

```text
I_D
≈
(1/2)μnCox(W/L)V_OV^2
```

したがって、トランジスタ寸法`W/L`が同じ場合、`V_OV`が大きくなるとドレイン電流はおおよそ2乗に比例して増加する。

```text
V_OVが大きい
→ チャネルが強く形成される
→ I_Dが大きくなる
```

### オーバードライブ電圧と飽和条件

MOSFETを増幅回路として使用するときは、一般に飽和領域で動作させる。

NMOSの飽和条件は、次のように表せる。

```text
V_DS >= V_OV
```

PMOSの飽和条件は、次のようになる。

```text
V_SD >= V_OVp
```

したがって、`V_OV`を大きくすると電流を流しやすくなる一方、飽和領域を維持するために必要なドレイン・ソース間電圧も大きくなる。

```text
V_OVが大きい
→ 電流を流しやすい
→ 必要なV_DSも大きい
→ 使用できる出力電圧範囲が狭くなる
```

この「回路を正しく動作させるために必要な電圧の余裕」を、電圧ヘッドルームという。

### 回路設計における意味

オーバードライブ電圧には、次のようなトレードオフがある。

```text
V_OVを大きくする
→ 同じW/LならI_Dが増える
→ 必要な電圧ヘッドルームが大きくなる
→ 低電源電圧では使いにくくなる
```

一方、同じドレイン電流で比較すると、相互コンダクタンスは次の式で表される。

```text
g_m = 2I_D / V_OV
```

したがって、同じ`I_D`であれば、`V_OV`を小さくした方が`g_m`は大きくなる。

```text
同じI_Dの場合

V_OVが小さい
→ g_mが大きい
→ 増幅能力が高くなる
→ 必要なW/Lは大きくなる
```

オーバードライブ電圧は、単に大きくすればよいものではない。電流、利得、消費電力、トランジスタ寸法、出力電圧範囲を考えながら決める必要がある。

```text
しきい値電圧
＝ MOSFETが電流を流しやすくなる基準

オーバードライブ電圧
＝ ゲート電圧がしきい値を超えた量
```

**結論**

オーバードライブ電圧は、MOSFETがどれくらい強く動作しているかを表す。

## 1.6　線形領域と飽和領域

### NMOSの動作領域

| 動作領域 | 条件 | 主な使い方 |
|---|---|---|
| カットオフ領域 | V_GS ≤ V_THn | オフ状態 |
| 線形領域 | V_GS > V_THn、V_DS < V_OV | スイッチ、可変抵抗 |
| 飽和領域 | V_GS > V_THn、V_DS ≥ V_OV | 増幅回路、電流源 |

| 記号 | 意味 |
|---|---|
| V_DS | NMOSのドレイン・ソース間電圧 |
| V_OV | NMOSのオーバードライブ電圧 |

アナログ増幅回路では、MOSFETを主に飽和領域で使う。

PMOSではV_SGとV_SDを使い、V_SDがV_OVp以上なら飽和領域になる。

~~~text
PMOSの飽和条件：V_SD ≥ V_OVp
~~~


**結論**

増幅回路では、MOSFETが飽和領域に入っていることを確認する。

## 1.7　ドレイン電流

### 飽和領域のドレイン電流

長チャネルNMOSの基本式は次のようになる。

~~~text
I_D = (1 / 2) × k_n × V_OV^2
~~~

k_nは、製造プロセスとMOSFETの大きさをまとめた値である。

~~~text
k_n = μ_n × C_ox × (W / L)
~~~

| 記号 | 意味 |
|---|---|
| I_D | ドレイン電流 |
| k_n | NMOSの電流の流しやすさを表す係数 |
| μ_n | 電子の移動度 |
| C_ox | 単位面積当たりのゲート酸化膜容量 |
| W | MOSFETのチャネル幅 |
| L | MOSFETのチャネル長 |
| V_OV | オーバードライブ電圧 |

式から、次の関係が分かる。

- Wを大きくすると、I_Dは増える
- Lを長くすると、I_Dは減る
- V_OVを大きくすると、I_Dは増える

実際には、V_DSが増えるとI_Dも少し増える。この現象をチャネル長変調という。

## 1.8　相互コンダクタンス `g_m`

### MOSFETは電圧で電流を変える

ここでは、NMOSを例に考える。

NMOSでは、ゲート・ソース間電圧`V_GS`を大きくすると、ドレイン電流`I_D`が増える。

```text
入力：ゲート・ソース間電圧 V_GS
              ↓
            NMOS
              ↓
出力：ドレイン電流 I_D
```

つまりMOSFETは、入力側の電圧によって、出力側の電流を制御する素子である。

例えば、`V_GS`を少し上げたとき、`I_D`が大きく増えるMOSFETもあれば、あまり増えないMOSFETもある。

```text
V_GSを少し変えたとき
I_Dがどれくらい変わるか
```

この「ゲート電圧に対するドレイン電流の変わりやすさ」を表す量が、相互コンダクタンス`g_m`である。

---

### なぜ「相互コンダクタンス」と呼ぶのか

抵抗の逆数をコンダクタンスという。コンダクタンスは、電圧を加えたときに電流がどれだけ流れやすいかを表す。

```text
コンダクタンス
=
電流
/
電圧
```

相互コンダクタンスでは、同じ場所の電圧と電流ではなく、入力側のゲート電圧と、出力側のドレイン電流の関係を見る。

```text
入力側の電圧 V_GS
        ↓
出力側の電流 I_D
```

入力側と出力側という異なる部分の関係を表すため、「相互コンダクタンス」と呼ばれる。

---

### まずは変化量で考える

ゲート・ソース間電圧を`ΔV_GS`だけ変えたとき、ドレイン電流が`ΔI_D`だけ変化したとする。

このとき、`g_m`は次のように考えられる。

```text
g_m ≈ ΔI_D / ΔV_GS
```

この式は、ゲート電圧を1 V変化させたとき、ドレイン電流が何A変化するかを表している。

| 記号      | 意味               |
| ------- | ---------------- |
| `ΔV_GS` | ゲート・ソース間電圧の変化量   |
| `ΔI_D`  | ドレイン電流の変化量       |
| `g_m`   | 電圧変化を電流変化へ変換する割合 |

例えば、`V_GS`を`10 mV`増やしたとき、`I_D`が`10 μA`増えたとする。

```text
ΔV_GS = 10 mV
ΔI_D  = 10 μA
```

これらの値を`g_m`の式へ代入する。

```text
g_m
≈
10 μA / 10 mV
```

この計算結果は次のようになる。

```text
g_m ≈ 1 mS
```

`1 mS`は、次の関係を表している。

```text
1 mS
=
1 mA / 1 V
=
1 μA / 1 mV
```

したがって、`g_m = 1 mS`のMOSFETでは、ゲート電圧が`1 mV`変化すると、ドレイン電流が約`1 μA`変化する。

```text
V_GSが1 mV増える
        ↓
I_Dが約1 μA増える
```

---

### `g_m`が大きいとはどういうことか

`g_m`が大きいMOSFETは、ゲート電圧の小さな変化に対して、ドレイン電流が大きく変化する。

| `g_m` | MOSFETの動作            |
| ----- | -------------------- |
| 大きい   | 小さな入力電圧で電流が大きく変わる    |
| 小さい   | 入力電圧を変えても電流があまり変わらない |

増幅回路では、小さな入力電圧から大きな電流変化を作りたい。そのため、一般に`g_m`が大きいほど増幅しやすい。

ただし、`g_m`を大きくするために電流を増やすと、消費電力も増える。

```text
電流を増やす
      ↓
g_mが大きくなる
      ↓
増幅しやすくなる
      ↓
消費電力も増える
```

---

### `g_m`はグラフの傾きである

MOSFETの`I_D`と`V_GS`の関係をグラフにすると、直線ではなく曲線になる。

横軸を`V_GS`、縦軸を`I_D`とする。

```text
横軸：V_GS
縦軸：I_D
```

直線であれば、どの場所でも傾きは同じである。しかし、MOSFETの特性は曲線なので、傾きは動作する場所によって変わる。

```text
V_GSが比較的小さい
        ↓
グラフの傾きが小さい
        ↓
g_mが小さい
```

```text
V_GSが比較的大きい
        ↓
グラフの傾きが大きい
        ↓
g_mが大きい
```

この関係は、長チャネルMOSFETの平方則モデルを使った場合に成り立つ。

---

### 動作点とは何か

MOSFETを増幅回路として使うときは、入力信号を加える前から一定の電圧と電流を与えておく。

この基準となる電圧と電流の組を動作点という。

```text
動作点
=
信号がないときの基準電圧と基準電流
```

例えば、次の状態を動作点とする。

```text
V_GSQ = 0.70 V
I_DQ  = 100 μA
```

添字`Q`は、動作点を表している。

実際のゲート・ソース間電圧は、動作点の直流電圧と、その周りの小さな電圧変化を足したものになる。

```text
V_GS = V_GSQ + v_gs
```

この式で、`V_GSQ`は基準となる直流電圧、`v_gs`は入力信号による小さな電圧変化である。

ドレイン電流も同じように考えられる。

```text
I_D = I_DQ + i_d
```

この式で、`I_DQ`は動作点の直流電流、`i_d`は入力信号によって生じる小さな電流変化である。

| 記号      | 意味             |
| ------- | -------------- |
| `V_GSQ` | 動作点のゲート・ソース間電圧 |
| `I_DQ`  | 動作点のドレイン電流     |
| `v_gs`  | 動作点の周りの小さな電圧変化 |
| `i_d`   | 動作点の周りの小さな電流変化 |

`g_m`は、この動作点における曲線の傾きである。

<img width="1672" height="941" alt="image" src="https://github.com/user-attachments/assets/3c3fd38b-905e-4ee2-ad82-a7d544ab96bb" />

---

### なぜ微分を使うのか

最初に、変化量を使って次のように表した。

```text
g_m ≈ ΔI_D / ΔV_GS
```

しかし、この式で求められるのは、ある範囲における平均的な傾きである。

MOSFETの特性は曲線なので、変化させる範囲が広いと、動作点における正確な傾きとは異なる値になる。

そこで、`ΔV_GS`を非常に小さくして、動作点のすぐ近くの傾きを求める。

```text
g_m
=
ΔV_GSを0へ近づけたときの
ΔI_D / ΔV_GS
```

これが微分の考え方である。

1つの変数だけを考える場合は、次のように書ける。

```text
g_m = dI_D / dV_GS
```

この式は、`I_D–V_GS`グラフの動作点に引いた接線の傾きを表している。

```text
曲線上の動作点
        ↓
その場所に接線を引く
        ↓
接線の傾きがg_m
```

---

### なぜ偏微分を使うのか

ドレイン電流`I_D`は、`V_GS`だけで決まるわけではない。実際には、ドレイン・ソース間電圧`V_DS`などの影響も受ける。

```text
I_D = I_D(V_GS, V_DS)
```

この式は、`I_D`が`V_GS`と`V_DS`の両方によって決まることを表している。

`g_m`では、`V_DS`を一定にして、`V_GS`だけを変化させたときの`I_D`の変化を見る。

複数の変数のうち、1つだけを変化させる微分を偏微分という。

```text
g_m
=
(∂I_D / ∂V_GS)
```

この式の`∂`は、ほかの変数を一定にして、指定した変数だけを変化させることを表している。

より正確には、次のように書く。

```text
g_m
=
(∂I_D / ∂V_GS)
V_DSを一定にして動作点で求める
```

したがって、`g_m`は「`V_DS`を固定した状態で、動作点の`V_GS`を少し変えたときの`I_D`の変化率」である。

---

### 平方則モデルから`g_m`を求める

飽和領域にある長チャネルNMOSのドレイン電流は、次の式で表される。

```text
I_D
=
(1 / 2) × k_n × (V_GS - V_THn)^2
```

この式は、しきい値電圧を超えた分の電圧によって、ドレイン電流が決まることを表している。

| 記号      | 意味                 |
| ------- | ------------------ |
| `I_D`   | ドレイン電流             |
| `k_n`   | NMOSの電流の流しやすさを表す係数 |
| `V_GS`  | ゲート・ソース間電圧         |
| `V_THn` | NMOSのしきい値電圧        |

`k_n`は、製造プロセスとMOSFETの大きさによって決まる。

```text
k_n = μ_n × C_ox × (W / L)
```

この式は、電子の移動度`μ_n`、ゲート酸化膜容量`C_ox`、MOSFETの寸法比`W/L`によって、電流の流しやすさが決まることを表している。

ここで、オーバードライブ電圧`V_OV`を使う。

```text
V_OV = V_GS - V_THn
```

`V_OV`は、ゲート・ソース間電圧がしきい値電圧をどれだけ超えているかを表す。

この定義を使うと、ドレイン電流の式は次のようになる。

```text
I_D
=
(1 / 2) × k_n × V_OV^2
```

この式から、ドレイン電流は`V_OV`の2乗に比例することが分かる。

---

### ドレイン電流の式を微分する

`g_m`は、`I_D`を`V_GS`で微分した値である。

```text
g_m = ∂I_D / ∂V_GS
```

2乗の式を微分するときは、次の関係を使う。

```text
x^2をxで微分すると2x
```

ドレイン電流の式を`V_GS`で微分する。

```text
I_D
=
(1 / 2) × k_n × (V_GS - V_THn)^2
```

`(V_GS - V_THn)^2`を微分すると、`2 × (V_GS - V_THn)`になる。

したがって、次の式が得られる。

```text
g_m
=
k_n × (V_GS - V_THn)
```

ここで、`V_GS - V_THn`は`V_OV`である。

```text
g_m = k_n × V_OV
```

この式は、平方則モデルでは、`V_OV`が大きいほど`g_m`が大きくなることを表している。

---

### `I_D`と`V_OV`から`g_m`を求める

ドレイン電流は次の式で表される。

```text
I_D
=
(1 / 2) × k_n × V_OV^2
```

この式を2倍する。

```text
2 × I_D
=
k_n × V_OV^2
```

両辺を`V_OV`で割る。

```text
2 × I_D / V_OV
=
k_n × V_OV
```

右辺の`k_n × V_OV`は`g_m`であるため、次の式が得られる。

```text
g_m = 2 × I_D / V_OV
```

この式は、動作点のドレイン電流`I_D`とオーバードライブ電圧`V_OV`が分かっているときに使いやすい。

この式から、次のことが分かる。

* 同じ`V_OV`なら、`I_D`が大きいほど`g_m`は大きい
* 同じ`I_D`なら、`V_OV`が小さいほど`g_m`は大きい

---

### `g_m`の計算例

次の動作点を考える。

```text
I_D = 100 μA
V_OV = 0.20 V
```

このMOSFETには直流で`100 μA`が流れ、ゲート電圧はしきい値を`0.20 V`超えている。

`g_m`を求める。

```text
g_m = 2 × I_D / V_OV
```

数値を代入する。

```text
g_m
=
2 × 100 μA / 0.20 V
```

計算すると、次のようになる。

```text
g_m = 1.0 mS
```

この結果は、動作点の周りでゲート電圧が`1 mV`変化すると、ドレイン電流が約`1 μA`変化することを表している。

---

### 小さな入力電圧から電流変化を求める

動作点の周りに加わる小さなゲート・ソース間電圧を`v_gs`とする。

このときに生じるドレイン電流の小さな変化を`i_d`とする。

両者の関係は次のようになる。

```text
i_d = g_m × v_gs
```

この式は、入力電圧`v_gs`を`g_m`倍すると、出力電流の変化`i_d`になることを表している。

例えば、次の値を考える。

```text
g_m = 1.0 mS
v_gs = 1 mV
```

数値を代入する。

```text
i_d
=
1.0 mS × 1 mV
```

計算結果は次のようになる。

```text
i_d = 1.0 μA
```

したがって、ゲート電圧が`1 mV`変化すると、ドレイン電流は`1 μA`変化する。

```text
小さな入力電圧 v_gs
          ↓
     g_mで変換
          ↓
小さな出力電流 i_d
```

---

### `g_m`は電圧利得ではない

`g_m`が直接表すのは、入力電圧から出力電流への変換である。

```text
入力電圧
    ↓
  g_m
    ↓
出力電流
```

したがって、`g_m`だけでは出力電圧は得られない。

出力電流を出力電圧へ変えるには、出力ノードに抵抗が必要になる。

```text
v_out = -i_d × R_out
```

この式は、電流変化`i_d`が出力抵抗`R_out`へ流れることで、出力電圧`v_out`が変化することを表している。

負号は、ソース接地増幅回路で入力と出力が反対方向に変化することを表している。

```text
ゲート電圧が上がる
        ↓
ドレイン電流が増える
        ↓
負荷の電圧降下が増える
        ↓
出力電圧が下がる
```

先ほどの関係を使う。

```text
i_d = g_m × v_gs
```

これを出力電圧の式へ代入する。

```text
v_out
=
-g_m × v_gs × R_out
```

入力電圧に対する出力電圧の比が、電圧利得`A_v`である。

```text
A_v = v_out / v_gs
```

したがって、ソース接地増幅回路の電圧利得は次のようになる。

```text
A_v ≈ -g_m × R_out
```

この式は、`g_m`と出力抵抗`R_out`の両方が大きいほど、電圧利得が大きくなることを表している。

---

### 電圧利得の計算例

次の値を考える。

```text
g_m = 1.0 mS
R_out = 100 kΩ
```

電圧利得を求める。

```text
A_v
≈
-g_m × R_out
```

数値を代入する。

```text
A_v
≈
-1.0 mS × 100 kΩ
```

計算すると、次のようになる。

```text
A_v ≈ -100
```

この結果は、入力電圧の変化を約100倍にして、反対方向の出力電圧を作ることを表している。

入力電圧が`1 mV`増えた場合、出力電圧の変化は次のようになる。

```text
v_out
=
-100 × 1 mV
=
-100 mV
```

したがって、入力が`1 mV`上がると、出力は約`100 mV`下がる。

---

### 設計では何を考えるのか

`g_m`を大きくすると増幅しやすくなるが、ほかの性能も変化する。

| 変更           | `g_m`への影響   | 注意点            |
| ------------ | ----------- | -------------- |
| `I_D`を増やす    | 大きくなる       | 消費電力が増える       |
| `V_OV`を小さくする | 同じ電流なら大きくなる | 必要な`W/L`が大きくなる |
| `W`を大きくする    | 同じ電圧なら大きくなる | 面積と寄生容量が増える    |

したがって、設計では`g_m`だけを大きくするのではなく、利得、速度、消費電力、面積のバランスを考える必要がある。

---

### まとめ

| 段階 | 内容                                  |
| -- | ----------------------------------- |
| 1  | `V_GS`を変えると`I_D`が変わる                |
| 2  | 電流の変わりやすさを`g_m`で表す                  |
| 3  | `g_m`は動作点における`I_D–V_GS`曲線の傾きである     |
| 4  | `V_DS`を一定にして考えるため偏微分を使う             |
| 5  | 平方則モデルでは`g_m = 2I_D / V_OV`となる      |
| 6  | 小さな入力電圧は`i_d = g_m v_gs`によって電流変化になる |
| 7  | 出力抵抗によって電流変化が出力電圧へ変わる               |
| 8  | ソース接地回路の利得は`A_v ≈ -g_mR_out`となる     |

**結論**

相互コンダクタンス`g_m`は、動作点において「ゲート電圧のわずかな変化がドレイン電流にどれだけ影響するか」を表す量である。

MOSFET増幅は、まず`g_m`で電圧を電流に変え、その電流を抵抗で電圧に変換することで成り立っている。

## 1.9　出力抵抗 r_o

### MOSFETは完全な電流源ではない
<img width="315" height="427" alt="image" src="https://github.com/user-attachments/assets/7be0e318-d4e5-4d93-9fd0-ddaa1f3a4584" />

理想的な電流源では、出力電圧が変化しても電流は変化しない。

実際のMOSFETでは、飽和領域であっても、V_DSが変化するとI_Dもわずかに変化する。この主な原因がチャネル長変調である。

この影響を小信号の抵抗として表したものが、出力抵抗r_oである。

ただし、r_oは回路に実際に接続されている抵抗ではない。V_DSの変化によってI_Dがどの程度変化するかを、抵抗として表した小信号モデルである。
<img width="1672" height="941" alt="image" src="https://github.com/user-attachments/assets/a371a7ec-7294-4656-a969-0ce4e9fa19e2" />

### 変化量から出力抵抗を考える

V_DSがΔV_DSだけ変化したとき、I_DがΔI_Dだけ変化したとする。このとき、出力抵抗r_oは次のように表される。

```text
r_o ≈ ΔV_DS / ΔI_D
```

| 記号    | 意味                       |
| ----- | ------------------------ |
| ΔV_DS | ドレイン・ソース間電圧の変化量          |
| ΔI_D  | V_DSの変化によって生じるドレイン電流の変化量 |
| r_o   | MOSFETの小信号出力抵抗           |

同じ大きさのΔV_DSを加えた場合でも、I_Dがほとんど変化しなければ、ΔI_Dは小さくなる。

```text
r_o ≈ ΔV_DS / ΔI_D
```

この式から、ΔI_Dが小さいほどr_oは大きくなることが分かる。

### 出力コンダクタンスg_o

V_DSに対するI_Dの変化の割合を先に求める場合は、出力コンダクタンスg_oを用いる。

```text
g_o = ∂I_D / ∂V_DS　（V_GSを一定にする）
```

g_oは、V_GSを一定にしたままV_DSだけを変化させたとき、I_Dがどの程度変化するかを表している。言い換えると、V_DSとI_Dの関係を表すグラフにおける傾きである。

出力抵抗r_oは、g_oの逆数である。

```text
r_o = 1 / g_o
```

| 記号  | 意味                     |
| --- | ---------------------- |
| g_o | 出力電圧の変化を出力電流の変化に変換する割合 |
| r_o | g_oの逆数で表される小信号出力抵抗     |

g_oが小さいということは、V_DSが変化してもI_Dがあまり変化しないということである。そのため、g_oが小さいほどr_oは大きくなる。

g_mとg_oは、どちらもI_Dを電圧で偏微分することによって求められる。ただし、変化させる電圧と一定にする電圧が異なる。

| パラメータ | 変化させる電圧 | 一定にする電圧 |
| ----- | ------- | ------- |
| g_m   | V_GS    | V_DS    |
| g_o   | V_DS    | V_GS    |

g_mを求めるときは、V_DSを一定にしてV_GSを変化させる。一方、g_oを求めるときは、V_GSを一定にしてV_DSを変化させる。

### チャネル長変調からr_oを求める
![Uploading image.png…]()

チャネル長変調を含めたドレイン電流I_Dは、簡単には次の式で表される。

```text
I_D ≈ I_D0 × (1 + λ × V_DS)
```

| 記号   | 意味                 |
| ---- | ------------------ |
| I_D0 | チャネル長変調を無視したドレイン電流 |
| λ    | チャネル長変調係数          |
| V_DS | ドレイン・ソース間電圧        |

この式から、V_DSが大きくなると、I_Dもわずかに大きくなることが分かる。

この式をV_DSで偏微分すると、出力コンダクタンスg_oは次のように表される。

```text
g_o ≈ λ × I_D
```

出力抵抗r_oはg_oの逆数であるため、次のようになる。

```text
r_o ≈ 1 / (λ × I_D)
```

λの単位は1/Vである。

λが小さいMOSFETでは、V_DSが変化してもI_Dがあまり変化しない。そのため、λが小さいほどg_oは小さくなり、r_oは大きくなる。

### r_oの計算例

次の値を考える。

```text
λ = 0.05 / V
I_D = 100 μA
```

出力抵抗r_oは、次の式から求められる。

```text
r_o = 1 / (λ × I_D)
```

値を代入すると、次のようになる。

```text
r_o = 1 / (0.05 / V × 100 μA)
```

したがって、r_oは次の値になる。

```text
r_o = 200 kΩ
```

次に、V_DSが小信号として0.10 V変化した場合を考える。このときの電流変化ΔI_Dは、次の式で求められる。

```text
ΔI_D ≈ ΔV_DS / r_o
```

値を代入すると、次のようになる。

```text
ΔI_D ≈ 0.10 V / 200 kΩ
```

したがって、電流の変化量は次の値になる。

```text
ΔI_D ≈ 0.5 μA
```

この例では、V_DSが0.10 V変化したとき、I_Dは約0.5 μA変化することになる。

### r_oと電圧利得

MOSFET単体で得られる電圧利得の目安を固有利得という。固有利得は、g_mとr_oの積によって表される。

```text
固有利得 ≈ g_m × r_o
```

先ほどの例において、g_mとr_oが次の値であるとする。

```text
g_m = 1.0 mS
r_o = 200 kΩ
```

固有利得は次のようになる。

```text
固有利得 ≈ 1.0 mS × 200 kΩ
```

したがって、固有利得は次の値になる。

```text
固有利得 ≈ 200
```

ただし、実際の回路では、負荷抵抗や別のMOSFETのr_oが並列に接続される。そのため、実際に得られる電圧利得は、この固有利得よりも小さくなることが多い。

**結論**

出力抵抗r_oは、V_GSを一定にしたままV_DSを変化させたときのI_Dの変化から求められる小信号抵抗である。

V_DSが変化してもI_Dがほとんど変化しないMOSFETほど、r_oは大きい。r_oが大きいMOSFETは理想的な電流源に近く、高い電圧利得を得やすい。

## 1.10　MOSFETの小信号モデル

### なぜ小信号モデルを使うのか

MOSFETのI_DとV_GSの関係は曲線であり、そのままでは増幅回路の計算が複雑になる。

そこで、最初に直流電圧と直流電流で動作点を決める。その動作点の周りにある小さな変化だけを直線として考える。

この考え方を小信号モデルという。

### 直流値と小信号値

ゲート・ソース間電圧を、直流値と小信号値に分ける。

~~~text
実際のゲート・ソース間電圧 = V_GS + v_gs
~~~

ドレイン・ソース間電圧も同じように分ける。

~~~text
実際のドレイン・ソース間電圧 = V_DS + v_ds
~~~

ドレイン電流は、直流値と小信号値に分ける。

~~~text
実際のドレイン電流 = I_D + i_d
~~~

| 大文字 | 小文字 | 意味 |
|---|---|---|
| V_GS | v_gs | ゲート・ソース間電圧の動作点と小さな変化 |
| V_DS | v_ds | ドレイン・ソース間電圧の動作点と小さな変化 |
| I_D | i_d | ドレイン電流の動作点と小さな変化 |

大文字は動作点を表し、小文字は動作点からの小さな変化を表す。

### 曲線を直線で近似する

I_Dは、V_GSとV_DSなどによって決まる。

~~~text
I_D = I_D(V_GS, V_DS)
~~~

動作点の周りでV_GSがv_gs、V_DSがv_dsだけ変化したとする。

非常に小さな変化だけを考えると、ドレイン電流の変化は、それぞれの偏微分を使って次のように近似できる。

~~~text
i_d
≈
(∂I_D / ∂V_GS) × v_gs
+
(∂I_D / ∂V_DS) × v_ds
~~~

ここで、2つの偏微分をg_mとg_oへ置き換える。

~~~text
g_m = ∂I_D / ∂V_GS
~~~

~~~text
g_o = ∂I_D / ∂V_DS
~~~

したがって、小信号ドレイン電流は次のようになる。

~~~text
i_d = g_m × v_gs + g_o × v_ds
~~~

g_o = 1 / r_oなので、次の形でも表せる。

~~~text
i_d = g_m × v_gs + v_ds / r_o
~~~

| 項 | 意味 |
|---|---|
| g_m × v_gs | ゲート電圧の変化によって生じる電流変化 |
| v_ds / r_o | ドレイン電圧の変化によって生じる電流変化 |
| i_d | 2つの変化を合わせた小信号ドレイン電流 |

これは、曲線を動作点の近くで直線に置き換えた式である。

### 基本的な小信号等価回路
<img width="1672" height="941" alt="image" src="https://github.com/user-attachments/assets/b4058468-2ec3-418c-baa4-79cca4c79d87" />

低周波におけるMOSFETの基本的な小信号モデルは、次の3つで考えられる。

1. ゲートへ流れる電流はほぼ0
2. ドレインとソースの間に制御電流源g_m × v_gsがある
3. ドレインとソースの間に出力抵抗r_oがある

| 要素 | 役割 |
|---|---|
| 開放されたゲート | MOSFETの高い入力抵抗を表す |
| g_m × v_gs | 入力電圧で制御される出力電流を表す |
| r_o | V_DSによるI_Dの変化を表す |


### 小信号モデルを使う手順

1. 直流のV_GS、V_DS、I_Dを求める
2. MOSFETが飽和領域にあることを確認する
3. 動作点からg_mとr_oを求める
4. MOSFETをg_m × v_gsとr_oのモデルへ置き換える
5. 小信号回路から電圧利得を求める

小信号モデルを使えるのは、信号の変化が動作点の周りで十分に小さい場合である。信号が大きく、MOSFETが別の動作領域へ移る場合は、この近似をそのまま使えない。



**結論**

小信号モデルは、非線形なMOSFETを動作点の近くで直線として扱う方法である。g_mは入力電圧による電流変化を表し、r_oは出力電圧による電流変化を表す。この2つを使うと、MOSFET増幅回路の電圧利得を求められる。

## 第1章のまとめ

- オペアンプは、2つの入力電圧の差を増幅する
- 負帰還によって、抵抗の比から利得を決められる
- 反転増幅では入力と出力の向きが反対になる
- 非反転増幅では入力と出力が同じ方向に変化する
- CMOSオペアンプは、NMOSとPMOSで作られる
- 増幅に使うMOSFETは、主に飽和領域で動作させる
- g_mは入力電圧を電流変化へ変換する能力を表す
- r_oはMOSFETが電流源にどれだけ近いかを表す
- 電圧利得は、おおよそg_mと出力抵抗の積で決まる


# 第2章　二段構成オペアンプを構成する基本回路

## Basic Circuits for a Two-Stage CMOS Operational Amplifier

二段構成CMOSオペアンプは、ソース接地回路、電流源、電流ミラー、差動対を組み合わせて作られる。

この章では、それぞれの回路がどのように電圧と電流を変化させるかを確認する。最後に、各段の電圧利得を倍率とdBの両方で表す。

---
## 2.1　ソース接地増幅回路

### 入力と反対向きの出力を作る

ソース接地増幅回路では、入力をMOSFETのゲートへ加え、出力をドレインから取り出す。ソースは小信号的にGNDへ接続される。
<img width="488" height="632" alt="image" src="https://github.com/user-attachments/assets/46ac4529-0d46-4592-97f3-c5dbd5084c4a" />

```text
入力：ゲート電圧
出力：ドレイン電圧
```

NMOSでは、次の順番で信号が変化する。

```text
ゲート電圧が上がる
        ↓
ドレイン電流が増える
        ↓
負荷の電圧降下が増える
        ↓
出力電圧が下がる
```

したがって、入力と出力は反対方向に変化する。これを反転増幅という。

### 直流動作点と小信号

MOSFETには、直流のバイアス電圧と、その周りで変化する小さな信号が加わる。

```text
V_GS,total = V_GS + v_gs
I_D,total  = I_D + i_d
V_OUT,total = V_OUT + v_out
```

| 記号                   | 意味          |
| -------------------- | ----------- |
| `V_GS`、`I_D`、`V_OUT` | 直流動作点の電圧と電流 |
| `v_gs`、`i_d`、`v_out` | 動作点周辺の小さな変化 |

小信号のゲート電圧とドレイン電流の関係は、次のようになる。

```text
i_d = g_m × v_gs
```

`g_m`は、入力電圧の変化をドレイン電流の変化へ変換する相互コンダクタンスである。

### 電圧利得

ドレイン電流の変化が出力抵抗`R_out`へ流れると、出力電圧が変化する。

```text
v_out = -i_d × R_out
```

`i_d = g_m × v_gs`を代入すると、次のようになる。

```text
v_out = -g_m × v_gs × R_out
```

したがって、電圧利得は次のようになる。

```text
A_v = v_out / v_gs
```

```text
A_v ≈ -g_m × R_out
```

マイナス記号は、入力と出力が反対方向に変化することを表す。

### 抵抗負荷の場合
<img width="488" height="632" alt="image" src="https://github.com/user-attachments/assets/883cc7f0-7557-4c64-99c6-b9fa31b94312" />

ドレインに抵抗`R_D`を接続し、MOSFETの出力抵抗を`r_o`とすると、出力抵抗は次のようになる。

```text
R_out = parallel(R_D, r_o)
```

```text
R_out = R_D × r_o / (R_D + r_o)
```

したがって、電圧利得は次のようになる。

```text
A_v ≈ -g_m × parallel(R_D, r_o)
```

`r_o`が`R_D`より十分大きい場合は、次のように近似できる。

```text
A_v ≈ -g_m × R_D
```

### 入力抵抗と出力抵抗

MOSFETのゲートには、理想的には直流電流が流れない。そのため、入力抵抗は非常に大きい。

```text
R_in ≈ 無限大
```

出力抵抗は、ドレインから回路内部を見た抵抗である。

```text
R_out = parallel(R_D, r_o)
```

| 特性   | ソース接地増幅回路  |
| ---- | ---------- |
| 入力抵抗 | 大きい        |
| 出力抵抗 | 比較的大きい     |
| 電圧利得 | 大きくできる     |
| 位相   | 入力に対して反転する |

### 飽和領域の確認

増幅に使用するNMOSは、飽和領域で動作させる。

```text
V_DS ≥ V_OV
```

```text
V_OV = V_GS - V_THn
```

ソースがGNDへ接続されている場合は、`V_DS = V_OUT`となるため、次の条件が必要である。

```text
V_OUT ≥ V_OV
```

出力電圧が下がりすぎるとMOSFETが線形領域へ入り、電圧利得が低下して波形がひずむ。

**結論**

ソース接地増幅回路は、ゲート電圧の変化をドレイン電流へ変換し、出力抵抗によって出力電圧へ変換する。

```text
入力電圧
   ↓ g_m
電流変化
   ↓ R_out
出力電圧
```

電圧利得は`A_v ≈ -g_mR_out`であり、入力と出力は反対方向に変化する。

## 2.2　電流源負荷と能動負荷

### MOSFETを負荷として使う

ICの中に大きな抵抗を作ると、多くの面積が必要になる。そこで、飽和領域のMOSFETを電流源や負荷として使用する。

MOSFETで作られた負荷を能動負荷という。電流源負荷は、能動負荷の代表的な構成である。

| 負荷    | 特徴                    |
| ----- | --------------------- |
| 抵抗負荷  | 分かりやすいが、大きな抵抗は面積を使う   |
| 能動負荷  | 小さな面積で大きな出力抵抗を作りやすい   |
| 電流源負荷 | バイアス電流を決めながら能動負荷として働く |

### PMOS電流源負荷

NMOSを増幅素子、PMOSを電流源負荷として使う場合を考える。

<img width="700" height="948" alt="image" src="https://github.com/user-attachments/assets/86a21784-4ae4-4595-8327-6726b76a3b4e" />


直流動作点では、NMOSとPMOSにほぼ同じ電流が流れる。

```text
I_Dn ≈ abs(I_Dp)
```

入力電圧が上がるとNMOSの電流が増加する。出力ノードからGNDへ引き込む電流が増えるため、出力電圧は低下する。

したがって、PMOS電流源負荷を使用しても、ソース接地増幅回路の出力は反転する。

### 能動負荷で利得が大きくなる理由

飽和領域のMOSFETは、ドレイン側から見ると大きな出力抵抗`r_o`を持つ。

```text
r_o ≈ 1 / (λ × I_D)
```

NMOSとPMOSが同じ出力ノードへ接続される場合、出力抵抗は次のようになる。

```text
R_out ≈ parallel(r_on, r_op)
```

```text
R_out ≈ r_on × r_op / (r_on + r_op)
```

| 記号     | 意味        |
| ------ | --------- |
| `r_on` | NMOSの出力抵抗 |
| `r_op` | PMOSの出力抵抗 |
| `λ`    | チャネル長変調係数 |

電圧利得は次のようになる。

```text
A_v ≈ -g_mn × parallel(r_on, r_op)
```

能動負荷は大きな`R_out`を作りやすいため、抵抗負荷よりも大きな電圧利得を得やすい。

### 出力電圧の範囲

NMOSとPMOSの両方を飽和領域に保つ必要がある。

NMOSの飽和条件は、次のようになる。

```text
V_OUT ≥ V_OVn
```

PMOSの飽和条件は、次のようになる。

```text
V_DD - V_OUT ≥ V_OVp
```

したがって、増幅できる出力電圧の範囲は、おおよそ次のようになる。

```text
V_OVn ≤ V_OUT ≤ V_DD - V_OVp
```

出力電圧が下がりすぎるとNMOSが線形領域へ入り、上がりすぎるとPMOSが線形領域へ入る。どちらの場合も出力抵抗と電圧利得が低下し、波形がひずむ。

### 能動負荷の特徴

| 長所                | 短所              |
| ----------------- | --------------- |
| 小さな面積で大きな出力抵抗を作れる | 飽和領域を保つための電圧が必要 |
| 大きな電圧利得を得やすい      | 出力電圧範囲が制限される    |
| バイアス電流を設定できる      | 素子のばらつきの影響を受ける  |

**結論**

能動負荷は、MOSFETの大きな出力抵抗を利用して、増幅回路の電圧利得を高くする。

```text
A_v ≈ -g_mn × parallel(r_on, r_op)
```

ただし、高い利得を得るには、NMOSとPMOSの両方が飽和領域に入る出力電圧範囲を確保する必要がある。


## 2.3　NMOS・PMOS電流ミラー

### 基準電流をコピーする

<img width="1657" height="949" alt="image" src="https://github.com/user-attachments/assets/f2925393-1ad7-486c-8782-c0f9985942b5" />

電流ミラーは、基準となる電流を別の回路へコピーする。

基本的な動作は次のようになる。

1. 基準側MOSFETのゲートとドレインを接続する
2. 基準電流I_REFによってゲート電圧が決まる
3. 同じゲート電圧を出力側MOSFETへ加える
4. 出力側にI_OUTが流れる

ゲートとドレインを接続することをダイオード接続という。

同じ種類、同じ大きさのMOSFETを使う場合は、次のようになる。

~~~text
I_OUT ≈ I_REF
~~~

| 記号 | 意味 |
|---|---|
| I_REF | 基準側に流す電流 |
| I_OUT | 出力側へコピーされる電流 |

MOSFETのW / Lを変えると、電流比も変えられる。

~~~text
I_OUT / I_REF
≈
(W / L)_OUT / (W / L)_REF
~~~

たとえば、出力側のW / Lを基準側の2倍にすると、理想的には2倍の電流が流れる。

~~~text
I_OUT ≈ 2 × I_REF
~~~



**結論**

電流ミラーは基準電流を別の枝へコピーし、W / Lによって電流比を決める。

## 2.4　差動増幅回路の基礎
<img width="1376" height="1143" alt="image" src="https://github.com/user-attachments/assets/5cbb1060-db95-454e-bc05-e37751d12556" />

## 2.4　差動増幅回路の基礎

### 2つのソース接地回路で入力を比べる

差動増幅回路は、2つのソース接地回路を組み合わせた回路である。

`MN1`には`V_IN1`、`MN2`には`V_IN2`が入力される。`MN1`と`MN2`は、`MN3`が作る一定のテール電流を分け合う。

```text
I_D1 + I_D2 ≈ I_TAIL
```

2つの入力電圧が等しいときは、左右にほぼ同じ電流が流れる。

```text
V_IN1 = V_IN2
→ I_D1 ≈ I_D2
→ V_OUT1 ≈ V_OUT2
```

`V_IN1`が高くなると、`MN1`の電流が増える。テール電流はほぼ一定なので、`MN2`の電流は減る。

各枝はソース接地回路と同じように動作する。

```text
V_IN1が上がる
→ I_D1が増える
→ V_OUT1が下がる
```

反対側では、次の変化が起こる。

```text
I_D2が減る
→ V_OUT2が上がる
```

`V_IN2`が高くなった場合は、左右が反対に動く。

```text
V_IN2が上がる
→ I_D2が増える
→ V_OUT2が下がる
```

```text
I_D1が減る
→ V_OUT1が上がる
```

| 入力の状態           | `V_OUT1` | `V_OUT2` |
| --------------- | -------: | -------: |
| `V_IN1 = V_IN2` |     ほぼ同じ |     ほぼ同じ |
| `V_IN1 > V_IN2` |      下がる |      上がる |
| `V_IN1 < V_IN2` |      上がる |      下がる |

### 増幅の仕組みもソース接地回路と同じ

差動増幅回路でも、入力電圧を`g_m`によって電流へ変え、その電流を負荷抵抗`R`によって出力電圧へ変える。

```text
入力電圧差
    ↓ g_m
左右の電流差
    ↓ R
左右の出力電圧差
```

したがって、差動電圧利得の大きさは、おおよそ次のように考えられる。

```text
abs(A_vd) ≈ g_m × R
```

これは、ソース接地回路の利得が`g_m`と出力抵抗の積で決まることと同じである。

**結論**

差動増幅回路は、2つのソース接地回路でテール電流を分け合い、入力電圧の差を左右反対向きの出力電圧へ変換する。

比較のためにMOSFETを2個使うが、電圧を増幅する仕組みはソース接地回路と同じである。


## 2.5　基本回路の電圧利得と出力抵抗

### 利得はg_mとR_outで決まる

MOSFET増幅回路では、入力電圧をg_mによって電流へ変え、その電流をR_outによって出力電圧へ変える。

~~~text
入力電圧
→ g_m
→ 出力電流
→ R_out
→ 出力電圧
~~~

電圧利得の大きさは、おおよそ次のようになる。

~~~text
abs(A_v) ≈ G_m × R_out
~~~

| 記号 | 意味 |
|---|---|
| A_v | 小信号電圧利得 |
| G_m | 回路全体で入力電圧を出力電流へ変える係数 |
| R_out | 出力ノードから見た合成抵抗 |

差動対と電流ミラー能動負荷を組み合わせた第1段では、次のようになる。

~~~text
abs(A_v1) ≈ g_m1 × R_out1
~~~

第2段のソース接地回路では、次のようになる。

~~~text
abs(A_v2) ≈ g_m2 × R_out2
~~~

二段構成オペアンプ全体の低周波開ループ利得は、各段の利得を掛けて求める。

~~~text
abs(A_0) ≈ abs(A_v1) × abs(A_v2)
~~~

| 記号 | 意味 |
|---|---|
| A_v1 | 第1段の電圧利得 |
| A_v2 | 第2段の電圧利得 |
| g_m1、g_m2 | 第1段と第2段の相互コンダクタンス |
| R_out1、R_out2 | 第1段と第2段の出力抵抗 |
| A_0 | オペアンプ全体の低周波開ループ利得 |

### dBとは

dBは、非常に大きな利得や小さな利得を短い数値で表すために使う。

電圧利得をdBへ変換する式は、次のようになる。

~~~text
A_v[dB] = 20 × log10(abs(A_v))
~~~

| 記号 | 意味 |
|---|---|
| A_v[dB] | dBで表した電圧利得 |
| abs(A_v) | 電圧利得の大きさ |
| log10 | 10を底とする対数 |

log10は「10を何乗するとその値になるか」を表す。

~~~text
log10(100) = 2
~~~

したがって、100倍の電圧利得は40 dBになる。

~~~text
20 × log10(100)
=
20 × 2
=
40 dB
~~~

反対に、dBから倍率へ戻す式は次のようになる。

~~~text
abs(A_v) = 10^(A_v[dB] / 20)
~~~

### よく使う倍率とdB

| 電圧利得の大きさ | dB |
|---:|---:|
| 0.5倍 | 約-6 dB |
| 1倍 | 0 dB |
| 2倍 | 約6 dB |
| 10倍 | 20 dB |
| 100倍 | 40 dB |
| 1,000倍 | 60 dB |

- 0 dBは1倍を表す
- 正のdBは1倍より大きい
- 負のdBは1倍より小さい
- 反転増幅の負号はdBには含めず、利得の大きさを使う

電力の比をdBで表す場合は、20ではなく10を掛ける。

~~~text
電力利得[dB]
=
10 × log10(P_OUT / P_IN)
~~~

### 二段の利得をdBで表す

倍率では、第1段と第2段の利得を掛ける。

~~~text
abs(A_0)
≈
abs(A_v1) × abs(A_v2)
~~~

dBでは、各段の利得を足す。

~~~text
A_0[dB]
≈
A_v1[dB] + A_v2[dB]
~~~

たとえば、第1段が50倍、第2段が20倍の場合を考える。

~~~text
第1段：50倍 ≈ 34 dB
第2段：20倍 ≈ 26 dB
~~~

倍率で求めると、全体利得は1,000倍になる。

~~~text
abs(A_0) ≈ 50 × 20 = 1,000
~~~

dBで求めると、全体利得は60 dBになる。

~~~text
A_0[dB] ≈ 34 dB + 26 dB = 60 dB
~~~

~~~text
1,000倍 = 60 dB
~~~

実際の利得は、MOSFETの出力抵抗、負荷、動作領域、周波数によって変化する。

**結論**

各段の電圧利得は主にg_mとR_outの積で決まる。二段の倍率は掛け算し、dBで表す場合は足し算する。

- 電流ミラーは、基準電流を別の枝へコピーする
- MOS差動対は、入力電圧の差を電流差へ変換する
- 各段の電圧利得は、主にg_mとR_outの積で決まる
- 二段の利得は倍率では掛け算し、dBでは足し算する

## 3.1　二段構成オペアンプの全体回路

このオペアンプは、2つの入力電圧の小さな差を見つけ、その差を大きな電圧にして出力する回路である。

回路は、次の4つの部分に分けて考えるとわかりやすい。

### ① `R`と`M8`：回路を動かす準備をする

抵抗`R`とトランジスタ`M8`は、回路に流す電流の基準を作る。

オペアンプを動かすためには、入力信号がないときでも、内部に一定の電流を流しておく必要がある。

`R`と`M8`は、この電流を決める役割を持つ。

つまり、`R`と`M8`は、オペアンプが信号を受け取れるように準備する部分である。

### ② `M1`～`M5`：入力電圧の差を見つける

`M1`～`M5`は、オペアンプの第1段である。

ここでは、2つの入力電圧`v_inp`と`v_inn`を比べる。

2つの入力電圧に差があると、`M1`と`M2`に流れる電流にも差ができる。

その電流の差を、`M3`と`M4`が1つの電圧に変える。

この電圧が、第1段の出力である中間電圧`v_1`である。

### ③ `M6`と`M7`：信号をさらに大きくする

`M6`と`M7`は、オペアンプの第2段である。

第1段で作られた中間電圧`v_1`は、`M6`へ入力される。

`M6`は、`v_1`の変化をさらに大きくする。

そして、最終的な出力電圧`v_out`を作る。

`M7`は、第2段を動かすために必要な電流を流す。

### ④ `C_C`：発振しにくくする

補償容量`C_C`は、オペアンプの動きを安定させるための容量である。

二段構成のオペアンプは、信号を大きく増幅できる。しかし、動作が速すぎると、出力電圧が振動してしまうことがある。

`C_C`は、回路の急激な変化を少しゆるやかにする。

これにより、オペアンプが発振しにくくなる。

回路全体の信号の流れをまとめると、次のようになる。

`v_inp`と`v_inn`を比べる
↓
入力電圧の差を電流の差に変える
↓
中間電圧`v_1`を作る
↓
`v_1`をさらに大きくする
↓
出力電圧`v_out`を作る

## 3.2　第1段の差動増幅回路

第1段の役割は、2つの入力電圧の差を見つけることである。

`v_inn`は`M1`へ入力される。

`v_inp`は`M2`へ入力される。

`M1`と`M2`は、2つの入力電圧を電流の違いに変える。

### 2つの入力電圧が同じとき

はじめに、

`v_inp = v_inn`

の場合を考える。

2つの入力電圧が同じなら、`M1`と`M2`には、ほぼ同じ大きさの電流が流れる。

`M5`から供給された電流を、`M1`と`M2`がほぼ半分ずつ分ける。

このとき、左右の電流はつり合っている。

### `v_inp`が高くなったとき

次に、`v_inp`が`v_inn`より高くなった場合を考える。

`v_inp`は`M2`へ入力されているため、`M2`に流れる電流が増える。

一方、`M5`から供給される電流の合計は、ほぼ一定である。

そのため、`M2`の電流が増えると、`M1`の電流は減る。

つまり、

* `M2`の電流は増える
* `M1`の電流は減る

という動きになる。

### `v_inn`が高くなったとき

反対に、`v_inn`が`v_inp`より高くなると、`M1`に流れる電流が増える。

このとき、`M2`に流れる電流は減る。

つまり、

* `M1`の電流は増える
* `M2`の電流は減る

という動きになる。

### 電流の差を電圧に変える

ここまでで、入力電圧の差は、`M1`と`M2`に流れる電流の差へ変わった。

しかし、次の第2段へ渡したいのは電圧である。

そこで、`M3`と`M4`を使う。

`M3`と`M4`は、`M1`と`M2`に流れる電流の違いを、1つの電圧の変化に変える。

この電圧が、中間電圧`v_1`である。

第1段の動きを簡単にまとめると、次のようになる。

2つの入力電圧を比べる
↓
`M1`と`M2`の電流に差ができる
↓
`M3`と`M4`が電流の差を電圧に変える
↓
中間電圧`v_1`が作られる

この`v_1`が、第2段の`M6`へ送られる。
## 3.3　電流ミラー能動負荷

`M1`と`M2`は、入力電圧の差を電流の差に変える。

しかし、この時点では、電流が左右2本に分かれている。そのままでは、次の第2段へ信号を渡しにくい。

そこで、`M3`と`M4`で作られた電流ミラーを使う。

電流ミラーは、一方の電流を、もう一方へ写す回路である。`M3`に流れる電流が変わると、`M4`に流れる電流も同じように変わる。

これにより、`M1`側と`M2`側の電流の違いを、1つの電圧の変化として取り出すことができる。

この電圧が、中間電圧`v_1`である。

### `v_inp`が高くなった場合

`v_inp`が高くなると、`M2`の電流が増え、`M1`の電流が減る。

`M1`の電流が減ると、`M3`の電流も減る。さらに、電流ミラーの働きによって、`M4`の電流も減る。

このとき、`M2`は多くの電流を下側へ流そうとする。一方、`M4`から供給される電流は少なくなる。

その結果、中間電圧`v_1`は低くなる。

### `v_inn`が高くなった場合

反対に、`v_inn`が高くなると、`M1`の電流が増え、`M2`の電流が減る。

`M1`の電流が増えると、`M3`と`M4`の電流も増える。

このとき、`M4`から供給される電流が増える。一方、`M2`が下側へ流す電流は少なくなる。

その結果、中間電圧`v_1`は高くなる。

このように、`M3`と`M4`は、左右の電流の違いを1つの電圧`v_1`に変える。

また、`M3`と`M4`は、抵抗の代わりとなる負荷としても働く。MOSFETを使った負荷なので、「能動負荷」と呼ばれる。

## 3.4　第2段のソース接地増幅回路

第1段で作られた中間電圧`v_1`は、第2段のPMOS `M6`のゲートへ入力される。

`M6`の役割は、`v_1`の変化を、さらに大きな出力電圧の変化にすることである。

### `v_1`が低くなった場合

`v_1`が低くなると、PMOSである`M6`は電流を多く流す。

すると、電源側から出力へ流れ込む電流が増えるため、出力電圧`v_out`は高くなる。

### `v_1`が高くなった場合

反対に、`v_1`が高くなると、`M6`の電流は減る。

すると、下側の`M7`が出力から電流を引く働きのほうが強くなり、出力電圧`v_out`は低くなる。

したがって、`v_1`と`v_out`は反対向きに変化する。

* `v_1`が低くなると、`v_out`は高くなる
* `v_1`が高くなると、`v_out`は低くなる

このように入力と出力が反対向きに変化する回路を、ソース接地増幅回路という。

`M6`は出力電圧を上げる方向に働き、`M7`は出力電圧を下げる方向に働く。この2つの電流のつり合いによって、出力電圧`v_out`が決まる。

## 3.5　バイアス電流の流れ

オペアンプを動かすためには、入力信号が加わる前から、各MOSFETに一定の電流を流しておく必要がある。

この電流を「バイアス電流」という。

バイアス電流を流しておくことで、入力信号が加わったときに、各MOSFETがすぐに増幅動作を始められる。

この回路では、抵抗`R`と`M8`が、バイアス電流の基準を作る。

この基準をもとに、`M5`と`M7`へ流す電流が決まる。

### `M5`の役割

`M5`は、第1段全体に流れる電流を決める。

`M5`から供給された電流は、`M1`と`M2`に分かれて流れる。

入力電圧が変化すると、`M1`と`M2`への電流の分かれ方が変わる。しかし、2つの電流を合わせた大きさは、ほぼ一定に保たれる。

### `M7`の役割

`M7`は、第2段に流れる電流を決める。

`M7`は、出力から下側へほぼ一定の電流を引く。

この`M7`の電流と、上側の`M6`から流れ込む電流のつり合いによって、出力電圧`v_out`が決まる。

つまり、バイアス回路には、次の2つの役割がある。

* `M5`を使って、第1段を動かす
* `M7`を使って、第2段を動かす

---

## 3.6　入力から出力までの信号経路

ここでは、入力電圧が変化してから、出力電圧が変化するまでの流れを順番に確認する。

### `v_inp`が高くなった場合

最初に、`v_inp`が高くなった場合を考える。

1. `M2`の電流が増える。
2. `M1`の電流が減る。
3. `M3`と`M4`の電流も減る。
4. 中間電圧`v_1`が低くなる。
5. PMOS `M6`の電流が増える。
6. 出力電圧`v_out`が高くなる。

したがって、`v_inp`が高くなると、`v_out`も高くなる。

### `v_inn`が高くなった場合

次に、`v_inn`が高くなった場合を考える。

1. `M1`の電流が増える。
2. `M2`の電流が減る。
3. `M3`と`M4`の電流が増える。
4. 中間電圧`v_1`が高くなる。
5. PMOS `M6`の電流が減る。
6. 出力電圧`v_out`が低くなる。

したがって、`v_inn`が高くなると、`v_out`は低くなる。

信号の変化を表にまとめると、次のようになる。

| 入力の変化        | `M1`と`M2`の変化    | 中間電圧`v_1` | 出力電圧`v_out` |
| ------------ | --------------- | --------- | ----------- |
| `v_inp`が高くなる | `M2`が増え、`M1`が減る | 低くなる      | 高くなる        |
| `v_inn`が高くなる | `M1`が増え、`M2`が減る | 高くなる      | 低くなる        |

### 補償容量`C_C`の働き

補償容量`C_C`は、中間電圧`v_1`と出力電圧`v_out`の間に接続されている。

`v_1`や`v_out`が急に変化しようとすると、`C_C`に電流が流れる。これにより、内部電圧の急激な変化が抑えられる。

その結果、オペアンプの動きが安定し、負帰還をかけたときに発振しにくくなる。

つまり、`C_C`は、オペアンプが速く動きすぎて不安定になることを防ぐための部品である。

## 3.7　各MOSFETの役割

| 回路部分   | 素子        | 一言で表した役割       |
| ------ | --------- | -------------- |
| バイアス回路 | `R`、`M8`  | 回路を動かす準備をする    |
| 差動入力   | `M1`、`M2` | 2つの入力電圧を比べる    |
| 電流ミラー  | `M3`、`M4` | 左右の電流差を1つにまとめる |
| テール電流源 | `M5`      | 第1段に流す電流を決める   |
| 第2段    | `M6`      | 中間信号をさらに大きくする  |
| 電流源負荷  | `M7`      | 第2段に一定の電流を流す   |
| 位相補償   | `C_C`     | 回路の発振を防ぐ       |

---

## 第3章のまとめ

二段構成オペアンプでは、最初に`R`と`M8`が回路を動かすための基準電流を作る。

次に、`M1`と`M2`が2つの入力電圧を比べ、`M3`と`M4`がその結果を中間電圧`v_1`へまとめる。

中間電圧`v_1`は`M6`へ渡され、さらに増幅されて出力電圧`v_out`になる。

`M5`と`M7`は各段に必要な電流を流し、`C_C`はオペアンプが安定して動作するようにする。

# 第4章　直流動作と低周波利得

## DC Operation and Low-Frequency Gain

MOSFET増幅回路は、最初に直流の動作点を決め、その動作点の周りに加わる小さな信号を増幅する。
<img width="1111" height="747" alt="image" src="https://github.com/user-attachments/assets/fb0bc7e1-93a8-497d-8a7e-974a0e5f888f" />


MOSFETを正しく増幅させるには、信号がないときの電圧と電流を適切に決める必要がある。

また、入力電圧と出力電圧には、正しく増幅できる範囲がある。

この章では、次の二段構成オペアンプを考える。

* `M1`、`M2`：NMOS差動対
* `M3`、`M4`：PMOS電流ミラー
* `M5`：第1段のNMOS電流源
* `M6`：第2段のNMOS増幅回路
* `M7`：第2段のPMOS電流源

説明では、次の数値を使用する。

| 項目               |      数値例 |   |         |
| ---------------- | -------: | - | ------- |
| 上側電源`V_DD`       | `+1.5 V` |   |         |
| 下側電源`V_SS`       | `-1.5 V` |   |         |
| 電源電圧の合計          |  `3.0 V` |   |         |
| NMOSのしきい値`V_THn` |  `0.5 V` |   |         |
| PMOSのしきい値の大きさ`   |    V_THp | ` | `0.5 V` |
| オーバードライブ電圧`V_OV` |  `0.2 V` |   |         |
| テール電流`I_TAIL`    |  `40 μA` |   |         |
| 第2段の電流`I_BIAS2`  | `100 μA` |   |         |

```text
電源電圧
= V_DD - V_SS
= 1.5 - (-1.5)
= 3.0 V
```

単電源回路では、例えば`V_DD = 3.0 V`、`V_SS = 0 V`として考えればよい。

---

## 4.1　直流動作点

直流動作点とは、入力信号がないときの電圧と電流である。

簡単にいえば、オペアンプの「待機中の状態」である。

2つの入力電圧が同じとき、`M5`のテール電流は`M1`と`M2`へ、ほぼ半分ずつ流れる。

```text
I_D1 ≈ I_D2
≈ I_TAIL / 2
```

数値例では、

```text
I_D1 ≈ I_D2
≈ 40 μA / 2
= 20 μA
```

となる。

`M3`と`M4`にも、約`20 μA`ずつ流れる。

第2段では、`M6`が下側へ引く電流と、`M7`が上側から供給する電流がつり合う。

```text
I_D6 ≈ I_D7 ≈ 100 μA
```

この電流のつり合いによって、信号がないときの出力電圧`V_OUT`が決まる。

**結論**

直流動作点は、各MOSFETを増幅できる状態にするための基準となる電圧と電流である。

---

## 4.2　MOSFETの飽和条件

MOSFETを増幅に使うときは、基本的に飽和領域で動作させる。

NMOSの飽和条件は、

```text
V_DS ≥ V_OV
```

PMOSの飽和条件は、

```text
V_SD ≥ V_OV
```

である。

今回の数値例では`V_OV = 0.2 V`なので、各MOSFETには、およそ`0.2 V`以上のドレイン・ソース間電圧が必要になる。

例えば、NMOSの`V_DS`が`0.1 V`まで下がると、

```text
0.1 V < 0.2 V
```

となり、飽和条件を満たさない。

この状態では、MOSFETの利得が低下し、出力波形もひずみやすくなる。

**結論**

各MOSFETには、少なくとも`V_OV`程度の電圧を残し、飽和領域を保つ必要がある。

---

## 4.3　電圧ヘッドルーム

電圧ヘッドルームとは、MOSFETが正しく動くために必要な電圧の余裕である。

今回の電源は、

```text
V_DD = +1.5 V
V_SS = -1.5 V
```

なので、利用できる電源電圧は`3.0 V`である。

第2段では、`M6`と`M7`が、それぞれ約`0.2 V`を必要とする。

したがって、出力に利用できる電圧幅の目安は、

```text
3.0 - 0.2 - 0.2
= 2.6 V
```

となる。

単電源の`V_DD = 3.0 V`、`V_SS = 0 V`でも、電源電圧の合計は同じ`3.0 V`なので、利用できる電圧幅は同じく約`2.6 V`である。

**結論**

電源電圧から各MOSFETに必要な電圧を引いた残りが、信号に利用できる電圧範囲になる。

---

## 4.4　入力同相電圧範囲

入力同相電圧`V_CM`は、2つの入力電圧の平均である。

```text
V_CM = (V_IN+ + V_IN-) / 2
```

`V_CM`を下げすぎると、下側の`M5`が正しく動作できなくなる。

反対に、`V_CM`を上げすぎると、入力MOSFETや上側のPMOS負荷が飽和領域から外れる。

入力範囲の下限は、おおよそ次のようになる。

```text
V_CM,min
≈ V_SS + V_THn + V_OV1 + V_OV5
```

数値例では、

```text
V_CM,min
≈ -1.5 + 0.5 + 0.2 + 0.2
= -0.6 V
```

となる。

入力範囲の上限は、おおよそ次のようになる。

```text
V_CM,max
≈ V_DD - |V_THp| - V_OV3 + V_THn
```

数値例では、

```text
V_CM,max
≈ 1.5 - 0.5 - 0.2 + 0.5
= 1.3 V
```

となる。

したがって、両電源での入力同相電圧範囲は、約

```text
-0.6 V ≤ V_CM ≤ 1.3 V
```

である。

同じ回路を`3.0 V`単電源で動かすと、電圧範囲は約

```text
0.9 V ≤ V_CM ≤ 2.8 V
```

となる。

実際にはMOSFETのばらつきなどを考え、この範囲より少し内側で使用する。

**結論**

NMOS入力差動対では、入力電圧を下げすぎても、上げすぎても正常に増幅できない。

---

## 4.5　出力電圧範囲

出力電圧`V_OUT`は、`M6`と`M7`が飽和領域を保てる範囲で動かす必要がある。

出力電圧の下限は、下側のNMOS `M6`によって決まる。

```text
V_OUT,min
≈ V_SS + V_OV6
```

両電源の場合は、

```text
V_OUT,min
≈ -1.5 + 0.2
= -1.3 V
```

となる。

出力電圧の上限は、上側のPMOS `M7`によって決まる。

```text
V_OUT,max
≈ V_DD - V_OV7
```

```text
V_OUT,max
≈ 1.5 - 0.2
= 1.3 V
```

したがって、両電源での理想的な出力範囲は、

```text
-1.3 V ≤ V_OUT ≤ 1.3 V
```

となる。

`3.0 V`単電源の場合は、

```text
0.2 V ≤ V_OUT ≤ 2.8 V
```

となる。

実際には余裕を持たせ、理論上の限界より少し内側で使用する。

**結論**

出力電圧の下限は`M6`、上限は`M7`の飽和条件によって決まる。

---

## 4.6　第1段の電圧利得

第1段では、`M1`と`M2`が入力電圧の差を電流の差に変える。

`M3`と`M4`は、その電流の差を中間電圧`v_1`へ変える。

第1段の利得は、おおよそ次のようになる。

```text
A_v1 ≈ -g_m1 × R_out1
```

例えば、

```text
g_m1 = 0.20 mS
R_out1 = 200 kΩ
```

とすると、

```text
A_v1
≈ -0.20 mS × 200 kΩ
= -40
```

となる。

利得の大きさは`40倍`、dBでは約`32 dB`である。

マイナス記号は、`v_in+`が高くなると、中間電圧`v_1`が低くなることを表している。

**結論**

第1段の利得は、入力MOSFETの`g_m1`と、第1段の出力抵抗`R_out1`の積で決まる。

---

## 4.7　第2段の電圧利得

第2段では、NMOS `M6`が中間電圧`v_1`をさらに増幅する。

`v_1`が高くなると、`M6`の電流が増え、出力電圧`v_out`は低くなる。

第2段の利得は、おおよそ次のようになる。

```text
A_v2 ≈ -g_m6 × R_out2
```

例えば、

```text
g_m6 = 1.0 mS
R_out2 = 50 kΩ
```

とすると、

```text
A_v2
≈ -1.0 mS × 50 kΩ
= -50
```

となる。

利得の大きさは`50倍`、dBでは約`34 dB`である。

このときも、出力が入力と反対向きに動くため、利得にマイナス記号が付く。

**結論**

第2段の利得は、`M6`の`g_m6`と、第2段の出力抵抗`R_out2`の積で決まる。

---

## 4.8　二段全体の開ループ利得

オペアンプ全体の利得は、第1段と第2段の利得を掛けて求める。

```text
A_0 = A_v1 × A_v2
```

数値例では、

```text
A_0
= (-40) × (-50)
= 2,000
```

となる。

第1段と第2段で2回反転するため、全体の利得は正になる。

dBでは、各段の利得を足せばよい。

```text
A_0
≈ 32 dB + 34 dB
= 66 dB
```

したがって、この例の低周波開ループ利得は、約`2,000倍`、または`66 dB`である。

電源電圧は`3.0 V`であるが、入力電圧の差を`2,000倍`しようとするため、入力差が少し大きいだけでも出力は限界に達する。

例えば、

```text
1 mV × 2,000 = 2.0 V
```

となる。

**結論**

二段全体の利得は、倍率では各段の利得を掛け、dBでは各段の利得を足して求める。

---

## 4.9　`g_m`、`r_o`、バイアス電流

MOSFET増幅回路の利得は、主に`g_m`と`r_o`で決まる。

```text
利得 ≈ g_m × r_o
```

`g_m`は、入力電圧の変化を電流の変化へ変える能力を表す。

```text
g_m = 2I_D / V_OV
```

例えば、`M1`に`20 μA`が流れ、`V_OV = 0.2 V`なら、

```text
g_m1
= 2 × 20 μA / 0.2 V
= 0.20 mS
```

となる。

`M6`に`100 μA`が流れる場合は、

```text
g_m6
= 2 × 100 μA / 0.2 V
= 1.0 mS
```

となる。

電流を増やすと`g_m`が大きくなり、回路は速く動きやすくなる。しかし、消費電力が増え、`r_o`は小さくなりやすい。

例えば、電源電圧が`3.0 V`で、回路全体に`200 μA`が流れる場合、消費電力の目安は、

```text
P
≈ 3.0 V × 200 μA
= 0.6 mW
```

となる。

| 変更           | 主な効果                      |
| ------------ | ------------------------- |
| 電流を増やす       | 速くなるが、消費電力が増える            |
| `V_OV`を小さくする | 利得と電圧範囲を改善しやすい            |
| `W`を大きくする    | `g_m`を大きくしやすいが、容量が増える     |
| `L`を長くする     | `r_o`と利得を大きくしやすいが、遅くなりやすい |

**結論**

高い利得には大きな`g_m`と`r_o`が必要であるが、速度、消費電力、電源電圧、出力範囲とのバランスも大切である。

## 第4章のまとめ

- 直流動作点は、信号がないときの電圧と電流である
- 増幅に使うMOSFETは、基本的に飽和領域へ置く
- 電圧ヘッドルームは、入力範囲と出力範囲を制限する
- NMOS入力差動対の同相入力下限は主にM5、上限は入力NMOSとPMOS負荷が決める
- 出力電圧の下限はM6、上限はM7の飽和条件が決める
- 第1段と第2段の低周波利得は、主にg_mとR_outの積で決まる
- 二段全体の利得は倍率では掛け算し、dBでは足し算する
- バイアス電流を増やすと速度は上げやすいが、r_oの低下と消費電力の増加が起こる

直流動作点と飽和条件を確認したうえでg_mとr_oを求めると、二段構成CMOSオペアンプの低周波開ループ利得を計算できる。
実際の設計ではSPICE解析を行い、直流動作点、飽和領域、利得が目標を満たすように`W/L`、電流、`V_OV`を調整する。





# 第5章　二段構成CMOSオペアンプに使う制御工学

## 5.1　なぜAC解析を行うのか

オペアンプでは、最初にDC解析を行い、その後にAC解析を行う。

```text
DC解析：回路の基準となる動作点を求める
AC解析：周波数ごとの利得と位相を求める
```

### DC解析

DC解析では、各MOSFETの直流電圧と直流電流を求める。

例えば、テール電流が`28 μA`で、差動対の入力電圧が等しい場合、`M1`と`M2`には約半分ずつ電流が流れる。

```text
I_D1 ≈ I_D2
     ≈ 28 μA / 2
     = 14 μA
```

このとき、

```text
V_GS = 0.700 V
I_D  = 14.0 μA
```

だったとする。この基準となる状態を動作点`Q`という。

DC解析では、主に次を確認する。

* 必要な電流が流れているか
* MOSFETが飽和領域にあるか
* 出力直流電圧が適切か
* 消費電力が仕様内か

---

### 小信号を考える

MOSFETの特性は本来曲線だが、動作点の近くだけなら直線として近似できる。

動作点に、

```text
v_gs = 1 mV
```

の小さな変化を加える。

`g_m = 100 μS`なら、ドレイン電流の変化は、

```text
i_d ≈ g_m v_gs

    = 100 μS × 1 mV

    = 0.10 μA
```

となる。

したがって、実際のドレイン電流は、

```text
14.0 μA + 0.10 μA
= 14.1 μA
```

となる。

直流値と小信号は、文字の大きさで区別する。

| 表記           | 意味          |
| ------------ | ----------- |
| `V_GS`、`I_D` | DC解析で求めた直流値 |
| `v_gs`、`i_d` | 動作点からの小さな変化 |

```text
実際の電圧 = V_GS + v_gs

実際の電流 = I_D + i_d
```

MOSFETの小信号電流は、次の式で表せる。

```text
i_d = g_m v_gs + v_ds/r_o
```

最初は、次の簡単な形で考えればよい。

```text
i_d ≈ g_m v_gs
```

---

### AC解析

AC解析では、動作点の周りに小さな交流信号を加え、周波数を変化させる。

回路内部の容量の影響により、周波数が高くなると利得が低下し、位相が遅れる。

二段オペアンプでは、主に次を確認する。

| 項目    |      数値例 | 意味         |
| ----- | -------: | ---------- |
| 低周波利得 |  `70 dB` | 低い周波数での増幅率 |
| GBW   | `45 MHz` | 増幅できる帯域の目安 |
| 位相余裕  |    `60°` | 発振しにくさの目安  |

低周波利得`70 dB`を倍率に直すと、

```text
10^(70/20) ≈ 3,160倍
```

となる。

SPICEでは、最初にDC動作点を求め、その動作点でMOSFETを小信号モデルへ置き換えてからAC解析を行う。

---


**結論**

DC解析では動作点`Q`を求め、AC解析ではその周りの小さな信号に対する利得と位相を求める。

## 5.2　複素数、ラプラス変換、伝達関数

交流回路では、信号の「大きさ」と「位相」を同時に考える必要がある。

そのため、複素数とラプラス変換を使用する。

### 主な記号

| 記号     | 意味                 |
| ------ | ------------------ |
| `j`    | `j² = -1`を満たす虚数単位  |
| `s`    | 複素周波数。`s = σ + jω` |
| `ω`    | 角周波数。`ω = 2πf`     |
| `H(s)` | 入力から出力までの伝達関数      |
| `δ(t)` | 単位インパルス            |
| `u(t)` | 単位ステップ入力           |
| `h(t)` | インパルス応答            |
| `A(s)` | オペアンプの開ループ伝達関数     |

電気回路では電流に`i`を使うため、虚数単位には`j`を使用する。

---

### なぜ複素数を使うのか

交流信号には、大きさと位相がある。

例えば、出力が入力の半分になり、さらに`45°`遅れる場合は、

```text
大きさ：0.5倍
位相　：-45°
```

となる。

複素数を使うと、大きさと位相をまとめて計算できる。

```text
e^(jθ) = cosθ + j sinθ
```

交流信号を`e^(jωt)`で表すことで、正弦波の微分や積分を簡単に計算できる。

---

### 複素周波数`s`

ラプラス変換では、複素周波数`s`を使用する。

```text
s = σ + jω
```

* `σ < 0`：時間とともに小さくなる
* `σ = 0`：大きさを保って振動する
* `σ > 0`：時間とともに大きくなる

通常のAC解析では、一定振幅の正弦波を考えるため、

```text
s = jω
```

と置く。

---

### ラプラス変換の役割

コンデンサやコイルを含む回路では、電圧や電流の微分と積分が現れる。

ラプラス変換を使うと、次のように置き換えられる。

```text
微分 d/dt → s

積分 ∫dt → 1/s
```

これにより、微分方程式を通常の式に近い形で計算できる。

### 正弦波を微分した場合

次の正弦波を考える。

```text
x(t) = sin(ωt)
```

これを時間で微分すると、

```text
dx(t)/dt
= ωcos(ωt)
= ωsin(ωt + 90°)
```

となる。

つまり、正弦波を微分すると、

* 振幅は`ω`倍になる
* 位相は`90°`進む

という変化が起こる。

### 正弦波を積分した場合

同じ正弦波を積分すると、

```text
∫sin(ωt)dt
= -(1/ω)cos(ωt)
= (1/ω)sin(ωt - 90°)
```

となる。ここでは積分定数を省略している。

つまり、正弦波を積分すると、

* 振幅は`1/ω`倍になる
* 位相は`90°`遅れる

という変化が起こる。

| 操作 |     振幅 |       位相 |
| -- | -----: | -------: |
| 微分 |   `ω`倍 |  `90°`進む |
| 積分 | `1/ω`倍 | `90°`遅れる |
<img width="1400" height="1260" alt="image" src="https://github.com/user-attachments/assets/892180c9-6d70-4482-b79e-21f4059253a3" />

例えば、`f = 1 kHz`の場合は、

```text
ω = 2πf
  = 2π × 1,000
  ≈ 6,280 rad/s
```

となる。

そのため、微分では振幅が約`6,280倍`され、積分では約`1/6,280`倍になる。

### 複素数で表した場合

正弦波を複素数`e^(jωt)`で表すと、微分と積分はさらに簡単になる。

```text
微分：
d/dt{e^(jωt)}
=
jωe^(jωt)
```

```text
積分：
∫e^(jωt)dt
=
1/(jω)e^(jωt)
```

AC解析では`s = jω`なので、

```text
微分 → jω → s

積分 → 1/(jω) → 1/s
```

となる。

この関係から、

* `jω`を掛けると位相が`90°`進む
* `1/(jω)`を掛けると位相が`90°`遅れる

ことが分かる。

これは、コンデンサやコイルの位相が変化する理由にもつながる。

```text
コンデンサ：
i_C = C・dv_C/dt
→ 電流が電圧より90°進む
```

```text
コイル：
v_L = L・di_L/dt
→ 電圧が電流より90°進む
```

つまり、ラプラス変換は、正弦波の微分と積分を`s`の掛け算と割り算に置き換える方法である。


### `R`・`C`・`L`のインピーダンス

抵抗、コンデンサ、コイルのインピーダンスは、次のようになる。

| 素子       | インピーダンス`Z(s)` | AC解析での形   |
| -------- | ------------- | --------- |
| 抵抗`R`    | `R`           | `R`       |
| コンデンサ`C` | `1/(sC)`      | `1/(jωC)` |
| コイル`L`   | `sL`          | `jωL`     |

周波数が高くなると、コンデンサのインピーダンスは小さくなり、コイルのインピーダンスは大きくなる。

例えば、`f = 1 kHz`では次のようになる。

| 素子    |         素子値 | インピーダンスの大きさ |
| ----- | ----------: | ----------: |
| 抵抗    |  `R = 1 kΩ` |      `1 kΩ` |
| コンデンサ |  `C = 1 μF` |    約`159 Ω` |
| コイル   | `L = 10 mH` |   約`62.8 Ω` |

---

### 伝達関数とは何か

伝達関数`H(s)`は、入力に対して出力がどのように変化するかを表す。

初期状態が0の場合、次のように定義する。

```text
H(s) = Y(s)/X(s)
```

例えば、RCローパスフィルタの伝達関数は、

```text
H(s) = 1/(1 + sRC)
```

となる。



### デルタ関数とインパルス入力

デルタ関数`δ(t)`は、一瞬だけ加わる理想的な入力である。インパルスとも呼ばれる。

```text
δ(t) = 0　　t ≠ 0

∫δ(t)dt = 1
```

デルタ関数は、幅が限りなく短く、全体の面積が1になる入力である。

実際の回路では作れないため、非常に短いパルスで近似する。

幅を`Δt`、高さを`1/Δt`にすると、パルスの面積は1になる。

```text
面積
= 高さ × 幅
= (1/Δt) × Δt
= 1
```

---

### インパルス応答

デルタ関数を入力したときの出力を、インパルス応答`h(t)`という。

```text
入力：x(t) = δ(t)

出力：y(t) = h(t)
```

インパルス応答を見ると、回路の応答速度、減衰、振動の様子が分かる。

線形で時間によって性質が変わらない回路では、任意の入力に対する出力を、インパルス応答から求められる。

```text
y(t)
=
∫x(τ)h(t - τ)dτ
```

この計算を畳み込みという。

---

### ステップ入力とステップ応答

時刻`t = 0`で、入力を0から1へ切り替える信号を単位ステップ入力`u(t)`という。

```text
u(t) = 0　　t < 0

u(t) = 1　　t ≥ 0
```

単位ステップ入力を加えたときの出力を、ステップ応答という。

実際のオペアンプでは、例えば入力を`0 V`から`10 mV`へ急に変化させ、出力波形を観測する。

ステップ応答から、次の項目を確認できる。

* 立ち上がり時間
* オーバーシュート
* リンギング
* 最終値へ落ち着くまでの時間
* 発振の有無

---

### インパルス応答とステップ応答の関係

デルタ関数は、ステップ入力を微分したものと考えられる。

```text
δ(t) = du(t)/dt
```

そのため、インパルス応答を積分するとステップ応答になる。

反対に、ステップ応答を微分するとインパルス応答になる。

```text
ステップ応答
=
インパルス応答の積分
```

```text
インパルス応答
=
ステップ応答の微分
```

---

### 伝達関数との関係

デルタ関数のラプラス変換は1である。

```text
L{δ(t)} = 1
```

したがって、デルタ関数を入力すると、

```text
Y(s)
= H(s) × 1
= H(s)
```

となる。

伝達関数を逆ラプラス変換すると、インパルス応答が得られる。

```text
h(t) = L^(-1){H(s)}
```

一方、単位ステップ入力のラプラス変換は、

```text
L{u(t)} = 1/s
```

である。

したがって、ステップ応答は、

```text
Y_step(s) = H(s)/s
```

を逆ラプラス変換して求める。

### RC回路の応答例

RCローパスフィルタの伝達関数は、

```text
H(s) = 1/(1 + sτ)
```

である。

インパルス応答は、

```text
h(t)
=
(1/τ)e^(-t/τ)u(t)
```

となる。

一瞬だけ大きな出力が現れ、その後は指数関数的に0へ近づく。

単位ステップ応答は、

```text
y_step(t)
=
1 - e^(-t/τ)
```

となる。

`R = 10 kΩ`、`C = 1 nF`では、`τ = 10 μs`である。

| 時刻               |       ステップ応答 |
| ---------------- | -----------: |

| `t = 3τ = 30 μs` | 最終値の約`95.0%` |
| `t = 5τ = 50 μs` | 最終値の約`99.3%` |

インパルス応答とステップ応答には同じ時定数`τ`が現れる。どちらも同じ回路の速さを、異なる入力で見ている。

## 　ボード線図

ボード線図は、周波数を変えたときの「利得」と「位相」を表すグラフである。

* 利得線図：信号を何倍に増幅できるか
* 位相線図：出力が入力からどれだけ遅れるか

伝達関数`A(s)`へ、

```text
s = jω
```

を代入すると、周波数応答`A(jω)`が得られる。

### 主な記号

| 記号      | 意味               |
| ------- | ---------------- |
| `f`     | 周波数〔Hz〕          |
| `ω`     | 角周波数。`ω = 2πf`   |
| `A(jω)` | 周波数ごとの利得と位相      |
| `fp1`   | 第1の極の周波数         |
| `fp2`   | 第2の極の周波数         |
| `fu`    | ループ利得が0 dBになる周波数 |
| `GBW`   | 利得帯域幅積           |

---

### 周波数を対数で表す

オペアンプでは、数Hzから数十MHzまでの広い周波数を扱う。

そのため、横軸には対数目盛を使う。

```text
10 Hz → 100 Hz → 1 kHz → 10 kHz
```

周波数が10倍になる区間を`1 decade`、または`1 dec`という。

---

### 利得をdBで表す

電圧利得は、次の式でdBへ変換する。

```text
利得[dB]
=
20log10|A(jω)|
```

|     電圧利得 |       dB |
| -------: | -------: |
|   `0.1倍` | `-20 dB` |
|     `1倍` |   `0 dB` |
|    `10倍` |  `20 dB` |
|   `100倍` |  `40 dB` |
| `1,000倍` |  `60 dB` |

`0 dB`は信号が0になるという意味ではない。

```text
0 dB = 利得1倍
```

という意味である。

---

### 極と利得の傾き

オペアンプ内部の抵抗と容量によって、極が生じる。

第1の極`fp1`を通過すると、利得は周波数が10倍になるごとに約`20 dB`低下する。

```text
fp1より低い周波数：0 dB/dec

fp1を通過した後　：-20 dB/dec

fp2を通過した後　：-40 dB/dec
```

極が1個増えるごとに、利得の傾きは`-20 dB/dec`ずつ急になる。

また、極1個につき、位相は最大で約`90°`遅れる。

---

### 位相線図

位相線図は、出力が入力から何度ずれているかを表す。

```text
位相0°　　：入力と出力が同じ向き

位相-90° ：4分の1周期遅れる

位相-180°：入力と出力が反対向き
```

周波数が高くなると、極の影響によって位相遅れが大きくなる。

二段オペアンプには主に2つの極があるため、位相は`-180°`へ近づいていく。

また、二段オペアンプのRHP零点は、位相をさらに遅らせる方向に働く。

---

### GBWとユニティゲイン周波数

低周波利得を`A0`、第1の極を`fp1`とすると、GBWはおおよそ次のようになる。

```text
GBW ≈ A0 × fp1
```

ここで、`A0`にはdBではなく倍率を使用する。

例えば、

```text
A0 = 70 dB
   ≈ 3,160倍

fp1 = 14 kHz
```

とすると、

```text
GBW
≈ 3,160 × 14 kHz
≈ 44 MHz
```

となる。

設計値を丸めると、約`45 MHz`である。

ループ利得が1倍、つまり`0 dB`になる周波数を`fu`とする。

```text
|T(jωu)| = 1
```

電圧フォロワでは帰還係数が`β = 1`なので、

```text
T(s) = A(s)
```

となる。

この場合は、

```text
fu ≈ GBW ≈ 45 MHz
```

となる。

**結論**

ボード線図では、周波数による利得の低下と位相の遅れを確認する。

安定性を調べるときは、ループ利得が`0 dB`になる周波数`fu`と、その周波数での位相が重要になる。

## 　負帰還と位相余裕

負帰還とは、出力の一部を入力へ戻し、入力との差を小さくする仕組みである。

### 主な記号

| 記号        | 意味                      |
| --------- | ----------------------- |
| `A(s)`    | オペアンプの開ループ利得            |
| `β(s)`    | 出力を入力へ戻す割合              |
| `T(s)`    | ループ利得。`T(s) = A(s)β(s)` |
| `A_CL(s)` | 負帰還後の閉ループ利得             |
| `fu`      | ループ利得が0 dBになる周波数        |
| `PM`      | 位相余裕                    |

---

### 負帰還の動き

オペアンプは、入力信号と、出力から戻ってきた信号の差を増幅する。

```text
誤差電圧
=
v_in - βv_out
```

出力は、

```text
v_out
=
A(v_in - βv_out)
```

となる。

この式を整理すると、閉ループ利得は、

```text
A_CL
=
A/(1 + Aβ)
```

となる。

ループ利得`Aβ`が十分に大きい場合は、

```text
A_CL ≈ 1/β
```

と近似できる。

---

### 負帰還によって利得が安定する

例えば、開ループ利得と帰還係数を、

```text
A = 3,160倍

β = 0.1
```

とする。

このとき、閉ループ利得は、

```text
A_CL
=
3,160/(1 + 3,160 × 0.1)
≈ 9.97倍
```

となる。

理想的な値は、

```text
1/β = 10倍
```

である。

このように、負帰還を使うと、オペアンプ自身の大きな利得ではなく、帰還係数`β`によって閉ループ利得を決められる。

---

### なぜ負帰還が正帰還になるのか

低い周波数では、出力から戻ってきた信号が入力を打ち消す。

```text
入力が大きくなる
↓
出力が大きくなる
↓
戻り信号が入力との差を小さくする
```

しかし、周波数が高くなると、オペアンプ内部の極によって信号が遅れる。

ループを一周した信号が`180°`遅れると、戻り信号の向きが反対になる。

本来の負帰還は、

```text
入力 - 戻り信号
```

である。

しかし、戻り信号が`180°`反転すると、

```text
入力 - (-戻り信号)
=
入力 + 戻り信号
```

となる。

つまり、信号を小さくするはずの負帰還が、信号を大きくする正帰還へ変わる。

---

### 発振しやすくなる条件

位相が`-180°`のとき、ループ利得が1倍以上あると、信号がループを回っても小さくならない。

```text
位相：-180°

ループ利得：1倍以上
```

この2つが同時に起こると、回路は発振しやすくなる。

| `-180°`でのループ利得 | 回路の動き    |
| -------------- | -------- |
| 1倍より小さい        | 振動は小さくなる |
| ほぼ1倍           | 振動が残りやすい |
| 1倍より大きい        | 振動が大きくなる |

---

### 位相余裕

ループ利得が`0 dB`になる周波数`fu`で、位相が`-180°`まであと何度残っているかを、位相余裕`PM`という。

```text
PM
=
180° + ∠T(jωu)
```

例えば、`fu = 45 MHz`で位相が`-120°`なら、

```text
PM
=
180° - 120°
=
60°
```

となる。

これは、発振条件である`-180°`まで、まだ`60°`の余裕があることを表している。

|    位相余裕 | 安定性の目安     |
| ------: | ---------- |
| `60°前後` | 安定しやすい     |
| `45°前後` | 一般的に使用できる  |
| `30°前後` | 振動的になりやすい  |
|  `0°以下` | 発振する可能性が高い |

**結論**

負帰還を使うと、閉ループ利得を安定して決められる。

しかし、高い周波数では位相遅れによって、負帰還が正帰還へ変わることがある。

安定性は、ループ利得が`0 dB`になる周波数で位相余裕を確認して判断する。

```text
0 dBになる周波数fuを探す
↓
fuでの位相を読む
↓
-180°までの差を求める
↓
位相余裕PM
```

今回の設計目標では、

```text
GBW：約45 MHz
位相余裕：約60°
```

を目安とする。

```python
#
# A(s) = A0(1 - s/wz)
#        -----------------------------
#        (1 + s/wp1)(1 + s/wp2)
#
# 1 - s/wz represents an RHP zero.
# ------------------------------------------------------------

    A0 * (1.0 - s / wz)
    / ((1.0 + s / wp1) * (1.0 + s / wp2))
)

T = A * beta

loop_phase_deg = np.unwrap(np.angle(T)) * 180.0 / np.pi

# ------------------------------------------------------------
# Find the actual 0 dB crossover frequency
# ------------------------------------------------------------

    loop_gain_dB[:-1] * loop_gain_dB[1:] <= 0.0

        "No 0 dB crossover was found in the frequency range."
```

## 6.3　伝達関数による性能の概算

二段構成オペアンプを、2つの極と1つのRHP零点を持つ回路として近似する。

~~~text
A(s) = A_0 × {1 - s/ω_z}
       / [{1 + s/ω_p1}{1 + s/ω_p2}]
~~~

| 記号 | 意味 |
|---|---|
| A_0 | 低周波の開ループ利得 |
| ω_p1 | 第1極の角周波数 |
| ω_p2 | 第2極の角周波数 |
| ω_z | RHP零点の角周波数 |
| s | 複素周波数。s = σ + iω |

設計値を代入すると、伝達関数は次のようになる。

~~~text
A(s) ≈ 4.25 × 10³
       × {1 - s/(3.14 × 10⁹)}

~~~

~~~text
f_p1 ≈ 11.8 kHz
~~~

~~~text
PM ≈ 90°
     - atan(50 MHz / 150 MHz)
     - atan(50 MHz / 500 MHz)
     ≈ 65.9°
~~~

**結論**

伝達関数による概算では、直流利得約72.6 dB、GBW約50 MHz、位相余裕約65.9°となる。

## 6.5　補足説明1　回路構成と目標仕様

### 各MOSFETの役割

| 素子 | 種類 | 役割 |
|---|---|---|
| M1、M2 | NMOS | 2つの入力電圧の差を電流差へ変換する |
| M3、M4 | PMOS | 差動電流を1つの出力電流へ変換する |
| M5 | NMOS | 入力段に一定の電流I_5を流す |
| M6 | PMOS | 第1段の出力をさらに増幅する |
| M7 | NMOS | M6に流れる直流電流を受ける |
| C_c | 容量 | 第1極を低くして発振を防ぐ |
| C_L | 容量 | 出力端子が駆動する負荷を表す |
| M8、R | バイアス回路 | I_5の基準になる電流を作る |

入力電圧の差は次の式で表す。

~~~text
v_id = v_in+ - v_in-
~~~

| 記号 | 意味 |
|---|---|
| v_in+ | 非反転入力の電圧 |
| v_in- | 反転入力の電圧 |
| v_id | 2つの入力電圧の差 |

第1段はv_idを電流へ変換する。

~~~text
Δi_d = g_m1 × v_id
~~~

| 記号 | 意味 |
|---|---|
| Δi_d | 入力電圧によって生じるドレイン電流の変化 |
| g_m1 | M1、M2の相互コンダクタンス |

### 目標仕様

~~~text
V_DD = +1.5 V
V_SS = -1.5 V
電源電圧 = V_DD - V_SS = 3.0 V
~~~

|---|---|---:|---|
| 直流利得 | A_0 | 60 dB以上 | 低周波で入力差を何倍に増幅するか |

## 6.6　補足説明2　設計で使うMOSFETの式

### ドレイン電流

MOSFETが飽和領域で動作するとき、ドレイン電流を次の式で近似する。

~~~text
I_D = (1 / 2) × μC_ox × (W / L) × V_OV²
~~~

オーバードライブ電圧は次の値である。

~~~text
V_OV = V_GS - V_T
~~~

| 記号 | 意味 |
|---|---|
| I_D | MOSFETのドレイン電流 |
| μC_ox | 製造プロセスで決まる電流の流れやすさ |
| W | MOSFETのゲート幅 |
| L | MOSFETのゲート長 |
| W/L | MOSFETの電流能力を調整する寸法比 |
| V_GS | ゲート・ソース間電圧 |
| V_T | しきい値電圧 |
| V_OV | V_GSがV_Tを超えている電圧 |

### 相互コンダクタンス

相互コンダクタンスg_mは、ゲート電圧を少し変化させたとき、ドレイン電流がどれだけ変化するかを表す。

~~~text
g_m = ∂I_D / ∂V_GS
~~~

飽和領域では、次の式を使える。

~~~text
g_m = 2I_D / V_OV
~~~

~~~text
g_m = √{2 × μC_ox × (W / L) × I_D}
~~~

g_mとI_Dが分かっている場合、W/Lは次の式で求められる。

~~~text
W / L = g_m² / (2 × μC_ox × I_D)
~~~

### 出力コンダクタンスと出力抵抗

実際のMOSFETでは、飽和領域でもV_DSによってI_Dがわずかに変化する。

~~~text
g_ds = ∂I_D / ∂V_DS
~~~

~~~text
g_ds ≈ I_D / V_A
~~~

~~~text
r_o = 1 / g_ds ≈ V_A / I_D
~~~

| 記号 | 意味 |
|---|---|
| g_ds | ドレイン電圧による電流変化の大きさ |
| r_o | MOSFETの小信号出力抵抗 |
| V_A | アーリー電圧。大きいほどr_oが大きい |

増幅段の利得は、おおよそ次のようになる。

~~~text
A_v ≈ -g_m × r_o = -g_m / g_ds
~~~

したがって、g_mが大きく、g_dsが小さいMOSFETほど高い利得を得やすい。

### 使用するMOSFETパラメータ

~~~text
μ_nC_ox = 220 μA/V²
μ_pC_ox = 60 μA/V²
V_Tn = abs(V_Tp) = 0.4 V
V_An = 20 V
V_Ap = 30 V
~~~

これらは使用する製造プロセスによって決まる。実際の値はPDKに含まれるMOSFETモデルで確認する。

**結論**

設計では、仕様から必要なg_mとI_Dを求め、MOSFETの式を使ってW/Lへ変換する。

## 6.7　補足説明3　位相補償容量C_cを決める

### 何をしたいのか

負帰還をかけても発振しないように、位相余裕を60°以上にしたい。

二段構成オペアンプには、第1段出力と最終出力に容量を持つノードがある。そのため、第1極p_1と第2極p_2が生じる。

極を通過すると、利得が低下し、位相が遅れる。第2極がGBWへ近づくと、GBWに達するまでに位相が大きく遅れ、発振しやすくなる。

### 位相余裕の式

GBWの角周波数をω_uとする。

~~~text
ω_u = 2π × f_GBW
~~~

位相余裕は次の式で近似する。

~~~text
PM ≈ 90°
     - atan(ω_u / ω_p2)
     - atan(ω_u / ω_z)
~~~

| 記号 | 意味 |
|---|---|
| ω_u | 開ループ利得が1倍になる角周波数 |
| ω_p2 | 第2極の角周波数 |
| ω_z | RHP零点の角周波数 |
| atan | 逆正接。角度を求める関数 |

RHP零点をGBWの10倍以上に置く。

~~~text
ω_z ≥ 10ω_u
~~~

このとき、RHP零点による位相遅れは次の値になる。

~~~text
atan(ω_u / ω_z) ≤ atan(0.1) ≈ 5.7°
~~~

PMを60°以上にするには、第2極について次の条件が必要になる。

~~~text
ω_p2 ≥ 2.2ω_u
~~~

### C_cの計算

各周波数は次の式で近似できる。

~~~text
ω_u  ≈ g_m1 / C_c
ω_p2 ≈ g_m6 / C_L
ω_z  ≈ g_m6 / C_c
~~~

RHP零点をGBWの10倍にするため、次の条件を使う。

~~~text
g_m6 = 10g_m1
~~~

これをω_p2 ≥ 2.2ω_uへ代入すると、次の条件になる。

~~~text
C_c ≥ 0.22C_L
~~~

C_L = 1.0 pFなので、C_cは次の値以上でなければならない。

~~~text
C_c ≥ 0.22 × 1.0 pF = 0.22 pF
~~~

0.22 pFは計算上の下限である。寄生容量、温度、製造ばらつきで位相余裕が低下しても60°を下回りにくくするため、少し大きい値を選ぶ。

~~~text
C_c = 0.30 pF
~~~

C_cを大きくすると発振しにくくなるが、同じg_m1ではGBWが低下し、同じI_5ではスルーレートも低下する。

**結論**

位相余裕60°以上を確保するため、C_L = 1.0 pFに対してC_c = 0.30 pFとする。

## 6.8　補足説明4　入力段電流I_5を決める

### 何をしたいのか

C_cを必要な速度で充放電し、スルーレート5 V/μs以上を得たい。

コンデンサ電流は次の式で表される。

~~~text
I = C × dV/dt
~~~

したがって、スルーレートは次の式で近似できる。

~~~text
SR ≈ I_5 / C_c
~~~

必要な最小電流は次のようになる。

~~~text
I_5,min = SR × C_c
        = 5 V/μs × 0.30 pF
        = 1.5 μA
~~~

しかし、I_5 = 1.5 μAでは、後で求めるM3、M4のW/Lが約0.10になり、MOSFETの幅が小さくなりすぎる。

そこで、M3、M4のW/Lを1～2程度にしながら、消費電力を1 mW以下に保てる値として次を選ぶ。

~~~text
I_5 = 25 μA
~~~

このときのスルーレートは次のようになる。

~~~text
SR ≈ 25 μA / 0.30 pF
   ≈ 83.3 V/μs
~~~

仕様の5 V/μsより大きくなるのは、I_5をスルーレートだけでなく、MOSFET寸法、入力範囲、マッチング、消費電力から決めているためである。

**結論**

スルーレートに必要な最小電流は1.5 μAだが、実現しやすいMOSFET寸法にするため、I_5 = 25 μAとする。

## 6.9　補足説明5　入力MOSFET M1、M2を決める

### 何をしたいのか

GBWを50 MHzにしたい。

GBWとg_m1の関係は次の式である。

~~~text
ω_u = g_m1 / C_c
~~~

~~~text
g_m1 = 2π × f_GBW × C_c
~~~

数値を代入する。

~~~text
g_m1 = 2π × 50 MHz × 0.30 pF
     ≈ 94.2 μS
~~~

入力段電流I_5はM1とM2へ半分ずつ流れる。

~~~text
I_D1 = I_D2 = I_5 / 2
              = 12.5 μA
~~~

必要なW/Lは次の式で求める。

~~~text
W_1 / L_1 = g_m1² / (2 × μ_nC_ox × I_D1)
~~~

~~~text
W_1 / L_1
= (94.2 μS)² / (2 × 220 μA/V² × 12.5 μA)
≈ 1.61
~~~

したがって、M1とM2を同じ寸法にする。

~~~text
W_1 / L_1 = W_2 / L_2 = 1.61
~~~

M1とM2を同じ寸法にするのは、同じ入力電圧で同じ電流が流れるようにし、入力オフセットを小さくするためである。

M1、M2のオーバードライブ電圧は次の値になる。

~~~text
V_OV1 = 2I_D1 / g_m1
      = 2 × 12.5 μA / 94.2 μS
      ≈ 0.265 V
~~~

**結論**

GBW = 50 MHzとC_c = 0.30 pFからg_m1 = 94.2 μSが決まり、そのg_m1を12.5 μAで実現するため、M1、M2のW/Lを1.61とする。

## 6.10　補足説明6　同相入力範囲からM3、M4、M5を決める

### M3、M4で入力上限を決める

入力電圧を高くすると、M1、M2のドレイン・ソース間電圧が小さくなる。M1、M2が飽和領域を保てる入力上限は次の式で表される。

~~~text
V_CM,max = V_DD - V_OV3 - abs(V_Tp) + V_Tn
~~~

入力上限を+1.0 Vにしたいので、次のようになる。

~~~text
1.0 V = 1.5 V - V_OV3 - 0.4 V + 0.4 V
~~~

~~~text
V_OV3 = 0.50 V
~~~

M3、M4にはそれぞれI_5/2が流れる。W/Lは次の式で求める。

~~~text
W_3 / L_3 = I_5 / (μ_pC_ox × V_OV3²)
~~~

~~~text
W_3 / L_3
= 25 μA / {60 μA/V² × (0.50 V)²}
≈ 1.67
~~~

1.67では入力上限がちょうど+1.0 Vになる。ばらつきに対する余裕を持たせるため、少し大きい値を選ぶ。

~~~text
W_3 / L_3 = W_4 / L_4 = 1.8
~~~

このとき、入力上限は約+1.02 Vになる。

### M5で入力下限を決める

入力電圧を低くすると、M1、M2のソース電圧も低下する。M5が飽和領域を保つために必要な入力下限は次の式である。

~~~text
V_CM,min = V_SS + V_Tn + V_OV1 + V_OV5
~~~

入力下限を-0.7 Vにしたいので、V_OV5は次のようになる。

~~~text
V_OV5
= -0.7 V - (-1.5 V) - 0.4 V - 0.265 V
≈ 0.135 V
~~~

M5のW/Lは次の式で求める。

~~~text
W_5 / L_5 = 2I_5 / (μ_nC_ox × V_OV5²)
~~~

~~~text
W_5 / L_5
= 2 × 25 μA / {220 μA/V² × (0.135 V)²}
≈ 12.5
~~~

入力下限に余裕を持たせるため、少し大きい値を選ぶ。

~~~text
W_5 / L_5 = 13.5
~~~

このとき、V_OV5は約0.130 Vになり、入力下限は約-0.705 Vになる。

### W/Lを大きくすると入力範囲が広がる理由

同じ電流を流す場合、オーバードライブ電圧は次の式で表される。

~~~text
V_OV = √{2I_D / (μC_ox × W/L)}
~~~

W/Lを大きくすると、必要なV_OVが小さくなる。MOSFETが飽和領域を保つために必要な電圧も小さくなるため、入力範囲を広げられる。

ただし、Wを大きくするとゲート容量と面積も増える。

**結論**

入力上限+1.0 VからM3、M4のW/Lを1.8、入力下限-0.7 VからM5のW/Lを13.5とする。

## 6.11　補足説明7　第2段M6、M7を決める

### M6のg_m6を決める

第2段のg_m6は、第2極とRHP零点の位置を決める。

~~~text
ω_p2 ≈ g_m6 / C_L
~~~

~~~text
ω_z ≈ g_m6 / C_c
~~~

RHP零点をGBWの10倍以上にするため、次の条件を使う。

~~~text
g_m6 = 10g_m1
~~~

~~~text
g_m6 = 10 × 94.2 μS
     = 0.942 mS
~~~

g_m6を大きくすると第2極とRHP零点が高い周波数へ移動し、位相余裕を確保しやすくなる。ただし、電流またはW/Lも大きくなる。

### M6の出力上限を決める

M6はPMOSなので、M6が飽和領域を保てる出力上限は次の式で表される。

~~~text
V_out,max = V_DD - V_OV6
~~~

出力上限を+0.9 V以上にするため、次の条件が必要になる。

~~~text
V_OV6 ≤ 1.5 V - 0.9 V
V_OV6 ≤ 0.6 V
~~~

約0.09 Vの余裕を持たせ、V_OV6を次の値にする。

~~~text
V_OV6 = 0.51 V
~~~

この値は0.6 V以下という条件の中から、MOSFET寸法と消費電力が大きくなりすぎない値として選んでいる。

M6のW/Lは次の式で求める。

~~~text
W_6 / L_6 = g_m6 / (μ_pC_ox × V_OV6)
~~~

~~~text
W_6 / L_6
= 0.942 mS / (60 μA/V² × 0.51 V)
≈ 30.8
~~~

第2段電流は次の式で求める。

~~~text
I_6 = g_m6 × V_OV6 / 2
~~~

~~~text
I_6 = 0.942 mS × 0.51 V / 2
    ≈ 241 μA
~~~

出力上限は次の値になる。

~~~text
V_out,max = 1.5 V - 0.51 V
          = 0.99 V
~~~

### M7を決める

無入力時に出力電圧が一方向へ動かないように、M7にはM6と同じ直流電流を流す。

~~~text
I_7 = I_6
~~~

M5とM7のゲート電圧が同じ場合、電流比はW/L比で決まる。

~~~text
(W_7 / L_7) / (W_5 / L_5) = I_7 / I_5
~~~

~~~text
W_7 / L_7
= (W_5 / L_5) × (I_6 / I_5)
= 13.5 × 241 μA / 25 μA
≈ 130
~~~

M7のV_OV7はM5とほぼ同じ0.130 Vになる。出力下限は次の値になる。

~~~text
V_out,min = V_SS + V_OV7
          = -1.5 V + 0.130 V
          = -1.37 V
~~~

**結論**

位相余裕からg_m6 = 0.942 mS、出力上限からM6のW/L = 30.8とI_6 = 241 μAを求め、同じ電流を流すためM7のW/Lを130とする。

## 6.12　補足説明8　バイアス抵抗Rを決める

### 何をしたいのか

M5へ25 μAを流すための基準電流を作りたい。

M8をダイオード接続し、M8とM5のゲートを接続する。M8をM5と同じ動作条件にすると、次の関係になる。

~~~text
V_OV8 = V_OV5 ≈ 0.130 V
~~~

M8のゲート・ソース間電圧は次の値になる。

~~~text
V_GS8 = V_Tn + V_OV8
      = 0.4 V + 0.130 V
      = 0.530 V
~~~

抵抗に加わる電圧は次の値になる。

~~~text
V_R = V_DD - V_SS - V_GS8
    = 1.5 V - (-1.5 V) - 0.530 V
    = 2.470 V
~~~

オームの法則から抵抗を求める。

~~~text
R = V_R / I_5
  = 2.470 V / 25 μA
  ≈ 98.8 kΩ
~~~

初期値として次を選ぶ。

~~~text
R = 100 kΩ
~~~

実際のMOSFETでは二乗則からずれるため、最終的な抵抗値はDC動作点解析でI_5を確認して調整する。

**結論**

25 μAを作るため、M8のV_GSを含めて計算し、Rを約100 kΩとする。

## 6.13　補足説明9　直流利得を確認する

### 第1段の利得

第1段出力ノードにはM2とM4が接続されているため、出力コンダクタンスは次の和になる。

~~~text
g_o1 = g_ds2 + g_ds4
~~~

M2とM4には、それぞれ12.5 μAが流れる。

~~~text
g_o1
= 12.5 μA / 20 V + 12.5 μA / 30 V
≈ 1.04 μS
~~~

第1段利得は次のようになる。

~~~text
A_1 ≈ -g_m1 / g_o1
    ≈ -94.2 μS / 1.04 μS
    ≈ -90.5
~~~

### 第2段の利得

第2段出力ノードにはM6とM7が接続されている。

~~~text
g_o2 = g_ds6 + g_ds7
~~~

~~~text
g_o2
= 241 μA / 30 V + 241 μA / 20 V
≈ 20.1 μS
~~~

第2段利得は次のようになる。

~~~text
A_2 ≈ -g_m6 / g_o2
    ≈ -0.942 mS / 20.1 μS
    ≈ -46.9
~~~

### 全体の利得

二つの増幅段の利得を掛ける。

~~~text
A_0 = A_1 × A_2
    ≈ (-90.5) × (-46.9)
    ≈ 4.25 × 10³
~~~

dBへ変換する。

~~~text
A_0,dB = 20log_10(abs(A_0))
       ≈ 20log_10(4.25 × 10³)
       ≈ 72.6 dB
~~~

第1段と第2段は両方とも反転増幅する。負号が2つ掛かるため、全体の差動利得は正になる。

**結論**

第1段利得約-90.5と第2段利得約-46.9を掛けると、全体の直流利得は約72.6 dBとなり、60 dB以上の仕様を満たす。

## 6.14　補足説明10　伝達関数と周波数特性

### 開ループ伝達関数

二段構成オペアンプは、2つの極と1つのRHP零点を持つ回路として表せる。

~~~text
A(s) = A_0 × {1 - s/ω_z}
       / [{1 + s/ω_p1}{1 + s/ω_p2}]
~~~

| 記号 | 意味 |
|---|---|
| A(s) | 差動入力から出力までの開ループ伝達関数 |
| A_0 | 直流開ループ利得 |
| s | 複素周波数。s = σ + iω |
| ω_p1 | 第1極の角周波数 |
| ω_p2 | 第2極の角周波数 |
| ω_z | RHP零点の角周波数 |
| i | 虚数単位。i² = -1 |

第1極は次の式で近似する。

~~~text
ω_p1 ≈ g_o1 × g_o2 / (g_m6 × C_c)
~~~

~~~text
ω_p1 ≈ 7.40 × 10⁴ rad/s
f_p1 = ω_p1 / 2π ≈ 11.8 kHz
~~~

第2極は次の式で近似する。

~~~text
ω_p2 ≈ g_m6 / C_L
     ≈ 9.42 × 10⁸ rad/s
~~~

~~~text
f_p2 = ω_p2 / 2π ≈ 150 MHz
~~~

RHP零点は次の式で近似する。

~~~text
ω_z ≈ g_m6 / C_c
    ≈ 3.14 × 10⁹ rad/s
~~~

~~~text
f_z = ω_z / 2π ≈ 500 MHz
~~~

したがって、数値を入れた伝達関数は次のようになる。

~~~text
A(s) ≈ 4.25 × 10³
       × {1 - s/(3.14 × 10⁹)}
       / [{1 + s/(7.40 × 10⁴)}
          {1 + s/(9.42 × 10⁸)}]
~~~

### GBW

~~~text
ω_u ≈ g_m1 / C_c
    ≈ 3.14 × 10⁸ rad/s
~~~

~~~text
f_GBW = ω_u / 2π
      ≈ 50 MHz
~~~

### 位相余裕

~~~text
PM ≈ 90°
     - atan(50 MHz / 150 MHz)
     - atan(50 MHz / 500 MHz)
~~~

~~~text
PM ≈ 90° - 18.4° - 5.7°
   ≈ 65.9°
~~~

### 負帰還をかけた伝達関数

負帰還係数をβ_fとすると、閉ループ伝達関数は次のようになる。

~~~text
H(s) = A(s) / {1 + β_fA(s)}
~~~

電圧フォロワではβ_f = 1なので、次の式になる。

~~~text
H_VF(s) = A(s) / {1 + A(s)}
~~~

低周波でA_0が十分に大きい場合は、H_VF(0) ≈ 1となる。

**結論**

第1極は約11.8 kHz、GBWは約50 MHz、第2極は約150 MHz、RHP零点は約500 MHzとなる。この位置関係によって位相余裕約65.9°が得られる。

~~~text
V_out,max = V_DD - V_OV6
~~~

## 6.16　補足説明12　シミュレーションで確認する

ここまでの式では、MOSFETを飽和領域の二乗則モデルで計算している。実際のMOSFETには、寄生容量、ボディ効果、移動度低下、短チャネル効果、温度変化、製造ばらつきがある。

### DC動作点解析

全MOSFETが飽和領域にあることを確認する。

NMOSの飽和条件は次の式である。

~~~text
V_DS ≥ V_OV
~~~

PMOSの飽和条件は次の式である。

~~~text
V_SD ≥ V_OV
~~~

I_5、I_6、出力の静止電圧も確認する。

### DCスイープ解析

同相入力電圧を変化させ、入力範囲-0.7～+1.0 VでM1、M2、M5が正常に動作することを確認する。

出力電圧を変化させ、-1.1～+0.9 VでM6、M7が飽和領域を保つことを確認する。

### AC解析

次の特性を確認する。

- 直流利得
- 第1極
- GBW
- 第2極
- 位相余裕

ループ利得T(s)が0 dBになる角周波数をω_uとすると、位相余裕は次の式で求める。

~~~text
PM = 180° + angle{T(iω_u)}
~~~

### 過渡解析

電圧フォロワを構成してステップ入力を加え、次の式からスルーレートを求める。

~~~text
SR = max abs(dV_out/dt)
~~~

オーバーシュート、リンギング、セトリング時間も確認する。

### コーナー解析とモンテカルロ解析

プロセス、電源電圧、温度を変化させ、すべての条件で仕様を満たすか確認する。M1とM2、M3とM4などの素子間ミスマッチも確認する。

**結論**

手計算で最初の値を決め、SPICEで実際のMOSFETモデルと寄生容量を含めて確認し、必要ならW/L、電流、C_cを調整する。

## 6.17　補足説明13　細かい計算と、なぜこの順番と値になるのか

### なぜ最初にC_Lを決めるのか

C_Lは第2極を決める。

~~~text
ω_p2 = g_m6 / C_L
~~~

C_Lが分からなければ、位相余裕を満たすために必要なg_m6とC_cを決められない。そのため、最初に出力端子の負荷容量と寄生容量の合計をC_L = 1.0 pFとする。

### なぜ次にC_cを決めるのか

C_cはGBW、位相余裕、スルーレートの全てに関係する。

~~~text
ω_u = g_m1 / C_c
~~~

~~~text
SR = I_5 / C_c
~~~

~~~text
ω_z = g_m6 / C_c
~~~

位相余裕60°以上を得るため、第2極をGBWの2.2倍以上、RHP零点をGBWの10倍以上にする。

~~~text
ω_p2 ≥ 2.2ω_u
ω_z  ≥ 10ω_u
~~~

この条件から次の式が得られる。

~~~text
C_c ≥ 0.22C_L
~~~

C_L = 1.0 pFに対する下限は0.22 pFである。ばらつきに対する余裕を加えるため、C_c = 0.30 pFとする。

### なぜI_5を25 μAにするのか

スルーレートだけから求めた最小電流は1.5 μAである。

~~~text
I_5,min = SR × C_c
        = 1.5 μA
~~~

しかし、1.5 μAではM3、M4のW/Lが約0.10になり、MOSFETの幅が小さくなりすぎる。そこで、M3、M4のW/Lを1～2程度にし、消費電力を1 mW以下に保てる値としてI_5 = 25 μAを選ぶ。

つまり、I_5はスルーレートだけではなく、MOSFET寸法、入力範囲、マッチング、消費電力を同時に考えて決めている。

### なぜM1、M2のW/Lが1.61になるのか

GBW = 50 MHzとC_c = 0.30 pFから、必要なg_m1が決まる。

~~~text
g_m1 = 2π × f_GBW × C_c
     = 94.2 μS
~~~

M1、M2には各12.5 μAが流れるため、次の式からW/Lが決まる。

~~~text
W_1 / L_1
= g_m1² / (2 × μ_nC_ox × I_D1)
= 1.61
~~~

つまり、M1、M2の寸法はGBW、C_c、I_5から決まっている。

### なぜM3、M4のW/Lが1.8になるのか

入力上限+1.0 Vを満たすため、V_OV3は0.50 V以下でなければならない。

~~~text
V_CM,max
= V_DD - V_OV3 - abs(V_Tp) + V_Tn
~~~

計算上必要なW/Lは1.67である。1.67では入力上限がちょうど+1.0 Vになるため、ばらつきに対する余裕を加えて1.8とする。

つまり、M3、M4の寸法は同相入力範囲の正側から決まっている。

### なぜM5のW/Lが13.5になるのか

入力下限-0.7 Vを満たすため、V_OV5は約0.135 V以下でなければならない。

~~~text
V_CM,min
= V_SS + V_Tn + V_OV1 + V_OV5
~~~

計算上必要なW/Lは約12.5である。入力下限に余裕を持たせるため、13.5とする。

つまり、M5の寸法は同相入力範囲の負側から決まっている。

### なぜg_m6をg_m1の10倍にするのか

RHP零点とGBWの比は次のようになる。

~~~text
ω_z / ω_u
= (g_m6 / C_c) / (g_m1 / C_c)
= g_m6 / g_m1
~~~

RHP零点をGBWの10倍にするには、次の関係が必要になる。

~~~text
g_m6 = 10g_m1
~~~

したがって、g_m1 = 94.2 μSからg_m6 = 0.942 mSとなる。

### なぜM6のW/Lが30.8、I_6が241 μAになるのか

出力上限+0.9 Vを満たすには、V_OV6を0.6 V以下にする必要がある。

~~~text
V_out,max = V_DD - V_OV6
~~~

出力上限に余裕を持たせ、V_OV6 = 0.51 Vとする。すでにg_m6 = 0.942 mSと決めているため、W/Lと電流は次の式で決まる。

~~~text
W_6 / L_6
= g_m6 / (μ_pC_ox × V_OV6)
= 30.8
~~~

~~~text
I_6 = g_m6 × V_OV6 / 2
    = 241 μA
~~~

つまり、M6のg_mは安定性から、V_OVは出力上限から、W/Lと電流はその2つから決まっている。

### なぜM7のW/Lが130になるのか

静止状態でM6とM7に同じ電流を流す。

~~~text
I_7 = I_6
~~~

M5とM7がカレントミラーを構成するため、電流比とW/L比は等しくなる。

~~~text
W_7 / L_7
= (W_5 / L_5) × (I_6 / I_5)
= 130
~~~

つまり、M7の寸法はM5との電流比から決まっている。

### なぜ最終的に仕様を満たすのか

入力段のg_m1とC_cからGBWが決まる。

~~~text
f_GBW = g_m1 / (2πC_c)
      = 50 MHz
~~~

第2段のg_m6、C_L、C_cから第2極とRHP零点が決まる。

~~~text
f_p2 = 150 MHz
f_z  = 500 MHz
~~~

この位置関係から位相余裕が決まる。

~~~text
PM ≈ 65.9°
~~~

入力段と第2段の利得を掛けると直流利得が決まる。

~~~text
A_0 = (g_m1 / g_o1) × (g_m6 / g_o2)
    ≈ 4.25 × 10³
    ≈ 72.6 dB
~~~

I_5とC_cからスルーレートが決まる。

~~~text
SR = I_5 / C_c
   ≈ 83.3 V/μs
~~~

M6とM7のV_OVから出力範囲が決まる。

~~~text
V_out,min ≈ -1.37 V
V_out,max ≈ +0.99 V
~~~

電源電圧と全電流から消費電力が決まる。

~~~text
P_diss
= (V_DD - V_SS) × (I_5 + I_6)
≈ 0.80 mW
~~~

### 補足計算1　C_cの下限0.22C_Lが出るまで

RHP零点をGBWの10倍にする条件は次の式である。

~~~text
ω_z ≥ 10ω_u
~~~

~~~text
g_m6 / C_c ≥ 10g_m1 / C_c
~~~

両辺へC_cを掛けると、次の条件になる。

~~~text
g_m6 ≥ 10g_m1
~~~

消費電力を増やしすぎないため、最小値としてg_m6 = 10g_m1を選ぶ。

位相余裕60°から得られた第2極の条件は次の式である。

~~~text
ω_p2 ≥ 2.2ω_u
~~~

各角周波数を代入する。

~~~text
g_m6 / C_L ≥ 2.2g_m1 / C_c
~~~

さらにg_m6 = 10g_m1を代入する。

~~~text
10g_m1 / C_L ≥ 2.2g_m1 / C_c
~~~

両辺からg_m1を消去して整理する。

~~~text
10 / C_L ≥ 2.2 / C_c
~~~

~~~text
10C_c ≥ 2.2C_L
~~~

~~~text
C_c ≥ 0.22C_L
~~~

したがって、C_L = 1.0 pFではC_c ≥ 0.22 pFとなる。設計では余裕を加えてC_c = 0.30 pFとする。

### 補足計算2　直流利得72.6 dBが出るまで

第1段出力の出力コンダクタンスは、M2とM4のg_dsの和である。

~~~text
g_o1
= I_D2 / V_An + I_D4 / V_Ap
= 12.5 μA / 20 V + 12.5 μA / 30 V
= 0.625 μS + 0.417 μS
= 1.042 μS
~~~

第1段利得は次の値になる。

~~~text
A_1 = -g_m1 / g_o1
    = -94.2 μS / 1.042 μS
    ≈ -90.4
~~~

第2段出力の出力コンダクタンスは、M6とM7のg_dsの和である。

~~~text
g_o2
= I_6 / V_Ap + I_6 / V_An
= 241 μA / 30 V + 241 μA / 20 V
= 8.03 μS + 12.05 μS
= 20.08 μS
~~~

第2段利得は次の値になる。

~~~text
A_2 = -g_m6 / g_o2
    = -942 μS / 20.08 μS
    ≈ -46.9
~~~

二つの利得を掛ける。

~~~text
A_0 = A_1 × A_2
    ≈ (-90.4) × (-46.9)
    ≈ 4.24 × 10³
~~~

dBへ変換する。

~~~text
A_0,dB
= 20log_10(4.24 × 10³)
≈ 72.6 dB
~~~

### 補足計算3　第1極、第2極、RHP零点、位相余裕

第1極は次の式で計算する。

~~~text
ω_p1
= g_o1 × g_o2 / (g_m6 × C_c)
= 1.042 μS × 20.08 μS
  / (0.942 mS × 0.30 pF)
≈ 7.40 × 10⁴ rad/s
~~~

~~~text
f_p1 = ω_p1 / 2π
     ≈ 11.8 kHz
~~~

第2極は次の式で計算する。

~~~text
ω_p2 = g_m6 / C_L
     = 0.942 mS / 1.0 pF
     = 9.42 × 10⁸ rad/s
~~~

~~~text
f_p2 = ω_p2 / 2π
     ≈ 150 MHz
~~~

RHP零点は次の式で計算する。

~~~text
ω_z = g_m6 / C_c
    = 0.942 mS / 0.30 pF
    = 3.14 × 10⁹ rad/s
~~~

~~~text
f_z = ω_z / 2π
    ≈ 500 MHz
~~~

GBWは50 MHzなので、位相余裕は次の値になる。

~~~text
PM
≈ 90°
  - atan(50 MHz / 150 MHz)
  - atan(50 MHz / 500 MHz)
~~~

~~~text
PM
≈ 90° - atan(0.333) - atan(0.100)
≈ 90° - 18.4° - 5.7°
≈ 65.9°
~~~

### 補足計算4　バイアス抵抗Rが約100 kΩになるまで

M8とM5を同じ動作条件にすると、M8のオーバードライブ電圧は約0.130 Vになる。

~~~text
V_GS8 = V_Tn + V_OV8
      = 0.4 V + 0.130 V
      = 0.530 V
~~~

抵抗に加わる電圧は次の値になる。

~~~text
V_R
= V_DD - V_SS - V_GS8
= 1.5 V - (-1.5 V) - 0.530 V
= 2.470 V
~~~

25 μAを流すために必要な抵抗は次の値になる。

~~~text
R = V_R / I_5
  = 2.470 V / 25 μA
  = 98.8 kΩ
~~~

そのため、初期値としてR = 100 kΩを選ぶ。

**最終結論**

二段構成オペアンプの設計値は、MOSFETのW/Lを先に決めているのではない。

最初に、負荷容量と位相余裕からC_cを決める。次に、スルーレートと実現可能なMOSFET寸法からI_5を決める。GBWからM1、M2を決め、同相入力範囲からM3、M4、M5を決める。最後に、位相余裕と出力範囲からM6、M7を決める。

```python
import numpy as np
import matplotlib.pyplot as plt


# ============================================================
# 1. Specifications and process parameters
# ============================================================

VDD = 1.5                 # Positive supply voltage [V]
VSS = -1.5                # Negative supply voltage [V]

CL = 1.0e-12              # Load capacitance [F]
Cc = 0.30e-12             # Compensation capacitance [F]

f_GBW_target = 50.0e6     # Target GBW [Hz]

mu_n_Cox = 220.0e-6       # NMOS process parameter [A/V^2]
mu_p_Cox = 60.0e-6        # PMOS process parameter [A/V^2]

Vtn = 0.4                 # NMOS threshold voltage [V]
Vtp_abs = 0.4             # Absolute PMOS threshold voltage [V]

VA_n = 20.0               # NMOS Early voltage [V]
VA_p = 30.0               # PMOS Early voltage [V]


# ============================================================
# 2. Selected design values
# ============================================================

I5 = 25.0e-6              # Input-stage current [A]

W3_L3 = 1.8               # M3 and M4 aspect ratio
W5_L5 = 13.5              # M5 aspect ratio
W6_L6 = 30.8              # M6 aspect ratio


# ============================================================
# 3. Input-stage calculation
# ============================================================

omega_u_target = 2.0 * np.pi * f_GBW_target

# From omega_u = gm1 / Cc
gm1 = omega_u_target * Cc

ID1 = I5 / 2.0

# From gm^2 = 2 * mu_n_Cox * (W/L) * ID
W1_L1 = gm1**2 / (2.0 * mu_n_Cox * ID1)

# From gm = 2ID / Vov
Vov1 = 2.0 * ID1 / gm1


# ============================================================
# 4. Current-mirror and tail-current-source calculation
# ============================================================

# M3 and M4 carry I5/2 each.
# Therefore Vov3 = sqrt(I5 / (mu_p_Cox * W3_L3)).
Vov3 = np.sqrt(I5 / (mu_p_Cox * W3_L3))

# M5 carries I5.
Vov5 = np.sqrt(2.0 * I5 / (mu_n_Cox * W5_L5))

Vcm_max = VDD - Vov3 - Vtp_abs + Vtn
Vcm_min = VSS + Vtn + Vov1 + Vov5


# ============================================================
# 5. Second-stage calculation
# ============================================================

# Place the RHP zero at approximately 10 times GBW.
gm6 = 10.0 * gm1

# From gm6 = mu_p_Cox * (W6/L6) * Vov6
Vov6 = gm6 / (mu_p_Cox * W6_L6)

# From gm6 = 2I6 / Vov6
I6 = gm6 * Vov6 / 2.0

# M5 and M7 form a current mirror.
W7_L7 = W5_L5 * I6 / I5

Vout_max = VDD - Vov6
Vout_min = VSS + Vov5


# ============================================================
# 6. Bias resistor, slew rate, and power
# ============================================================

VGS8 = Vtn + Vov5
R_bias = (VDD - VSS - VGS8) / I5

SR_input = I5 / Cc
SR_output = I6 / CL
SR_estimated = min(SR_input, SR_output)

P_diss = (VDD - VSS) * (I5 + I6)


# ============================================================
# 7. DC gain, poles, zero, and transfer function
# ============================================================

# Output conductance of the first stage
go1 = ID1 / VA_n + ID1 / VA_p

# Output conductance of the second stage
go2 = I6 / VA_p + I6 / VA_n

A1 = -gm1 / go1
A2 = -gm6 / go2
A0 = A1 * A2
A0_dB = 20.0 * np.log10(abs(A0))

# Pole and zero angular frequencies [rad/s]
omega_p1 = go1 * go2 / (gm6 * Cc)
omega_p2 = gm6 / CL
omega_z = gm6 / Cc

# Pole and zero frequencies [Hz]
f_p1 = omega_p1 / (2.0 * np.pi)
f_p2 = omega_p2 / (2.0 * np.pi)
f_z = omega_z / (2.0 * np.pi)


# ============================================================
# 8. Frequency response
# ============================================================

frequency = np.logspace(2, 10, 5000)  # 100 Hz to 10 GHz
omega = 2.0 * np.pi * frequency
s = 1j * omega

# A(s) = A0(1 - s/wz) / {(1 + s/wp1)(1 + s/wp2)}
A = (
    A0
    * (1.0 - s / omega_z)
    / ((1.0 + s / omega_p1) * (1.0 + s / omega_p2))
)

magnitude_dB = 20.0 * np.log10(np.abs(A))
phase_deg = np.rad2deg(np.unwrap(np.angle(A)))


# ============================================================
# 9. Unity-gain frequency and phase margin
# ============================================================

crossings = np.where(np.diff(np.signbit(magnitude_dB)))[0]

if len(crossings) == 0:
    raise RuntimeError("The 0 dB crossing was not found in the frequency range.")

i_cross = crossings[0]

x1 = np.log10(frequency[i_cross])
x2 = np.log10(frequency[i_cross + 1])
y1 = magnitude_dB[i_cross]
y2 = magnitude_dB[i_cross + 1]

# Linear interpolation on the log-frequency axis
x_unity = x1 + (0.0 - y1) * (x2 - x1) / (y2 - y1)
f_unity = 10.0**x_unity

phase_unity = np.interp(x_unity, np.log10(frequency), phase_deg)
phase_margin = 180.0 + phase_unity


# ============================================================
# 10. Print calculated results
# ============================================================

print("===== Two-Stage CMOS Op-Amp Calculation =====")
print(f"gm1              = {gm1 * 1e6:8.3f} uS")
print(f"gm6              = {gm6 * 1e3:8.3f} mS")
print(f"W1/L1 = W2/L2   = {W1_L1:8.3f}")
print(f"W3/L3 = W4/L4   = {W3_L3:8.3f}")
print(f"W5/L5           = {W5_L5:8.3f}")
print(f"W6/L6           = {W6_L6:8.3f}")
print(f"W7/L7           = {W7_L7:8.3f}")
print(f"I5               = {I5 * 1e6:8.3f} uA")
print(f"I6               = {I6 * 1e6:8.3f} uA")
print(f"R_bias           = {R_bias / 1e3:8.3f} kohm")
print()
print(f"DC gain          = {A0:8.3f} V/V")
print(f"DC gain          = {A0_dB:8.3f} dB")
print(f"First pole       = {f_p1 / 1e3:8.3f} kHz")
print(f"Second pole      = {f_p2 / 1e6:8.3f} MHz")
print(f"RHP zero         = {f_z / 1e6:8.3f} MHz")
print(f"Unity-gain freq. = {f_unity / 1e6:8.3f} MHz")
print(f"Phase at unity   = {phase_unity:8.3f} deg")
print(f"Phase margin     = {phase_margin:8.3f} deg")
print()
print(f"Input CM range   = {Vcm_min:8.3f} to {Vcm_max:8.3f} V")
print(f"Output range     = {Vout_min:8.3f} to {Vout_max:8.3f} V")
print(f"Input-stage SR   = {SR_input / 1e6:8.3f} V/us")
print(f"Output-stage SR  = {SR_output / 1e6:8.3f} V/us")
print(f"Estimated SR     = {SR_estimated / 1e6:8.3f} V/us")
print(f"Power            = {P_diss * 1e3:8.3f} mW")


# ============================================================
# 11. Bode magnitude and phase plots
# ============================================================

fig, (ax_mag, ax_phase) = plt.subplots(
    2,
    1,
    figsize=(10, 8),
    sharex=True,
)

# Magnitude plot
ax_mag.semilogx(frequency, magnitude_dB, color="tab:blue", linewidth=2)
ax_mag.axhline(0.0, color="black", linestyle="--", linewidth=1)
ax_mag.scatter(f_unity, 0.0, color="red", zorder=5)
ax_mag.annotate(

ax_phase.set_xlabel("Frequency [Hz]")
ax_phase.set_ylabel("Phase [deg]")
ax_phase.grid(True, which="both", linestyle=":")

# Pole and zero markers
markers = [
    (f_p1, "f_p1", "tab:green"),
    (f_p2, "f_p2", "tab:purple"),
    (f_z, "f_z (RHP)", "tab:brown"),
]

for f_marker, label, color in markers:
    ax_mag.axvline(
        f_marker,
        color=color,
        linestyle="--",
        linewidth=1,
        label=label,
    )
    ax_phase.axvline(
        f_marker,
        color=color,
        linestyle="--",
        linewidth=1,
    )

ax_mag.legend(loc="best")

plt.tight_layout()
plt.savefig("two_stage_opamp_bode.png", dpi=200, bbox_inches="tight")
plt.show()
```

このコードで伝達関数全体を数値計算すると、0 dB通過周波数は約47.9 MHz、位相余裕は約66.9°になる。本文の50 MHzと65.9°は、第1極が支配的であるとした設計時の概算値である。第2極とRHP零点を含む伝達関数全体で0 dB交差を求めると、わずかに異なる値になる。

### グラフの見方

上側のグラフが利得線図、下側のグラフが位相線図である。

- 利得線図が0 dBを通過する周波数がGBWである
- 0 dB通過周波数における位相から位相余裕を求める
- 第1極を通過すると利得の傾きが約-20 dB/decになる
- 第2極を通過すると傾きがさらに約-20 dB/dec増える
- RHP零点は利得を持ち上げるが、位相をさらに遅らせる
