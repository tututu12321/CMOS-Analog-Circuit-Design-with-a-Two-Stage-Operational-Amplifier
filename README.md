# 小さな信号を、次の回路へ

## オペアンプ

センサやマイクから出てくる信号は、とても小さい。
その小さな変化を受け取り、扱いやすい電圧に変える。
オペアンプは、電子機器の中でそんな仕事をしている。

## 0.1　二段構成オペアンプの概要

### わずかな電圧の違いを大きくする
<img width="1111" height="747" alt="image" src="https://github.com/user-attachments/assets/bf00479c-59f1-4c89-96fb-ea42275197c9" />

オペアンプには2つの入力があり、その電圧の違いを受け取って増幅する。

二段構成CMOSオペアンプでは、増幅する部分が内部で二つに分かれている。NMOSとPMOSで作られており、小さなICの中に組み込むことができる。
この回路は、NMOSとPMOSという2種類のMOSFETを組み合わせて作られる。MOSFETは、入力された電圧によって電流の流れ方を調整する部品である。
NMOSはゲートの電圧が高くなると電流を流しやすくなり、PMOSはゲートの電圧が低くなると電流を流しやすくなる。この反対の動きをする2種類を組み合わせることで、入力から出力までの信号を一つのICの中で扱える。

**結論**

二段構成CMOSオペアンプは、小さな入力電圧の差を二段に分けて増幅する回路である。

---

## 0.2　第1段と第2段の役割

### 前半で入力を受け取り、後半で大きくする

第1段は、2つの入力電圧の違いを受け取る部分である。

第2段は、第1段から渡された信号をさらに大きくして、出力へ送る部分である。

```text
入力 → 第1段 → 第2段 → 出力
```

**結論**

第1段が入力を受け取り、第2段が出力に必要な大きさまで増幅する。

---

## 0.3　入力から出力までの信号経路

### 信号は二つの増幅段を順番に通る

入力された信号は、まず第1段に入る。

第1段で変化した信号は第2段へ渡され、さらに増幅される。最後に、オペアンプの出力端子から外へ出ていく。

```text
2つの入力
    ↓
第1段
    ↓
第2段
    ↓
出力
```

**結論**

入力信号は、第1段から第2段へ順番に伝わり、最後に出力信号になる。

---

## 0.4　二段構成にする理由

### 二つの回路で仕事を分ける

一つの増幅回路だけで、小さな入力を受け取り、大きな出力を作るのは難しい。

そこで、入力を受け取る部分と、出力を大きくする部分に仕事を分ける。二段に分けることで、それぞれの役割に合った回路を作りやすくなる。

**結論**

二段構成にする理由は、入力と出力の仕事を分け、十分な増幅を得やすくするためである。

---

## 0.5　主な要求仕様

### 大きく、速く、安定して動くことが求められる

オペアンプは、ただ信号を大きくできればよいわけではない。

* 信号を十分に増幅できること
* 入力の変化にすばやく反応できること
* 出力が不安定にならないこと
* 必要な範囲の電圧を扱えること
* 消費する電力が大きすぎないこと

これらの性能を、使う目的に合わせて決めていく。

**結論**

オペアンプの設計では、増幅の大きさだけでなく、速度、安定性、電圧範囲、消費電力も重要になる。

---

## 序章の結論

二段構成CMOSオペアンプは、小さな入力電圧の差を受け取り、二つの増幅段を通して大きな出力信号に変える回路である。

第1段と第2段がどのような回路で作られ、どのように信号を増幅するのかを、次の章から順番に見ていく。

## Fundamentals of Operational Amplifiers and MOSFETs

二段構成CMOSオペアンプは、NMOSとPMOSを組み合わせて作られている。

回路図には多くのMOSFETが描かれているが、基本となる考え方は共通している。入力電圧の小さな変化によってMOSFETの電流が変わり、その電流の変化が出力電圧の変化に変換される。

この章では、最初にオペアンプの入力と出力の関係を確認する。その後、NMOSとPMOSの動作、ドレイン電流、相互コンダクタンス、出力抵抗、小信号モデルの順に学ぶ。

## この章で使う表し方

MOSFET回路では、回路を動かすための一定の値と、その値の周りで変化する小さな信号を分けて考える。

| 表し方 | 意味 | 例 |
|---|---|---|
| 大文字 | 信号がないときの直流値 | `V_GS`、`V_DS`、`I_D` |
| 小文字 | 直流値の周りに加わる小さな変化 | `v_gs`、`v_ds`、`i_d` |
| 合計値 | 直流値と小信号を合わせた実際の値 | `v_GS,total` |

ゲート・ソース間電圧の実際の値は、次のように表せる。

```text
v_GS,total(t) = V_GS + v_gs(t)
```

ドレイン電流も同じように分けられる。

```text
i_D,total(t) = I_D + i_d(t)
```

大文字で表す値は、回路の動作の中心となる値であり、**バイアス値**や**動作点**と呼ばれる。小文字で表す値は、その動作点からどれだけ変化したかを表す。

| 記号 | 読み方 | 倍率 | 例 |
|---|---|---:|---|
| k | キロ | `10^3` | `1 kΩ = 1,000 Ω` |
| M | メガ | `10^6` | `1 MΩ = 1,000,000 Ω` |
| m | ミリ | `10^(-3)` | `1 mV = 0.001 V` |
| `μ` | マイクロ | `10^(-6)` | `1 μA = 0.000001 A` |
| n | ナノ | `10^(-9)` | `1 nA = 0.000000001 A` |

## 1.1　差動入力と出力電圧

### オペアンプには2つの入力がある

オペアンプには、次の2つの入力端子がある。

- 非反転入力：`v_in+`
- 反転入力：`v_in-`

オペアンプが受け取るのは、それぞれの入力電圧そのものではなく、2つの入力電圧の差である。この差を**差動入力電圧** `v_id` と呼ぶ。

```text
v_id = v_in+ - v_in-
```

非反転入力の方が高い場合は、`v_id` が正になる。

```text
v_in+ > v_in- ⇒ v_id > 0
```

反転入力の方が高い場合は、`v_id` が負になる。

```text
v_in+ < v_in- ⇒ v_id < 0
```

2つの入力電圧が等しい場合は、差動入力電圧が0になる。

```text
v_in+ = v_in- ⇒ v_id = 0
```

### 差動入力電圧が出力を決める

オペアンプの開ループ利得を `A_0` とすると、出力電圧は次の式で表される。

```text
v_out = A_0 × v_id
```

差動入力電圧の式を代入すると、次のようになる。

```text
v_out = A_0 × (v_in+ - v_in-)
```

`A_0` は非常に大きな値である。実際のオペアンプでは、低い周波数における開ループ利得が数万倍から数十万倍になることがある。

### 数値例

次の値を考える。

```text
A_0 = 100,000
```

```text
v_in+ = 1.00001 V
```

```text
v_in- = 1.00000 V
```

差動入力電圧は次のようになる。

```text
v_id = 1.00001 - 1.00000
```

```text
v_id = 10 μV
```

したがって、計算上の出力電圧は次のようになる。

```text
v_out = 100,000 × 10 μV
```

```text
v_out = 1 V
```

入力電圧の差はわずか `10 μV` だが、大きな開ループ利得によって `1 V` の出力になる。

### 出力電圧には限界がある

実際のオペアンプは、電源からエネルギーを受け取って動作する。そのため、出力電圧をどこまでも大きくすることはできない。

正側の電源を `V_DD`、負側の電源を `V_SS` とすると、出力電圧はおおよそ次の範囲に制限される。

```text
V_SS < v_out < V_DD
```

実際には、電源電圧の端まで出力できない場合も多い。

計算上の出力が出力可能範囲を超えると、出力は上限または下限付近で止まる。この状態を**出力の飽和**という。

> ここでいう「出力の飽和」と、MOSFETの「飽和領域」は別の意味である。MOSFETの飽和領域は、アナログ増幅に利用する正常な動作領域である。

### 同相入力と差動入力

2つの入力に共通して含まれる電圧を**同相入力電圧** `v_icm` と呼ぶ。

```text
v_icm = (v_in+ + v_in-) / (2)
```

理想的なオペアンプは、差動入力電圧だけを増幅し、同相入力電圧には反応しない。

しかし、実際のオペアンプでは同相成分の影響を完全には取り除けない。また、正常に動作できる同相入力電圧の範囲にも限界がある。この範囲を**入力同相範囲**という。

### 結論

オペアンプは、非反転入力と反転入力の電圧差を大きくして出力する。入力電圧差の正負によって出力の変化する方向が決まり、出力できる電圧は電源電圧によって制限される。

## 1.2　開ループ動作と負帰還

### 開ループでは利得が大きすぎる

出力信号を入力側へ戻さずにオペアンプを使う状態を、**開ループ動作**という。

開ループ時の出力電圧は、次の式で表される。

```text
v_out = A_0 × (v_in+ - v_in-)
```

開ループ利得 `A_0` が `100,000` 倍のとき、差動入力電圧が `0.1 mV` になると、計算上の出力は次のようになる。

```text
v_out = 100,000 × 0.1 mV
```

```text
v_out = 10 V
```

電源電圧が `+1.5 V` と `-1.5 V` なら、`10 V` は出力できない。出力はすぐに電源電圧付近で飽和する。

このため、開ループのままでは「入力を正確に5倍する」といった連続的な増幅が難しい。

### 負帰還は出力のずれを小さくする

回路全体の利得を扱いやすくするために、出力信号の一部を反転入力へ戻す。この接続を**負帰還**という。

負帰還の「負」は、出力が負電圧になるという意味ではない。出力の変化を打ち消す方向へ信号を戻すことを表している。

非反転入力の電圧が高くなった場合を考える。

1. `v_in+` が高くなる。
2. `v_in+ > v_in-` となり、出力電圧が高くなる。
3. 出力電圧の一部が反転入力へ戻る。
4. `v_in-` も高くなる。
5. `v_in+ - v_in-` が小さくなる。
6. 出力の上昇が弱まり、一定の値へ近づく。

出力が高すぎる場合は出力を下げる方向に働き、出力が低すぎる場合は出力を上げる方向に働く。

### 負帰還時の入力電圧差

開ループ動作の式を、差動入力電圧について変形する。

```text
v_id = (v_out) / (A_0)
```

`A_0 = 100,000`、`v_out = 1 V` の場合は、次のようになる。

```text
v_id = (1 V) / (100,000)
```

```text
v_id = 10 μV
```

出力が `1 V` でも、2つの入力電圧の差はわずか `10 μV` である。

負帰還が正しく働き、出力が飽和していないときは、次のように近似できる。

```text
v_in+ ≈ v_in-
```

2つの入力端子が内部で接続されているわけではない。実際にはわずかな電圧差があり、その差が増幅されて出力を作っている。

### 帰還率と閉ループ利得

出力電圧のうち、反転入力へ戻す割合を**帰還率** `β_f` とする。

```text
v_f = β_f × v_out
```

ここで、`v_f` は反転入力へ戻る電圧である。

非反転入力へ加える信号を `v_in` とすると、オペアンプが増幅する電圧差は次のようになる。

```text
v_id = v_in - β_f × v_out
```

したがって、出力電圧は次の式で表される。

```text
v_out = A_0 × (v_in - β_f × v_out)
```

この式を整理すると、負帰還を含めた回路全体の電圧利得が得られる。

```text
v_out / v_in = A_0 / (1 + A_0 × β_f)
```

負帰還を含めた利得を**閉ループ利得** `A_CL` と呼ぶ。

```text
A_CL = A_0 / (1 + A_0 × β_f)
```

`A_0 × β_f` が1より十分に大きい場合は、次のように近似できる。

```text
A_CL ≈ 1 / β_f
```

つまり、十分な負帰還をかけると、回路全体の利得はオペアンプ自身の大きな開ループ利得ではなく、出力を戻す割合によって決まる。

### 2本の抵抗で利得を決める

非反転増幅回路では、次の2本の抵抗を使う。

- `R_1`：反転入力とGNDの間の抵抗
- `R_2`：出力と反転入力の間の抵抗

オペアンプの入力端子へ流れる電流は非常に小さいため、反転入力の電圧は抵抗による分圧で求められる。

```text
v_in- = v_out × R_1 / (R_1 + R_2)
```

負帰還が働くと、`v_in+ ≈ v_in-` となる。非反転入力へ `v_in` を加えると、次の関係が成り立つ。

```text
v_in ≈ v_out × R_1 / (R_1 + R_2)
```

この式を整理すると、非反転増幅回路の閉ループ利得が得られる。

```text
A_CL = (v_out) / (v_in) = 1 + (R_2) / (R_1)
```

### 計算例

`R_1 = 2 kΩ`、`R_2 = 8 kΩ` とする。

```text
A_CL = 1 + (8 kΩ) / (2 kΩ)
```

```text
A_CL = 5
```

入力電圧が `0.2 V` の場合は、次のようになる。

```text
v_out = 5 × 0.2 V
```

```text
v_out = 1.0 V
```

出力の5分の1が反転入力へ戻り、その電圧が非反転入力の電圧とほぼ等しくなるところで、出力が落ち着く。

### 負帰還を使える条件

`v_in+ ≈ v_in-` という近似を使うには、次の条件が必要である。

- 出力から反転入力へ負帰還がかかっている
- 出力が飽和していない
- 入力電圧が正常な入力範囲に入っている
- 出力電流が回路の限界を超えていない
- 回路が発振せず、安定して動作している

### 結論

開ループでは利得が大きすぎるため、わずかな入力電圧差で出力が飽和する。負帰還を使うと、出力のずれを小さくし、外部の抵抗などによって必要な閉ループ利得を決められる。

---

## 1.3　理想オペアンプと実際のオペアンプ

### 理想オペアンプは計算のためのモデル

実際のオペアンプには、利得や速度などに限界がある。しかし、最初からすべての限界を含めると、回路の基本動作が分かりにくくなる。

そこで、最初の計算では性能に限界がない**理想オペアンプ**を考える。

| 項目 | 理想オペアンプ | 実際のオペアンプ |
|---|---|---|
| 開ループ利得 | 無限大 | 大きいが有限 |
| 入力抵抗 | 無限大 | 非常に大きい |
| 入力電流 | `0 A` | わずかに流れる |
| 出力抵抗 | `0 Ω` | 小さいが0ではない |
| 周波数帯域 | 無限 | 上限がある |
| 入力オフセット電圧 | `0 V` | わずかに存在する |
| 雑音 | ない | 存在する |
| 出力変化速度 | 無限 | スルーレートによる上限がある |
| 入力電圧範囲 | 制限なし | 電源電圧などで制限される |
| 出力電圧範囲 | 制限なし | 電源電圧などで制限される |

### 基本ルール1：入力電流はほぼ0

理想オペアンプの入力抵抗は無限大なので、入力端子には電流が流れない。

```text
i_+ = i_- = 0
```

実際のCMOSオペアンプでも、MOSFETのゲートが入力になっているため、直流の入力電流は非常に小さい。

ただし、実際には漏れ電流や保護回路の影響がある。また、高い周波数では入力容量を充放電する電流が流れる。

### 基本ルール2：負帰還時の入力電圧差はほぼ0

理想オペアンプの開ループ利得は無限大である。有限の出力電圧を作るには、入力電圧差がほぼ0でなければならない。

```text
v_in+ ≈ v_in-
```

この考え方を**バーチャルショート**または**仮想短絡**という。

「短絡」という名前が付いているが、2つの入力端子が導線で接続されているわけではない。電圧がほぼ等しいだけであり、端子間に電流が流れるという意味ではない。

### バーチャルグラウンドとの違い

非反転入力がGNDに接続され、負帰還によって反転入力もほぼ `0 V` になる場合、その反転入力を**バーチャルグラウンド**または**仮想接地**と呼ぶ。

```text
v_in+ = 0 V
```

```text
v_in- ≈ 0 V
```

バーチャルショートは「2つの入力電圧がほぼ等しい」という関係である。バーチャルグラウンドは、その電圧がさらにGNDとほぼ等しい場合だけに使う言葉である。

### 入力オフセット電圧

実際のオペアンプでは、2つの入力電圧が完全に等しくても、出力が0にならない場合がある。

内部のMOSFETの特性がわずかに異なるためである。このずれを入力側の電圧に置き換えたものを**入力オフセット電圧** `V_OS` と呼ぶ。

入力オフセット電圧が小さくても、閉ループ利得が大きい回路では出力誤差が目立つことがある。

### 周波数帯域と利得

実際のオペアンプでは、周波数が高くなるほど開ループ利得が低下する。

低周波での利得を `A_0`、主要な極の角周波数を `ω_p` とすると、簡単なモデルでは次のように表せる。

```text
A(jω) = (A_0) / (1 + j(ω / ω_p))
```

角周波数 `ω` と周波数 `f` の関係は、`ω = 2π f` である。

周波数が高くなると、信号の大きさだけでなく位相も遅れる。負帰還回路では、この位相の遅れが大きくなると発振する可能性がある。

### スルーレート

実際の出力電圧は、瞬間的に変化できない。出力電圧が1秒間に変化できる最大値を**スルーレート** `SR` と呼ぶ。

```text
SR = max abs(dv_out / dt)
```

スルーレートが不足すると、正弦波を入力しても出力波形が三角波に近い形になり、ひずみが発生する。

### 理想モデルを使えない場合

次の場合は、理想オペアンプの近似だけでは正しく計算できない。

- 出力が電源電圧付近で飽和している
- 入力電圧が入力同相範囲を外れている
- 出力電流が限界を超えている
- 周波数が高く、利得や位相の変化を無視できない
- 入力オフセット電圧や雑音が信号と同じ程度になる
- スルーレートの上限に達している

### 結論

理想オペアンプでは「入力電流は0」「負帰還時の入力電圧差はほぼ0」と考える。実際の回路には利得、電圧範囲、電流、周波数、速度、雑音などの限界があるため、必要に応じて理想モデルへ補正を加える。

## 1.4　NMOSとPMOS

### MOSFETは電圧で電流を調整する

MOSFETは、ゲートに加える電圧によって、ドレインとソースの間に流れる電流を調整する部品である。

MOSFETには、主に次の4つの端子がある。

| 端子 | 記号 | 役割 |
|---|---|---|
| ゲート | G | 電流を調整するための入力 |
| ドレイン | D | 電流経路の一方 |
| ソース | S | 電流経路のもう一方 |
| バルク | B | MOSFETが作られている基板側の端子 |

ゲートは薄い絶縁膜によってチャネルから分離されている。そのため、直流ではゲートへほとんど電流が流れない。

ただし、ゲートには容量がある。入力電圧が変化するときは、この容量を充放電するための電流が必要になる。

### NMOSの動作

NMOSでは、ゲート電圧がソース電圧より十分に高くなると、ドレインとソースの間に電流が流れる経路が作られる。

ゲート・ソース間電圧は次のように定義する。

```text
V_GS = V_G - V_S
```

NMOSが強く電流を流し始める目安は、次の条件である。

```text
V_GS > V_THn
```

`V_THn` はNMOSのしきい値電圧であり、通常は正の値で表す。

NMOSの慣用的なドレイン電流 `I_D` は、ドレインからソースへ流れる向きを正とする。

### PMOSの動作

PMOSでは、ゲート電圧がソース電圧より十分に低くなると、電流が流れる経路が作られる。

PMOSでは、ソース・ゲート間電圧を使うと考えやすい。

```text
V_SG = V_S - V_G
```

PMOSが強く電流を流し始める目安は、次の条件である。

```text
V_SG > abs(V_THp)
```

`V_THp` はPMOSのしきい値電圧であり、符号付きでは負になることが多い。そのため、動作条件では大きさ `abs(V_THp)` を使う。

PMOSでは、慣用的な電流の向きはソースからドレインである。式を扱うときは、符号付きの電流を使う方法と、電流の大きさ `abs(I_D)` を使う方法がある。この章では、PMOSについては主に電流の大きさを使う。

### NMOSとPMOSの比較

| 項目 | NMOS | PMOS |
|---|---|---|
| 主なキャリア | 電子 | 正孔 |
| オンになりやすい条件 | ゲートがソースより高い | ゲートがソースより低い |
| 基本となる電圧 | `V_GS` | `V_SG` |
| しきい値条件 | `V_GS > V_THn` | `V_SG > abs(V_THp)` |
| 電流の向きの考え方 | ドレインからソース | ソースからドレイン |
| 一般的な移動度 | 高い | NMOSより低い |
| 同じ電流に必要な大きさ | 比較的小さい | 比較的大きいことが多い |

電子の移動度は正孔の移動度より高いため、同じ寸法と同じオーバードライブ電圧では、一般にNMOSの方が大きな電流を流しやすい。

NMOSとPMOSの電流能力を同程度にしたい場合は、PMOSのチャネル幅 `W` を大きくすることが多い。

### CMOSという言葉

CMOSは、NMOSとPMOSを相補的に組み合わせる回路方式である。

デジタルCMOS回路では、NMOSとPMOSをスイッチとして使うことが多い。アナログCMOS回路では、MOSFETを増幅素子、電流源、能動負荷、電流ミラーなどとして使う。

二段構成CMOSオペアンプでも、NMOSとPMOSがそれぞれの特性を生かして働いている。

### 結論

NMOSはゲート電圧がソースより高くなると電流を流しやすくなり、PMOSはゲート電圧がソースより低くなると電流を流しやすくなる。CMOSアナログ回路では、この2種類を組み合わせて増幅回路や電流源を作る。

## 1.5　しきい値電圧とオーバードライブ電圧

### しきい値電圧は動作を始める目安

MOSFETでは、ゲート電圧を少し加えただけで大きな電流が流れるわけではない。

ゲート電圧がある値を超えると、ソースとドレインの間にチャネルが形成され、電流が流れやすくなる。この目安となる電圧を**しきい値電圧**と呼ぶ。

NMOSでは、しきい値条件を次のように表す。

```text
V_GS > V_THn
```

PMOSでは、次のように表す。

```text
V_SG > abs(V_THp)
```

しきい値電圧は、完全なオンとオフを分ける理想的な境界ではない。しきい値より低い電圧でも、**サブスレッショルド電流**と呼ばれる小さな電流が流れる。

### しきい値電圧は一定ではない

しきい値電圧は、次の条件によって変化する。

- 製造工程のばらつき
- 温度
- バルクとソースの電圧差
- チャネルの寸法
- ドレイン電圧

特に、バルクとソースの電圧差によってしきい値電圧が変わる現象を**ボディ効果**という。

そのため、回路設計ではしきい値電圧を完全に一定の値として扱わず、ある範囲で変化することを考える。

### NMOSのオーバードライブ電圧

NMOSのゲート・ソース間電圧が、しきい値電圧をどれだけ超えているかを**オーバードライブ電圧** `V_OV` と呼ぶ。

```text
V_OV = V_GS - V_THn
```

たとえば、次の値を考える。

```text
V_GS = 0.80 V
```

```text
V_THn = 0.50 V
```

オーバードライブ電圧は次のようになる。

```text
V_OV = 0.80 - 0.50
```

```text
V_OV = 0.30 V
```

ゲート・ソース間電圧の全部が、電流を増やすために使われるわけではない。しきい値電圧を超えた部分が、チャネルの強さを決める。

### PMOSのオーバードライブ電圧

PMOSでは、ソース・ゲート間電圧を使って次のように定義する。

```text
V_OVp = V_SG - abs(V_THp)
```

たとえば、次の値を考える。

```text
V_SG = 0.90 V
```

```text
abs(V_THp) = 0.55 V
```

```text
V_OVp = 0.90 - 0.55
```

```text
V_OVp = 0.35 V
```

### オーバードライブ電圧と電流

長チャネルMOSFETの基本モデルでは、飽和領域のドレイン電流はオーバードライブ電圧の2乗に比例する。

```text
I_D ∝ V_OV^2
```

オーバードライブ電圧が2倍になると、同じMOSFETでは理想的なドレイン電流が約4倍になる。

ただし、実際の短チャネルMOSFETでは速度飽和などの影響があり、完全な2乗関係にならない場合がある。

### オーバードライブ電圧と電圧の余裕

アナログ回路では、MOSFETを飽和領域に保つためのドレイン・ソース間電圧が必要である。

NMOSでは、長チャネルモデルで次の条件が必要になる。

```text
V_DS ≥ V_OV
```

`V_OV` を小さくすると、低い電源電圧でもMOSFETを飽和領域に保ちやすくなる。一方で、同じ電流を流すにはMOSFETの幅を大きくする必要があり、寄生容量が増えることがある。

### 結論

しきい値電圧は、MOSFETにチャネルが形成される目安である。オーバードライブ電圧は、ゲート電圧がしきい値をどれだけ超えているかを表し、ドレイン電流、相互コンダクタンス、必要な電圧の余裕に大きく関係する。

---

## 1.6　線形領域と飽和領域

### MOSFETの動作領域

MOSFETの動作は、端子間電圧によって次の3つに分けられる。

1. カットオフ領域
2. 線形領域
3. 飽和領域

線形領域は、**トライオード領域**と呼ばれることもある。

### NMOSのカットオフ領域

NMOSでゲート・ソース間電圧がしきい値以下の場合、強い反転チャネルが形成されない。

```text
V_GS ≤ V_THn
```

理想的な基本モデルでは、ドレイン電流を0とする。

```text
I_D ≈ 0
```

実際には、サブスレッショルド電流や漏れ電流が流れる。

### NMOSの線形領域

NMOSがオンになっており、ドレイン・ソース間電圧がオーバードライブ電圧より小さい場合は、線形領域になる。

```text
V_GS > V_THn
```

```text
0 ≤ V_DS < V_OV
```

この領域では、MOSFETはゲート電圧によって値が変わる抵抗のように動作する。

スイッチをオンにしたときのMOSFETや、可変抵抗として使う回路で利用される。

### NMOSの飽和領域

NMOSがオンになっており、ドレイン・ソース間電圧がオーバードライブ電圧以上になると、飽和領域になる。

```text
V_GS > V_THn
```

```text
V_DS ≥ V_OV
```

長チャネルの理想モデルでは、飽和領域のドレイン電流は主に `V_GS` によって決まり、`V_DS` の影響は小さくなる。

そのため、MOSFETは電圧で制御される電流源に近い動作をする。アナログ増幅回路では、この性質を利用する。

> MOSFETの飽和領域は、増幅に利用する正常な動作領域である。オペアンプ出力が電源電圧付近で止まる「出力の飽和」とは意味が異なる。

### PMOSの動作領域

PMOSでは、`V_SG` と `V_SD` を使うとNMOSと同じ形で判断できる。

カットオフ領域は次の条件である。

```text
V_SG ≤ abs(V_THp)
```

線形領域は次の条件である。

```text
V_SG > abs(V_THp)
```

```text
0 ≤ V_SD < V_OVp
```

飽和領域は次の条件である。

```text
V_SG > abs(V_THp)
```

```text
V_SD ≥ V_OVp
```

### 動作領域の判定例

NMOSについて、次の値を考える。

```text
V_THn = 0.50 V
```

```text
V_GS = 0.80 V
```

```text
V_DS = 0.40 V
```

まず、オーバードライブ電圧を求める。

```text
V_OV = V_GS - V_THn
```

```text
V_OV = 0.80 - 0.50 = 0.30 V
```

次に、`V_DS` と `V_OV` を比較する。

```text
V_DS = 0.40 V
```

```text
V_OV = 0.30 V
```

```text
V_DS ≥ V_OV
```

したがって、このNMOSは飽和領域にある。

同じ条件で `V_DS = 0.10 V` なら、次の関係になる。

```text
V_DS < V_OV
```

したがって、線形領域になる。

### 動作領域のまとめ

| MOSFET | カットオフ領域 | 線形領域 | 飽和領域 |
|---|---|---|---|
| NMOS | `V_GS ≤ V_THn` | `V_GS > V_THn`、`V_DS < V_OV` | `V_GS > V_THn`、`V_DS ≥ V_OV` |
| PMOS | `V_SG ≤ abs(V_THp)` | `V_SG > abs(V_THp)`、`V_SD < V_OVp` | `V_SG > abs(V_THp)`、`V_SD ≥ V_OVp` |

### 結論

MOSFETにはカットオフ領域、線形領域、飽和領域がある。アナログ増幅回路では、MOSFETを電圧制御電流源として使うため、通常は飽和領域で動作させる。

---

## 1.7　ドレイン電流

### ドレイン電流を決めるもの

MOSFETのドレイン電流は、主に次の値によって決まる。

- ゲート・ソース間電圧
- ドレイン・ソース間電圧
- しきい値電圧
- キャリアの移動度
- 酸化膜容量
- チャネル幅 `W`
- チャネル長 `L`

NMOSについて、次の係数を定義する。

```text
k_n' = μ_n × C_ox
```

```text
k_n = μ_n × C_ox × (W / L)
```

ここで、各記号は次の意味を持つ。

| 記号 | 意味 |
|---|---|
| `μ_n` | 電子の移動度 |
| `C_ox` | 単位面積当たりのゲート酸化膜容量 |
| `W` | チャネル幅 |
| `L` | チャネル長 |
| `k_n'` | 製造プロセスによって決まる係数 |
| `k_n` | プロセスとMOSFET寸法を含む係数 |

`W` を大きくすると電流を流しやすくなり、`L` を長くすると電流は小さくなる。

### カットオフ領域の電流

理想的な基本モデルでは、カットオフ領域のドレイン電流を0とする。

```text
V_GS ≤ V_THn
```

```text
I_D ≈ 0
```

実際には小さなサブスレッショルド電流や漏れ電流が存在する。

### 線形領域の電流

NMOSが線形領域にあるとき、長チャネルの基本モデルでは次の式を使う。

```text
I_D = k_n × [(V_GS - V_THn) × V_DS - V_DS^2 / 2]
```

オーバードライブ電圧を使うと、次のように書ける。

```text
I_D = k_n × (V_OV × V_DS - V_DS^2 / 2)
```

`V_DS` が非常に小さい場合は、`V_DS^2 / 2` の項を小さいものとして無視できる。

```text
I_D ≈ k_n × V_OV × V_DS
```

この式は抵抗の式 `I = V / R` に似ている。そのため、線形領域のMOSFETは電圧で抵抗値が変わる抵抗のように考えられる。

### 飽和領域の電流

チャネル長変調を無視した長チャネルモデルでは、飽和領域のドレイン電流は次のようになる。

```text
I_D = (1 / 2) × k_n × V_OV^2
```

または、次のように表せる。

```text
I_D = (1 / 2) × μ_n × C_ox × (W / L) × (V_GS - V_THn)^2
```

この式から、次のことが分かる。

- `V_OV` を大きくすると、電流はおおよそ2乗で増える
- `W` を大きくすると、電流は比例して増える
- `L` を長くすると、電流は反比例して減る
- 移動度や酸化膜容量が大きいプロセスほど電流を流しやすい

### 飽和領域の計算例

次の値を考える。

```text
k_n = 1.0 mA / V^2
```

```text
V_OV = 0.20 V
```

ドレイン電流は次のようになる。

```text
I_D = (1 / 2) × 1.0 mA / V^2 × (0.20 V)^2
```

```text
I_D = 0.5 × 1.0 × 0.04 mA
```

```text
I_D = 0.020 mA
```

```text
I_D = 20 μA
```

### PMOSのドレイン電流

PMOSでは電流の大きさを使うと、NMOSと同じ形で表せる。

```text
k_p = μ_p × C_ox × (W / L)
```

飽和領域では、次のようになる。

```text
abs(I_D) = (1 / 2) × k_p × V_OVp^2
```

```text
V_OVp = V_SG - abs(V_THp)
```

正孔の移動度 `μ_p` は一般に電子の移動度 `μ_n` より小さい。そのため、同じ電流を得るにはPMOSの `W / L` を大きくすることが多い。

### チャネル長変調

理想的な飽和領域では、`V_DS` が変化しても `I_D` は一定と考える。

しかし実際には、`V_DS` が高くなると有効なチャネル長が少し短くなり、ドレイン電流が増加する。この現象を**チャネル長変調**という。

チャネル長変調を含めた式は、次のように表せる。

```text
I_D ≈ (1 / 2) × k_n × V_OV^2 × (1 + λ × V_DS)
```

`λ` はチャネル長変調係数であり、単位は `V^(-1)` である。

`λ` が0なら理想的な電流源になり、`λ` が大きいほどドレイン電流が `V_DS` の影響を受けやすい。

### モデルの限界

ここで使った平方則は、長チャネルMOSFETの基本モデルである。実際の微細なMOSFETでは、次の影響によって式からずれる。

- 速度飽和
- 移動度低下
- ドレイン誘起障壁低下
- サブスレッショルド電流
- ソース・ドレイン抵抗
- 温度変化

それでも平方則モデルは、電流、寸法、オーバードライブ電圧の関係を理解するために役立つ。

### 結論

ドレイン電流は、端子電圧、しきい値電圧、MOSFETの寸法、製造プロセスによって決まる。飽和領域の基本モデルでは、電流はオーバードライブ電圧の2乗と `W / L` に比例する。

## 1.8　相互コンダクタンス `g_m`

### `g_m` は電圧を電流へ変える能力

MOSFETでは、ゲート・ソース間電圧を変えるとドレイン電流が変化する。

ゲート・ソース間電圧の小さな変化に対して、ドレイン電流がどれだけ変化するかを表す値が**相互コンダクタンス** `g_m` である。

```text
g_m = ∂I_D / ∂V_GS  （動作点で評価）
```

`g_m` の単位はジーメンス `S` である。

```text
1 S = 1 A / V
```

### 小信号の電流変化

動作点の周りでゲート・ソース間電圧が `v_gs` だけ変化したとき、ドレイン電流の小さな変化 `i_d` は次のように表せる。

```text
i_d = g_m × v_gs
```

たとえば、次の値を考える。

```text
g_m = 2 mS
```

```text
v_gs = 1 mV
```

```text
i_d = 2 mS × 1 mV
```

```text
i_d = 2 μA
```

つまり、ゲート電圧が `1 mV` 変化すると、ドレイン電流が `2 μA` 変化する。

### 平方則モデルから求める

飽和領域のドレイン電流を次の式で表す。

```text
I_D = (1 / 2) × k_n × V_OV^2
```

`V_GS` で微分すると、次の式が得られる。

```text
g_m = k_n × V_OV
```

ドレイン電流の式と組み合わせると、次の形でも表せる。

```text
g_m = (2 × I_D) / (V_OV)
```

さらに、次の形も使える。

```text
g_m = sqrt(2 × k_n × I_D)
```

3つの式は、同じ長チャネル平方則モデルから得られる。分かっている値に合わせて使い分ける。

### 計算例

次の値を考える。

```text
I_D = 20 μA
```

```text
V_OV = 0.20 V
```

相互コンダクタンスは次のようになる。

```text
g_m = (2 × 20 μA) / (0.20 V)
```

```text
g_m = 200 μS
```

```text
g_m = 0.20 mS
```

このMOSFETでは、ゲート・ソース間電圧が `1 mV` 変化すると、ドレイン電流はおよそ次の値だけ変化する。

```text
i_d = 0.20 mS × 1 mV
```

```text
i_d = 0.20 μA
```

### `g_m` を大きくする方法

平方則モデルでは、次の方法で `g_m` を大きくできる。

- ドレイン電流 `I_D` を増やす
- `W / L` を大きくする
- 同じ電流なら `V_OV` を小さくする

ただし、どの方法にも注意点がある。

| 方法 | 利点 | 注意点 |
|---|---|---|
| `I_D` を増やす | `g_m` が大きくなり、速度も上げやすい | 消費電力が増える |
| `W` を大きくする | 同じ `V_OV` で大きな電流を流せる | ゲート容量や面積が増える |
| `V_OV` を小さくする | 同じ電流で `g_m` を大きくできる | ばらつきの影響や必要寸法が増える |

### `g_m / I_D`

相互コンダクタンスを消費電流で割った値を、`g_m / I_D` と呼ぶ。

平方則モデルでは、次の関係になる。

```text
g_m / I_D = 2 / V_OV
```

`g_m / I_D` が大きいほど、少ない電流で大きな相互コンダクタンスを得られる。

低消費電力のアナログ回路では重要な指標だが、速度、面積、動作領域との間にトレードオフがある。

### `g_m` と電圧利得

`g_m` は電圧を電流へ変換する能力であり、それだけでは電圧利得ではない。

電流変化を抵抗によって電圧変化へ変換すると、電圧利得が生まれる。

簡単なソース接地回路では、電圧利得はおおよそ次のようになる。

```text
A_v ≈ -g_m × R_out
```

負号は、入力電圧が高くなると出力電圧が低くなることを表している。

### 結論

相互コンダクタンス `g_m` は、ゲート電圧の小さな変化をドレイン電流の変化へ変換する能力を表す。`g_m` が大きいほど増幅しやすいが、消費電力、面積、容量、電圧の余裕とのバランスが必要になる。

## 1.9　出力抵抗 `r_o`

### 理想的な電流源と実際のMOSFET

理想的な電流源は、両端の電圧が変化しても一定の電流を流す。

チャネル長変調を無視したMOSFETも、飽和領域ではドレイン電流が `V_DS` によらず一定になる。

しかし実際のMOSFETでは、`V_DS` が増えるとドレイン電流も少し増える。そのため、完全な電流源ではない。

### 出力コンダクタンス

ドレイン・ソース間電圧の小さな変化に対して、ドレイン電流がどれだけ変化するかを**出力コンダクタンス** `g_o` と呼ぶ。

```text
g_o = ∂I_D / ∂V_DS  （動作点で評価）
```

チャネル長変調を含む簡単なモデルでは、次のように近似できる。

```text
g_o ≈ λ × I_D
```

### 出力抵抗

出力コンダクタンスの逆数を**出力抵抗** `r_o` と呼ぶ。

```text
r_o = (1) / (g_o)
```

したがって、次の近似式が得られる。

```text
r_o ≈ 1 / (λ × I_D)
```

`r_o` が大きいほど、`V_DS` が変化してもドレイン電流が変わりにくく、理想的な電流源に近い。

### アーリー電圧を使った表し方

チャネル長変調係数の代わりに、アーリー電圧 `V_A` を使う場合がある。

```text
V_A ≈ (1) / (λ)
```

したがって、出力抵抗は次のように書ける。

```text
r_o ≈ (V_A) / (I_D)
```

### 計算例

次の値を考える。

```text
λ = 0.10 V^(-1)
```

```text
I_D = 20 μA
```

出力抵抗は次のようになる。

```text
r_o = (1) / (0.10 × 20 μA)
```

```text
r_o = 500 kΩ
```

ドレイン・ソース間電圧が小信号として `10 mV` 変化すると、`r_o` を通して生じる電流変化は次のようになる。

```text
i_d = (10 mV) / (500 kΩ)
```

```text
i_d = 20 nA
```

### 電流とチャネル長の影響

近似式から、ドレイン電流を増やすと `r_o` は小さくなる。

```text
r_o ∝ (1) / (I_D)
```

一般に、チャネル長 `L` を長くするとチャネル長変調が小さくなり、`r_o` は大きくなる。

ただし、チャネルを長くすると同じ電流を得るために幅を大きくする必要があり、面積や容量が増える場合がある。

### 複数の出力抵抗

回路の出力ノードにNMOSとPMOSの両方が接続されている場合、それぞれの出力抵抗は小信号的に並列になる。

```text
R_out = r_on || r_op
```

2つの抵抗 `R_a` と `R_b` の並列合成は、次の式で求められる。

```text
R_a || R_b = (R_a × R_b) / (R_a + R_b)
```

同じ値の抵抗を2本並列にすると、合成抵抗は半分になる。

### 固有利得

1個のMOSFETが得られる基本的な電圧利得の目安を、**固有利得**と呼ぶ。

```text
A_intrinsic ≈ g_m × r_o
```

たとえば、次の値を考える。

```text
g_m = 0.20 mS
```

```text
r_o = 500 kΩ
```

```text
g_m × r_o = 0.20 mS × 500 kΩ
```

```text
g_m × r_o = 100
```

このMOSFETの固有利得は約100倍である。

実際の増幅回路では、負荷抵抗やほかのMOSFETの出力抵抗が並列に接続されるため、得られる利得はこの値より小さくなることが多い。

### 結論

出力抵抗 `r_o` は、MOSFETがどれだけ理想的な電流源に近いかを表す。`r_o` が大きいほど出力電圧の変化による電流変化が小さくなり、`g_m × r_o` が大きいほど高い電圧利得を得やすい。

## 1.10　MOSFETの小信号モデル

### 動作点と小さな変化を分ける

MOSFETのドレイン電流とゲート電圧の関係は直線ではない。

たとえば、飽和領域の長チャネルモデルでは次の関係になる。

```text
I_D = (1 / 2) × k_n × (V_GS - V_THn)^2
```

この式をそのまま使って信号の変化を毎回計算すると複雑になる。

そこで、最初に直流バイアスによって動作点を決め、その周りの小さな変化だけを直線として扱う。この考え方を**小信号解析**という。

### 直流値と小信号値

ゲート・ソース間電圧を、直流値と小信号に分ける。

```text
v_GS,total(t) = V_GS + v_gs(t)
```

ドレイン電流も同じように分ける。

```text
i_D,total(t) = I_D + i_d(t)
```

`V_GS` と `I_D` が動作点を表し、`v_gs` と `i_d` が信号による小さな変化を表す。

### 小信号モデルの基本要素

飽和領域にあるMOSFETの低周波小信号モデルには、主に次の要素がある。

| 要素 | 意味 |
|---|---|
| 開放されたゲート | 直流ではゲート電流がほぼ0 |
| 制御電流源 `g_m × v_gs` | ゲート電圧の変化によって生じるドレイン電流 |
| 出力抵抗 `r_o` | チャネル長変調によるドレイン電流の変化 |
| ボディ効果 `g_mb × v_bs` | バルク・ソース間電圧の変化による電流変化 |

ボディ効果と容量を無視した最も基本的なモデルでは、ドレイン電流の小さな変化は次のようになる。

```text
i_d = g_m × v_gs + (v_ds) / (r_o)
```

第1項はゲート電圧による電流変化、第2項はドレイン・ソース間電圧による電流変化である。

出力コンダクタンス `g_o` を使うと、次のようにも書ける。

```text
i_d = g_m × v_gs + g_o × v_ds
```

```text
g_o = (1) / (r_o)
```

### 交流的なGND

小信号解析では、変化しない直流電源を**交流的なGND**として扱う。

たとえば、一定の電源電圧 `V_DD` には小信号成分がない。

```text
v_dd = 0
```

そのため、小信号等価回路では理想的な直流電源をGNDへ置き換える。

これは、実際の電源端子が物理的にGNDへ接続されるという意味ではない。信号による変化が0であるため、小信号だけを考えたときにGNDと同じになる。

### ソース接地回路の電圧利得

NMOSのソースが交流的にGNDへ接続され、ドレインに負荷抵抗 `R_D` が接続されたソース接地回路を考える。

入力電圧が高くなると、`v_gs` が高くなる。

```text
v_gs↑
```

ドレイン電流は増える。

```text
i_d = g_m × v_gs  ↑
```

負荷抵抗の電圧降下が大きくなるため、ドレインの出力電圧は低くなる。

```text
v_out↓
```

したがって、入力と出力の向きは反対になる。

`r_o` を無視した場合の電圧利得は、次のようになる。

```text
A_v = (v_out) / (v_in) ≈ -g_m × R_D
```

MOSFETの出力抵抗を含めると、次のようになる。

```text
A_v ≈ -g_m × (R_D || r_o)
```

### 電圧利得の計算例

次の値を考える。

```text
g_m = 0.20 mS
```

```text
r_o = 500 kΩ
```

```text
R_D = 100 kΩ
```

まず、並列抵抗を求める。

```text
R_D || r_o = (100 kΩ × 500 kΩ) / (100 kΩ + 500 kΩ)
```

```text
R_D || r_o ≈ 83.3 kΩ
```

したがって、電圧利得は次のようになる。

```text
A_v ≈ -0.20 mS × 83.3 kΩ
```

```text
A_v ≈ -16.7
```

入力の小信号が `1 mV` の場合、出力の小信号はおよそ次の値になる。

```text
v_out = -16.7 × 1 mV
```

```text
v_out ≈ -16.7 mV
```

負号は、入力電圧が上がると出力電圧が下がることを表す。

### 能動負荷を使った場合

CMOSオペアンプでは、抵抗の代わりにPMOSやNMOSを能動負荷として使うことが多い。

NMOS増幅素子とPMOS能動負荷が同じ出力ノードに接続される場合、出力抵抗はおおよそ次のようになる。

```text
R_out ≈ r_on || r_op
```

電圧利得は、簡単には次のように表せる。

```text
A_v ≈ -g_mn × (r_on || r_op)
```

大きな出力抵抗を持つ能動負荷を使うことで、ICの中に大きな抵抗を作らなくても高い電圧利得を得られる。

### ボディ効果

バルク・ソース間電圧が信号によって変化すると、しきい値電圧も変化し、ドレイン電流へ影響する。

この影響を小信号で表す係数が、ボディ相互コンダクタンス `g_mb` である。

```text
i_d = g_m × v_gs + g_mb × v_bs + (v_ds) / (r_o)
```

バルクとソースが同じ小信号電位にある場合は、`v_bs = 0` となり、ボディ効果の項は現れない。

### 高い周波数で必要な容量

低周波の小信号モデルでは、MOSFET内部の容量を無視する。

周波数が高くなると、次の容量を考える必要がある。

- ゲート・ソース間容量 `C_gs`
- ゲート・ドレイン間容量 `C_gd`
- ドレイン・バルク間容量 `C_db`
- ソース・バルク間容量 `C_sb`

特に `C_gd` は、入力と出力の間に接続されるため、増幅回路の周波数特性へ大きく影響する。

入力と出力の電圧変化が反対方向になる回路では、`C_gd` が入力側から大きな容量に見えることがある。この現象を**ミラー効果**という。

二段構成CMOSオペアンプでは、内部容量や補償容量が利得と位相に影響し、負帰還時の安定性を決める。

### 小信号モデルを使う手順

MOSFET回路を小信号解析するときは、次の順番で考える。

1. 直流バイアスを求める。
2. 各MOSFETの動作領域を確認する。
3. 動作点から `g_m` と `r_o` を求める。
4. 直流電源を交流的なGNDへ置き換える。
5. MOSFETを小信号モデルへ置き換える。
6. 小信号等価回路から電圧利得や入出力抵抗を求める。
7. 必要に応じて容量を加え、周波数特性を求める。

小信号モデルは、動作点の周りにある小さな変化だけを扱う。入力信号が大きく、MOSFETが別の動作領域へ移動する場合は、小信号近似をそのまま使うことはできない。

### 結論

MOSFETの小信号モデルは、非線形なMOSFETを動作点の周りで直線的な回路として表したものである。低周波では主に `g_m × v_gs` と `r_o` を使い、高い周波数では内部容量も加える。このモデルによって、CMOS増幅回路の電圧利得や周波数特性を計算できる。
