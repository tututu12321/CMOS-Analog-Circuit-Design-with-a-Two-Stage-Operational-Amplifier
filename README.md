# 小さな信号を、次の回路へ

## オペアンプ

センサやマイクから出てくる信号は、とても小さい。
その小さな変化を受け取り、扱いやすい電圧に変える。
オペアンプは、電子機器の中でそんな仕事をしている。

## 0.1　二段構成オペアンプの概要

### わずかな電圧の違いを大きくする
<img width="1111" height="747" alt="image" src="https://github.com/user-attachments/assets/bf00479c-59f1-4c89-96fb-ea42275197c9" />

オペアンプには2つの入力があり、その電圧の違いを受け取って増幅する。

二段構成CMOSオペアンプでは、増幅する部分が内部で二つに分かれている。NMOSとPMOSで作られており、小さなICの中に組み込むことができる。
この回路は、NMOSとPMOSという2種類のMOSFETを組み合わせて作られる。MOSFETは、入力された電圧によって電流の流れ方を調整する部品である。
NMOSはゲートの電圧が高くなると電流を流しやすくなり、PMOSはゲートの電圧が低くなると電流を流しやすくなる。この反対の動きをする2種類を組み合わせることで、入力から出力までの信号を一つのICの中で扱える。

**結論**

二段構成CMOSオペアンプは、小さな入力電圧の差を二段に分けて増幅する回路である。

---

## 0.2　第1段と第2段の役割

### 前半で入力を受け取り、後半で大きくする

第1段は、2つの入力電圧の違いを受け取る部分である。

第2段は、第1段から渡された信号をさらに大きくして、出力へ送る部分である。

```text
入力 → 第1段 → 第2段 → 出力
```

**結論**

第1段が入力を受け取り、第2段が出力に必要な大きさまで増幅する。

---

## 0.3　入力から出力までの信号経路

### 信号は二つの増幅段を順番に通る

入力された信号は、まず第1段に入る。

第1段で変化した信号は第2段へ渡され、さらに増幅される。最後に、オペアンプの出力端子から外へ出ていく。

```text
2つの入力
    ↓
第1段
    ↓
第2段
    ↓
出力
```

**結論**

入力信号は、第1段から第2段へ順番に伝わり、最後に出力信号になる。

---

## 0.4　二段構成にする理由

### 二つの回路で仕事を分ける

一つの増幅回路だけで、小さな入力を受け取り、大きな出力を作るのは難しい。

そこで、入力を受け取る部分と、出力を大きくする部分に仕事を分ける。二段に分けることで、それぞれの役割に合った回路を作りやすくなる。

**結論**

二段構成にする理由は、入力と出力の仕事を分け、十分な増幅を得やすくするためである。

---

## 0.5　主な要求仕様

### 大きく、速く、安定して動くことが求められる

オペアンプは、ただ信号を大きくできればよいわけではない。

* 信号を十分に増幅できること
* 入力の変化にすばやく反応できること
* 出力が不安定にならないこと
* 必要な範囲の電圧を扱えること
* 消費する電力が大きすぎないこと

これらの性能を、使う目的に合わせて決めていく。

**結論**

オペアンプの設計では、増幅の大きさだけでなく、速度、安定性、電圧範囲、消費電力も重要になる。

---

## 序章の結論

二段構成CMOSオペアンプは、小さな入力電圧の差を受け取り、二つの増幅段を通して大きな出力信号に変える回路である。

第1段と第2段がどのような回路で作られ、どのように信号を増幅するのかを、次の章から順番に見ていく。

## 第1章　オペアンプとMOSFETの基礎

二段構成CMOSオペアンプは、NMOSとPMOSを組み合わせて作られている。

オペアンプ全体の動作を理解するには、まず「オペアンプが何を増幅するのか」を知り、その後で「MOSFETがどのように電圧を電流へ変えるのか」を学ぶと分かりやすい。

この章では、次の順番で話を進める。

```text
2つの入力電圧の差
        ↓
MOSFETのゲート電圧
        ↓
ドレイン電流の変化
        ↓
出力電圧の変化
```

### この章で使う記号

MOSFET回路では、直流の値と小さな信号の変化を区別して書く。

| 表し方   | 意味              | 例                       |
| ----- | --------------- | ----------------------- |
| 大文字   | 回路を動作させる直流の値    | (V_{GS})、(V_{DS})、(I_D) |
| 小文字   | 直流値の周りに加わる小さな変化 | (v_{gs})、(v_{ds})、(i_d) |
| total | 直流と小信号を合わせた実際の値 | (v_{GS,\mathrm{total}}) |

たとえば、実際のゲート・ソース間電圧は、直流電圧と小信号電圧の和として表せる。

[
v_{GS,\mathrm{total}}(t)=V_{GS}+v_{gs}(t)
]

同じように、ドレイン電流も次のように分けられる。

[
i_{D,\mathrm{total}}(t)=I_D+i_d(t)
]

この区別は、1.10節の小信号モデルで重要になる。

### 1.1　差動入力と出力電圧

#### オペアンプは2つの入力電圧の差を増幅する

オペアンプには、2つの入力端子と1つの出力端子がある。

```text
非反転入力 v_in+ ─┐
                   ├─ オペアンプ ─ v_out
反転入力   v_in- ─┘
```

プラス記号の付いた入力を非反転入力、マイナス記号の付いた入力を反転入力と呼ぶ。

オペアンプは、それぞれの入力電圧を別々に増幅するのではない。2つの入力電圧を比べ、その差を増幅する。

この差を差動入力電圧 (v_{id}) と呼ぶ。

[
v_{id}=v_{in+}-v_{in-}
]

たとえば、非反転入力が1.001 V、反転入力が1.000 Vなら、差動入力電圧は次のようになる。

[
v_{id}=1.001-1.000=0.001\ \mathrm{V}
]

0.001 Vは1 mVである。

[
1\ \mathrm{mV}=0.001\ \mathrm{V}
]

このように、2つの入力には約1 Vが加わっていても、オペアンプが増幅するのは、その差である1 mVである。

#### 非反転入力と反転入力の違い

非反転入力の電圧が高くなると、出力電圧は高くなる方向へ動く。

```text
v_in+ が上がる
      ↓
v_out も上がる
```

反転入力の電圧が高くなると、出力電圧は低くなる方向へ動く。

```text
v_in- が上がる
      ↓
v_out は下がる
```

この動作は、次の式で表せる。

[
v_{out}=A_0(v_{in+}-v_{in-})
]

または、

[
v_{out}=A_0v_{id}
]

(A_0) は、負帰還をかけていないときの電圧利得である。これを開ループ利得と呼ぶ。

一般的なオペアンプの開ループ利得は非常に大きく、数万倍から数十万倍になることがある。

#### わずかな電圧差でも大きな出力になる

開ループ利得が100,000倍のオペアンプを考える。

差動入力電圧が10 µVなら、出力電圧は次のようになる。

[
v_{out}=100{,}000\times10\ \mathrm{\mu V}
]

[
v_{out}=1\ \mathrm{V}
]

10 µVは、0.00001 Vである。このような小さな電圧差からでも、1 Vの出力を作れる。

一方、差動入力電圧が1 mVなら、計算上の出力は100 Vになる。

[
v_{out}=100{,}000\times1\ \mathrm{mV}=100\ \mathrm{V}
]

しかし、3 Vの電源で動いているオペアンプが100 Vを出力することはできない。実際の出力電圧は、電源電圧で決まる範囲内に制限される。

出力が上限または下限付近で止まり、それ以上変化できなくなる状態を出力飽和と呼ぶ。

```text
計算上の出力が電源範囲内
        ↓
入力差に応じて出力が変化する

計算上の出力が電源範囲外
        ↓
出力が上限または下限付近で止まる
```

**結論**

オペアンプは、非反転入力と反転入力の電圧差を大きくして出力する。ただし、出力できる電圧は電源電圧の範囲に制限される。

### 1.2　開ループ動作と負帰還

#### 開ループでは利得が大きすぎる

オペアンプの出力を入力側へ戻していない状態を、開ループと呼ぶ。

```text
入力 → オペアンプ → 出力
```

開ループでは、オペアンプが持つ非常に大きな電圧利得がそのまま使われる。

たとえば、開ループ利得が100,000倍なら、入力電圧差がわずか10 µVでも出力は1 V変化する。入力電圧差が少し大きくなるだけで、出力はすぐに電源電圧付近へ達する。

このため、開ループのままでは「入力を正確に10倍する」といった使い方が難しい。

#### 出力の一部を入力へ戻す

そこで、出力信号の一部を反転入力へ戻す。

```text
入力 → オペアンプ → 出力
          ↑          │
          └──────────┘
              負帰還
```

出力信号を反転入力へ戻し、出力の変化を打ち消す方向に働かせることを負帰還という。

負帰還の動きを順番に考える。

1. 非反転入力の電圧が少し高くなる。
2. オペアンプの出力電圧が高くなる。
3. 出力の一部が反転入力へ戻る。
4. 反転入力の電圧も高くなる。
5. 非反転入力と反転入力の差が小さくなる。
6. 出力の上昇が抑えられる。

出力が高くなりすぎると、それを下げる方向に働く。出力が低くなりすぎると、それを上げる方向に働く。この働きによって、出力が目的の値に近づく。

#### ボルテージフォロワの動作

最も簡単な負帰還回路は、出力端子をそのまま反転入力へ接続したボルテージフォロワである。

```text
入力 ──→ 非反転入力
             │
         オペアンプ ──→ 出力
             ↑            │
             └────────────┘
```

出力電圧が入力電圧より低い場合、非反転入力の方が高くなるため、出力は上昇する。

出力電圧が入力電圧より高い場合、反転入力の方が高くなるため、出力は低下する。

その結果、出力電圧は入力電圧とほぼ等しくなる。

[
v_{out}\approx v_{in}
]

電圧利得は約1倍だが、入力側の回路と出力側の回路を切り離すバッファとして使える。

#### 抵抗で電圧利得を決める

非反転増幅回路では、2本の抵抗によって閉ループ利得を決められる。

[
A_{CL}=1+\frac{R_2}{R_1}
]

ここで、

* (R_1)：反転入力とGNDの間に接続する抵抗
* (R_2)：出力と反転入力の間に接続する抵抗
* (A_{CL})：負帰還をかけた回路全体の電圧利得

とする。

(R_1=1\ \mathrm{k\Omega})、(R_2=9\ \mathrm{k\Omega}) の場合は、次のようになる。

[
A_{CL}=1+\frac{9\ \mathrm{k\Omega}}{1\ \mathrm{k\Omega}}
]

[
A_{CL}=10
]

したがって、入力電圧が0.1 Vなら、理想的な出力電圧は1.0 Vになる。

[
v_{out}=10\times0.1=1.0\ \mathrm{V}
]

負帰還を使うと、オペアンプ自身の開ループ利得ではなく、外側に接続した抵抗によって回路全体の利得を決めやすくなる。

また、正しく設計された負帰還には、ひずみを小さくしたり、扱える周波数範囲を広げたりする効果もある。

**結論**

開ループでは利得が大きすぎて出力が飽和しやすい。負帰還をかけることで、必要な倍率で安定して増幅できる。

### 1.3　理想オペアンプと実際のオペアンプ

#### 理想オペアンプは計算のためのモデル

実際のオペアンプには、利得、速度、電圧範囲などに限界がある。

しかし、最初からすべての限界を含めると、回路計算が複雑になる。そこで、まずは理想オペアンプを使って回路の基本動作を考える。

理想オペアンプと実際のオペアンプの違いを表に示す。

| 項目        | 理想オペアンプ | 実際のオペアンプ     |
| --------- | ------- | ------------ |
| 開ループ利得    | 無限大     | 数万倍から数十万倍程度  |
| 入力抵抗      | 無限大     | 非常に大きい       |
| 入力電流      | 0 A     | わずかに流れる      |
| 出力抵抗      | 0 Ω     | 小さいが0 Ωではない  |
| 周波数帯域     | 無限      | 上限がある        |
| 入力オフセット電圧 | 0 V     | わずかに存在する     |
| 雑音        | ない      | 存在する         |
| 出力の変化速度   | 無限      | 上限がある        |
| 入力電圧範囲    | 制限なし    | 電源電圧などで制限される |
| 出力電圧範囲    | 制限なし    | 電源電圧などで制限される |

#### 理想オペアンプの二つの基本ルール

負帰還が正しくかかり、出力が飽和していないときは、次の二つのルールを使える。

##### ルール1：入力端子には電流が流れない

[
i_+=i_-=0
]

理想オペアンプの入力抵抗は無限大なので、入力端子には電流が流れないと考える。

実際のオペアンプでも入力電流は非常に小さいため、多くの基本計算では0 Aとして扱える。

##### ルール2：2つの入力電圧はほぼ等しい

[
v_{in+}\approx v_{in-}
]

オペアンプの開ループ利得は非常に大きい。出力が電源範囲内に収まるためには、2つの入力電圧の差が非常に小さくなければならない。

たとえば、開ループ利得が100,000倍で、出力電圧が1 Vなら、必要な入力電圧差は次のようになる。

[
v_{id}=\frac{v_{out}}{A_0}
]

[
v_{id}=\frac{1}{100{,}000}=10\ \mathrm{\mu V}
]

出力が1 Vあっても、入力電圧差は10 µVしかない。このため、基本的な回路計算では2つの入力電圧が等しいとみなせる。

この関係をバーチャルショート、または仮想短絡と呼ぶ。

「短絡」という名前が付いているが、2つの入力端子が導線で接続されているわけではない。入力電流も流れない。負帰還の働きによって、電圧だけがほぼ等しくなっている。

#### バーチャルショートを使えない場合

次のような場合は、(v_{in+}\approx v_{in-}) と考えることができない。

* 負帰還がかかっていない
* 正帰還がかかっている
* 出力が上限または下限で飽和している
* オペアンプが正常に動作できる入力電圧範囲を外れている
* 高い周波数でオペアンプが入力変化に追いつけない

また、バーチャルショートとバーチャルグラウンドは同じ意味ではない。

非反転入力がGNDに接続され、負帰還によって反転入力も約0 Vになる場合、その反転入力をバーチャルグラウンドと呼ぶ。

**結論**

理想オペアンプでは「入力電流は0」「負帰還時の入力電圧差はほぼ0」と考える。ただし、この考え方を使えるのは、負帰還が働き、出力が飽和していない場合である。

---

### 1.4　NMOSとPMOS

#### MOSFETは電圧によって電流を調整する部品

MOSFETは、ゲートに加える電圧によって、ドレインとソースの間に流れる電流を調整する部品である。

MOSFETには、基本的に4つの端子がある。

| 端子   | 記号 | 役割                |
| ---- | -: | ----------------- |
| ゲート  |  G | 電流の流れ方を調整する       |
| ドレイン |  D | 電流経路の一方           |
| ソース  |  S | 電流経路の一方           |
| バルク  |  B | MOSFETが作られている基板部分 |

ゲートと内部の半導体の間には、薄い絶縁膜がある。そのため、一定の電圧を加えているだけなら、ゲートにはほとんど電流が流れない。

ただし、ゲートは小さなコンデンサのような性質を持っている。ゲート電圧を変化させるときには、このコンデンサを充電または放電するための電流が一時的に流れる。

#### NMOSの動作

NMOSでは、一般にソースを低い電位側に置く。

ゲート電圧をソース電圧より高くすると、ゲートの下に電流が流れるための通路が作られる。この通路をチャネルと呼ぶ。

```text
ゲート電圧が低い
      ↓
チャネルができにくい
      ↓
電流がほとんど流れない

ゲート電圧が高い
      ↓
チャネルができる
      ↓
電流が流れやすくなる
```

NMOSの動作を考えるときは、ゲート・ソース間電圧を使う。

[
V_{GS}=V_G-V_S
]

(V_{GS}) が大きくなるほど、NMOSは電流を流しやすくなる。

#### PMOSの動作

PMOSでは、一般にソースを電源側の高い電位に置く。

PMOSは、ゲート電圧をソース電圧より低くすると電流を流しやすくなる。

PMOSでは、ソース・ゲート間電圧を使うと、電圧を正の値として扱いやすい。

[
V_{SG}=V_S-V_G
]

(V_{SG}) が大きくなるほど、PMOSは電流を流しやすくなる。

```text
NMOS：ゲート電圧を高くすると電流が増える

PMOS：ゲート電圧を低くすると電流が増える
```

NMOSとPMOSでは、ゲート電圧に対する動きが反対になる。

CMOSオペアンプでは、この2種類のMOSFETを使い分ける。たとえば、NMOSで差動入力回路を作り、PMOSで電流を供給する負荷回路を作ることができる。反対に、PMOSを入力側に使い、NMOSを負荷側に使う構成もある。

バルク端子は、不要な接合が導通しないように接続する。一般的なCMOS回路では、NMOSのバルクを低い電位側、PMOSのバルクを高い電位側へ接続することが多い。

**結論**

NMOSはゲート電圧を高くすると電流を流しやすくなり、PMOSはゲート電圧を低くすると電流を流しやすくなる。この2種類を組み合わせてCMOS回路を作る。

---

### 1.5　しきい値電圧とオーバードライブ電圧

#### しきい値電圧はMOSFETが動き始める目安

NMOSでは、ゲート・ソース間電圧 (V_{GS}) を高くしていくと、ある電圧からドレイン電流が大きく流れ始める。

この動作の目安となる電圧を、しきい値電圧 (V_{th}) と呼ぶ。

[
V_{GS}>V_{th}
]

最初の回路計算では、次のように考える。

```text
V_GS が V_th 以下
        ↓
NMOSはOFF

V_GS が V_th より大きい
        ↓
NMOSはON
```

実際には、(V_{GS}) が (V_{th}) を少し下回っていても、弱い電流が流れる。この動作を弱反転という。ただし、基本的な平方則モデルでは、しきい値電圧をONとOFFの境界として扱う。

#### オーバードライブ電圧

NMOSがONになった後、ゲート・ソース間電圧がしきい値電圧をどれだけ超えているかを、オーバードライブ電圧 (V_{OV}) と呼ぶ。

[
V_{OV}=V_{GS}-V_{th}
]

しきい値電圧を「動作を始めるために必要な電圧」と考えると、オーバードライブ電圧は「そこから余分に加えた電圧」にあたる。

たとえば、

[
V_{GS}=0.8\ \mathrm{V}
]

[
V_{th}=0.5\ \mathrm{V}
]

なら、オーバードライブ電圧は次のようになる。

[
V_{OV}=0.8-0.5=0.3\ \mathrm{V}
]

このNMOSは、しきい値電圧を0.3 V上回った状態で動作している。

#### PMOSの場合

PMOSでは、しきい値電圧が負の値で表されることが多い。符号による混乱を避けるため、しきい値電圧の大きさ (|V_{th,P}|) と (V_{SG}) を使う。

[
V_{OV,P}=V_{SG}-|V_{th,P}|
]

たとえば、PMOSのソース電圧が1.5 V、ゲート電圧が0.7 Vなら、

[
V_{SG}=1.5-0.7=0.8\ \mathrm{V}
]

しきい値電圧の大きさが0.5 Vなら、

[
V_{OV,P}=0.8-0.5=0.3\ \mathrm{V}
]

となる。

#### オーバードライブ電圧が重要な理由

オーバードライブ電圧は、次の三つに関係する。

1. MOSFETに流れるドレイン電流
2. 入力電圧を電流に変える能力 (g_m)
3. MOSFETを飽和領域に保つために必要な電圧

平方則モデルでは、ドレイン電流は (V_{OV}) の2乗に比例する。

[
I_D\propto V_{OV}^2
]

したがって、ほかの条件が同じなら、(V_{OV}) を2倍にするとドレイン電流は4倍になる。

一方、同じドレイン電流で比較すると、(V_{OV}) を小さくした方が大きな (g_m) を得やすい。ただし、そのためにはMOSFETの幅を広くする必要があり、回路面積や寄生容量が増える場合がある。

**結論**

しきい値電圧はMOSFETが動き始める目安であり、オーバードライブ電圧は、しきい値を超えてどれだけ強く動作させているかを表す。

---

### 1.6　線形領域と飽和領域

#### MOSFETは端子電圧によって動作が変わる

NMOSがONになっていても、常に同じ動作をするわけではない。

ゲート・ソース間電圧 (V_{GS}) とドレイン・ソース間電圧 (V_{DS}) の関係によって、動作領域が変わる。

NMOSの動作は、次の三つに分けられる。

| 動作領域    | 条件                                  | 動作のイメージ        | 主な使い方    |
| ------- | ----------------------------------- | -------------- | -------- |
| カットオフ領域 | (V_{GS}\leq V_{th})                 | 電流がほとんど流れない    | スイッチのOFF |
| 線形領域    | (V_{GS}>V_{th})、(V_{DS}<V_{OV})     | 電圧で変化する抵抗      | スイッチのON  |
| 飽和領域    | (V_{GS}>V_{th})、(V_{DS}\geq V_{OV}) | ゲート電圧で制御される電流源 | 増幅回路     |

#### カットオフ領域

[
V_{GS}\leq V_{th}
]

ゲート電圧が十分に高くないため、電流の通路となるチャネルが十分に作られていない。基本的なモデルでは、ドレイン電流を0 Aとして扱う。

[
I_D\approx0
]

#### 線形領域

[
V_{GS}>V_{th}
]

[
0\leq V_{DS}<V_{OV}
]

MOSFETがONになり、ドレインとソースの間に電流が流れる。(V_{DS}) が小さい範囲では、MOSFETは抵抗に近い動作をする。

線形領域は、トライオード領域とも呼ばれる。

デジタル回路でMOSFETをスイッチとして使う場合、ON状態のMOSFETは線形領域で使われることが多い。

#### 飽和領域

[
V_{GS}>V_{th}
]

[
V_{DS}\geq V_{OV}
]

ドレイン側のチャネルが細くなり、ドレイン電流が主にゲート電圧によって決まるようになる。

飽和領域では、(V_{DS}) が多少変化してもドレイン電流は大きく変化しない。このため、入力電圧によって出力電流を調整する増幅素子として使える。

「飽和」という言葉から、電流が限界まで流れている状態を想像しやすいが、MOSFETの飽和領域は故障状態ではない。アナログ増幅回路では、MOSFETを飽和領域で動かすことが基本になる。

また、MOSFETの飽和領域と、オペアンプの出力飽和は別の現象である。

* MOSFETの飽和領域：増幅に利用する正常な動作領域
* オペアンプの出力飽和：出力が電源電圧付近で止まった状態

#### 数値で動作領域を判断する

次のNMOSを考える。

[
V_{th}=0.5\ \mathrm{V}
]

[
V_{GS}=0.8\ \mathrm{V}
]

オーバードライブ電圧は、

[
V_{OV}=0.8-0.5=0.3\ \mathrm{V}
]

となる。

(V_{DS}=0.1\ \mathrm{V}) なら、

[
V_{DS}<V_{OV}
]

なので線形領域である。

(V_{DS}=0.5\ \mathrm{V}) なら、

[
V_{DS}\geq V_{OV}
]

なので飽和領域である。

PMOSでは、(V_{SG})、(V_{SD})、(|V_{th,P}|) を使って同じように判断する。

**結論**

MOSFETを増幅回路や電流源として使うときは、(V_{DS}\geq V_{OV}) を満たし、飽和領域で動作させる。

---

### 1.7　ドレイン電流

#### ドレイン電流はゲート電圧とMOSFETの大きさで決まる

MOSFETのドレイン端子に流れる主な電流を、ドレイン電流 (I_D) と呼ぶ。

MOSFETがどれだけ電流を流しやすいかを表す係数として、(\beta) を次のように定義する。

[
\beta=\mu C_{ox}\frac{W}{L}
]

それぞれの記号は、次の意味を持つ。

| 記号       | 意味                |
| -------- | ----------------- |
| (\mu)    | 電子や正孔の動きやすさ       |
| (C_{ox}) | ゲート絶縁膜の単位面積当たりの容量 |
| (W)      | MOSFETのゲート幅       |
| (L)      | MOSFETのゲート長       |

(W) を広くすると、電流が流れる通路が広くなるため、ドレイン電流は増える。

(L)を長くすると、電流が流れる通路が長くなるため、同じ電圧ではドレイン電流が減る。

#### カットオフ領域のドレイン電流

[
V_{GS}\leq V_{th}
]

のとき、基本的なモデルでは次のように考える。

[
I_D=0
]

#### 線形領域のドレイン電流

線形領域では、次の式を使う。

[
I_D=
\beta
\left{
(V_{GS}-V_{th})V_{DS}
-\frac{V_{DS}^2}{2}
\right}
]

オーバードライブ電圧を使うと、次のように書ける。

[
I_D=
\beta
\left(
V_{OV}V_{DS}
-\frac{V_{DS}^2}{2}
\right)
]

線形領域では、ドレイン電流が (V_{GS}) と (V_{DS}) の両方によって変化する。

#### 飽和領域のドレイン電流

飽和領域では、次の平方則モデルを使う。

[
I_D=
\frac{\beta}{2}
(V_{GS}-V_{th})^2
]

オーバードライブ電圧を使うと、

[
I_D=\frac{\beta}{2}V_{OV}^2
]

となる。

この式から、ドレイン電流は次の量で決まることが分かる。

* MOSFETの大きさを表す (\beta)
* オーバードライブ電圧 (V_{OV})

#### ドレイン電流の計算例

次の条件を考える。

[
\frac{\beta}{2}=1\ \mathrm{mA/V^2}
]

[
V_{OV}=0.2\ \mathrm{V}
]

ドレイン電流は、

[
I_D=
1\ \mathrm{mA/V^2}
\times
(0.2\ \mathrm{V})^2
]

[
I_D=0.04\ \mathrm{mA}
]

[
I_D=40\ \mathrm{\mu A}
]

となる。

オーバードライブ電圧を0.2 Vから0.4 Vへ2倍にすると、ドレイン電流は次のようになる。

[
I_D=
1\ \mathrm{mA/V^2}
\times
(0.4\ \mathrm{V})^2
]

[
I_D=0.16\ \mathrm{mA}
]

[
I_D=160\ \mathrm{\mu A}
]

オーバードライブ電圧は2倍だが、ドレイン電流は40 µAから160 µAへ4倍になる。

#### チャネル長変調を含めた式

理想的な平方則モデルでは、飽和領域のドレイン電流は (V_{DS}) によって変化しない。

実際には、(V_{DS}) が大きくなるとドレイン電流も少し増加する。この影響をチャネル長変調という。

チャネル長変調を含めると、飽和領域の式は次のようになる。

[
I_D=
\frac{\beta}{2}
V_{OV}^2
(1+\lambda V_{DS})
]

(\lambda) はチャネル長変調係数で、単位は (\mathrm{V^{-1}}) である。

実際の微細なMOSFETは平方則からずれる場合があるが、平方則モデルは回路の基本的な関係を理解するために役立つ。

**結論**

飽和領域のドレイン電流は、MOSFETの大きさ (\beta) とオーバードライブ電圧 (V_{OV}) で決まり、理想的には (V_{OV}) の2乗に比例する。

---

### 1.8　相互コンダクタンス (g_m)

#### (g_m) はゲート電圧の変化を電流の変化へ変える能力

ゲート・ソース間電圧を少し変えると、ドレイン電流も変化する。

このとき、

```text
ゲート電圧を少し変えた
        ↓
ドレイン電流がどれだけ変わったか
```

を表す値が、相互コンダクタンス (g_m) である。

変化量を使って表すと、(g_m) はおおよそ次のように考えられる。

[
g_m\approx
\frac{\Delta I_D}{\Delta V_{GS}}
]

より正確には、直流動作点 (Q) における (I_D)-(V_{GS}) 曲線の傾きとして定義する。

[
g_m=
\left.
\frac{\partial I_D}{\partial V_{GS}}
\right|_Q
]

(Q) は、信号を加える前にMOSFETが動作している点である。この点を直流動作点、またはバイアス点と呼ぶ。

#### 小さな電圧変化と電流変化の関係

ゲート・ソース間に小さな電圧変化 (v_{gs}) を加えたとき、ドレイン電流の小さな変化 (i_d) は次のようになる。

[
i_d=g_mv_{gs}
]

(g_m) の単位はS、つまりジーメンスである。

[
1\ \mathrm{S}=1\ \mathrm{A/V}
]

これは、入力電圧を1 V変化させたとき、電流が何A変化するかを表している。

#### 平方則モデルから (g_m) を求める

飽和領域のドレイン電流は、

[
I_D=
\frac{\beta}{2}
(V_{GS}-V_{th})^2
]

である。

これを (V_{GS}) で微分すると、

[
g_m=
\beta(V_{GS}-V_{th})
]

となる。

したがって、

[
g_m=\beta V_{OV}
]

と表せる。

また、

[
I_D=\frac{\beta}{2}V_{OV}^2
]

を使うと、次の形にもできる。

[
g_m=\frac{2I_D}{V_{OV}}
]

#### (g_m) の計算例

次の条件を考える。

[
I_D=50\ \mathrm{\mu A}
]

[
V_{OV}=0.2\ \mathrm{V}
]

このとき、

[
g_m=
\frac{2\times50\ \mathrm{\mu A}}
{0.2\ \mathrm{V}}
]

[
g_m=0.5\ \mathrm{mS}
]

となる。

このMOSFETに1 mVの小さな入力電圧 (v_{gs}) を加えると、ドレイン電流の変化は次のようになる。

[
i_d=g_mv_{gs}
]

[
i_d=
0.5\ \mathrm{mS}
\times
1\ \mathrm{mV}
]

[
i_d=0.5\ \mathrm{\mu A}
]

つまり、ゲート電圧が1 mV変化すると、ドレイン電流は0.5 µA変化する。

#### (g_m) と電圧利得の違い

(g_m) は電圧利得ではない。

(g_m) が表すのは、入力電圧を出力電流へ変換する能力である。

```text
入力電圧 v_gs
      ↓  g_m
電流変化 i_d
```

この電流変化を抵抗へ流し、電圧へ戻すことで電圧利得が生まれる。

```text
入力電圧
   ↓
電流変化
   ↓
抵抗による電圧変化
   ↓
出力電圧
```

同じドレイン電流なら、(V_{OV}) を小さくすると (g_m) は大きくなる。

[
g_m=\frac{2I_D}{V_{OV}}
]

しかし、小さな (V_{OV}) で同じ電流を流すには、MOSFETの幅を広くする必要がある。その結果、回路面積や寄生容量が増えることがある。

**結論**

相互コンダクタンス (g_m) は、ゲート電圧の小さな変化をドレイン電流の変化へ変える能力を表す。

---

### 1.9　出力抵抗 (r_o)

#### 実際のMOSFETは完全な電流源ではない

理想的な飽和領域では、(V_{DS}) が変化してもドレイン電流は一定である。

```text
V_DS が変わる
      ↓
理想：I_D は変わらない
```

しかし、実際のMOSFETでは、(V_{DS}) が高くなるとチャネルの有効な長さが少し短くなり、ドレイン電流が増加する。

この現象をチャネル長変調と呼ぶ。

チャネル長変調を含めたドレイン電流は、次の式で表される。

[
I_D=
\frac{\beta}{2}
V_{OV}^2
(1+\lambda V_{DS})
]

この式には (V_{DS}) が含まれているため、飽和領域でもドレイン電流が完全に一定ではないことが分かる。

#### 出力コンダクタンスと出力抵抗

(V_{DS}) を少し変えたとき、(I_D) がどれだけ変化するかを表す値を、出力コンダクタンス (g_{ds}) と呼ぶ。

[
g_{ds}=
\left.
\frac{\partial I_D}{\partial V_{DS}}
\right|_Q
]

出力抵抗 (r_o) は、その逆数である。

[
r_o=\frac{1}{g_{ds}}
]

チャネル長変調係数 (\lambda) を使うと、出力抵抗は次のように近似できる。

[
r_o\approx\frac{1}{\lambda I_D}
]

この式から、次の関係が分かる。

* (\lambda) が小さいほど (r_o) は大きい
* (I_D) が小さいほど (r_o) は大きい

#### 出力抵抗の計算例

次の条件を考える。

[
\lambda=0.1\ \mathrm{V^{-1}}
]

[
I_D=50\ \mathrm{\mu A}
]

出力抵抗は、

[
r_o=
\frac{1}
{0.1\times50\ \mathrm{\mu A}}
]

[
r_o=200\ \mathrm{k\Omega}
]

となる。

これは、ドレイン側からMOSFETを見たとき、約200 kΩの抵抗があるように見えることを意味する。

#### (r_o) が大きいと電圧利得が高くなる

MOSFET増幅回路の電圧利得は、おおよそ次のように表せる。

[
|A_v|\approx g_mr_o
]

先ほど求めた値を使う。

[
g_m=0.5\ \mathrm{mS}
]

[
r_o=200\ \mathrm{k\Omega}
]

すると、

[
|A_v|
\approx
0.5\ \mathrm{mS}
\times
200\ \mathrm{k\Omega}
]

[
|A_v|\approx100
]

となる。

電圧利得100倍をdBで表すと、約40 dBである。

[
20\log_{10}(100)=40\ \mathrm{dB}
]

この (g_mr_o) をMOSFETの真性利得と呼ぶことがある。

[
g_mr_o
\approx
\frac{2}{\lambda V_{OV}}
]

(\lambda) の逆数をアーリー電圧 (V_A) とすると、

[
V_A=\frac{1}{\lambda}
]

なので、

[
g_mr_o
\approx
\frac{2V_A}{V_{OV}}
]

とも書ける。

一般に、ゲート長 (L) を長くするとチャネル長変調が小さくなり、(r_o) を大きくしやすい。ただし、MOSFETが大きくなり、寄生容量や回路面積が増える場合がある。

**結論**

出力抵抗 (r_o) は、ドレイン電圧が変わったときにドレイン電流がどれだけ変わりにくいかを表す。大きな (r_o) は、高い電圧利得を得るために重要である。

### 1.10　MOSFETの小信号モデル

#### MOSFETの曲線を動作点の近くだけ直線として考える

MOSFETのドレイン電流とゲート・ソース間電圧の関係は、平方則モデルでは次の式で表される。

[
I_D=
\frac{\beta}{2}
(V_{GS}-V_{th})^2
]

この式は2次関数なので、(I_D) と (V_{GS}) の関係は直線ではなく曲線になる。

そのため、入力電圧が大きく変化する場合、MOSFETの動作を単純な抵抗だけで表すことはできない。

しかし、MOSFETをある直流動作点で動かし、その周りに小さな信号だけを加える場合、曲線の一部分を直線に近似できる。

```text
MOSFET本来の動作：曲線

動作点の近くだけを見る
        ↓
短い範囲なら直線に近い
        ↓
簡単な回路として計算できる
```

曲線に接する直線を使って近似する考え方である。

この方法を小信号解析と呼び、小信号解析で使う等価回路を小信号モデルと呼ぶ。

#### 直流動作点を決める

小信号解析を始める前に、信号が加わっていないときの直流電圧と直流電流を求める。

この点を直流動作点、またはバイアス点 (Q) と呼ぶ。

たとえば、

[
V_{GS}=0.7\ \mathrm{V}
]

[
V_{DS}=1.0\ \mathrm{V}
]

[
I_D=50\ \mathrm{\mu A}
]

が直流動作点だとする。

この状態に、小さな交流信号 (v_{gs}) が加わる。

実際のゲート・ソース間電圧は、

[
v_{GS,\mathrm{total}}(t)
========================

V_{GS}+v_{gs}(t)
]

となる。

実際のドレイン電流も、

[
i_{D,\mathrm{total}}(t)
=======================

I_D+i_d(t)
]

と表せる。

たとえば、直流ゲート・ソース間電圧が0.7 Vで、小信号が5 mV変化するなら、実際の電圧は0.695 Vから0.705 Vの間で変化する。

```text
直流値：0.700 V
小信号：±0.005 V

実際の値：0.695 V ～ 0.705 V
```

#### 低周波小信号モデルの構成

低い周波数で使う基本的なMOSFETの小信号モデルは、次の三つの特徴で表される。

1. ゲートには電流がほとんど流れない
2. (v_{gs}) によって (g_mv_{gs}) の電流が発生する
3. ドレイン・ソース間には出力抵抗 (r_o) がある

```text
入力電圧 v_gs
      ↓
制御電流 g_m v_gs
      ↓
出力抵抗 r_o
      ↓
出力電圧 v_out
```

ゲート電圧の小さな変化は、(g_m) によってドレイン電流の変化へ変換される。

[
i_d=g_mv_{gs}
]

その電流変化が出力抵抗へ流れることで、出力電圧が変化する。

#### ソース接地増幅回路の電圧利得

ソース接地増幅回路では、入力電圧が高くなるとドレイン電流が増える。

ドレイン電流が増えると、出力側の負荷に生じる電圧降下が大きくなる。その結果、ドレインの出力電圧は低くなる。

```text
入力電圧が上がる
      ↓
ドレイン電流が増える
      ↓
負荷の電圧降下が増える
      ↓
出力電圧が下がる
```

このため、入力と出力の向きが反対になる。

ソース接地増幅回路の電圧利得は、おおよそ次の式で表せる。

[
A_v\approx-g_mR_{out}
]

出力にMOSFETの出力抵抗 (r_o) と負荷抵抗 (R_L) が接続されている場合、

[
R_{out}=r_o\parallel R_L
]

となる。

したがって、

[
A_v
\approx
-g_m(r_o\parallel R_L)
]

と書ける。

(\parallel) は並列接続を表す。

2本の抵抗 (R_1) と (R_2) の並列抵抗は、次の式で求められる。

[
R_1\parallel R_2
================

\frac{R_1R_2}{R_1+R_2}
]

#### 電圧利得の計算例

次の値を使う。

[
g_m=0.5\ \mathrm{mS}
]

[
r_o=200\ \mathrm{k\Omega}
]

[
R_L=200\ \mathrm{k\Omega}
]

まず、出力抵抗の並列値を求める。

[
r_o\parallel R_L
================

\frac{
200\ \mathrm{k\Omega}
\times
200\ \mathrm{k\Omega}
}{
200\ \mathrm{k\Omega}
+
200\ \mathrm{k\Omega}
}
]

[
r_o\parallel R_L
================

100\ \mathrm{k\Omega}
]

したがって、電圧利得は、

[
A_v
\approx
-0.5\ \mathrm{mS}
\times
100\ \mathrm{k\Omega}
]

[
A_v\approx-50
]

となる。

入力小信号が1 mVなら、出力小信号は次のようになる。

[
v_{out}=A_vv_{gs}
]

[
v_{out}
=======

-50\times1\ \mathrm{mV}
]

[
v_{out}=-50\ \mathrm{mV}
]

マイナス記号は、入力電圧が上がったときに出力電圧が下がることを表している。

#### 小信号モデルを使える範囲

小信号モデルは、入力信号が直流動作点の周りで十分に小さい場合に使える。

一つの目安として、

[
|v_{gs}|\ll V_{OV}
]

を満たす必要がある。

たとえば、(V_{OV}=0.2\ \mathrm{V}) なら、(v_{gs}) が数mV程度であれば小信号として扱いやすい。

入力信号が大きくなると、MOSFETの2次関数的な性質が無視できなくなり、出力波形にひずみが生じる。その場合は、小信号モデルではなく、大信号のドレイン電流式を使って考える。

また、周波数が高くなると、ゲート・ソース間容量 (C_{gs}) やゲート・ドレイン間容量 (C_{gd}) の影響も含める必要がある。

#### 二段構成オペアンプとのつながり

二段構成オペアンプの第1段では、入力電圧の差をMOSFETの (g_m) によって電流の変化へ変換する。

その電流変化が出力抵抗へ流れ、第1段の出力電圧を作る。

第2段でも同じように、入力電圧を電流へ変換し、出力抵抗によって電圧へ戻す。

```text
第1段
入力電圧差
   ↓
電流変化
   ↓
第1段の出力電圧

第2段
第1段の出力電圧
   ↓
電流変化
   ↓
最終的な出力電圧
```

第1段の電圧利得を (A_1)、第2段の電圧利得を (A_2) とすると、回路全体の開ループ利得は、おおよそ各段の利得の積になる。

[
A_0\approx A_1A_2
]

これが、二段構成によって大きな電圧利得を得られる理由である。

**結論**

小信号モデルでは、MOSFETを (g_m) と (r_o) を使った簡単な回路として表す。このモデルによって、MOSFET増幅回路や二段構成オペアンプの電圧利得を計算できる。

## 第1章の結論

オペアンプは、非反転入力と反転入力の電圧差を増幅する。開ループ利得は非常に大きいため、通常は負帰還をかけて必要な電圧利得に調整する。

CMOSオペアンプを構成するNMOSとPMOSは、ゲートに加わる電圧によってドレイン電流を調整する。

MOSFETを増幅回路として使うときは、基本的に飽和領域で動作させる。

飽和領域では、ドレイン電流は次のように表せる。

[
I_D=
\frac{\beta}{2}
V_{OV}^2
]

相互コンダクタンス (g_m) は、入力電圧を電流の変化へ変換する能力を表す。

[
i_d=g_mv_{gs}
]

出力抵抗 (r_o) は、ドレイン電圧が変化したときに、ドレイン電流がどれだけ変化しにくいかを表す。

[
r_o\approx\frac{1}{\lambda I_D}
]

MOSFET増幅回路の電圧利得は、おおよそ次のように決まる。

[
A_v\approx-g_mR_{out}
]

したがって、CMOS増幅回路では次の流れで電圧増幅が行われる。

```text
入力電圧の変化
        ↓
g_mによって電流の変化へ変換
        ↓
出力抵抗に電流が流れる
        ↓
出力電圧が変化する
```

この「電圧を電流へ変え、再び電圧へ戻す」という考え方が、二段構成CMOSオペアンプを理解するための基本になる。
